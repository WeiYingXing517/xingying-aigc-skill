# 故事梗概与全剧大纲

适用于原创、小说改编和已有故事修订。可独立处理梗概、全剧大纲、关键事件、冲突、转折、信息差、伏笔或结局。按用户目标和材料缺口选用相关段落。

## 建立故事依据

- 读取当前有效的创意、小说整理结果、梗概、大纲、人物或正文。区分用户硬要求、已有情节、合理推导、授权内新增和未决事项。来源、有效状态和版本遵循 [项目与事实](project.md)。
- 用一句具体的话明确故事核心，例如“债务到期前，主人公必须找回原始账本，否则妹妹会替他承担责任”。同时明确人物在意什么、受到何种阻力、失败或选择会改变什么。群像可由共同事件和多方选择推动。
- 区分阻碍当前产物的缺口、有意留白和尚未到兑现时点的内容。只说明必须补齐的最小条件。姓名、装饰等普通细节可在授权内补，受保护的身份、关系、关键事件和结局按已知边界处理。
- 核对输入覆盖。材料只支持某段时，依据用户授权分别给出该段的整理结果或明确标注的后续创作提案。只有素材或授权足以支撑全篇时才交付完整大纲。

方向尚未成立或候选雷同时，先按[构思与取舍](ideation.md)比较行动机制；已有方向不重开选题。类型主导时按[类型体验](genre.md)确定压力来源和结局约定，再展开本项目事件。

## 用事件组织主线和支线

关键事件保留内部事件 ID，例如 `E001`。已有事件沿用原 ID。内部按需记录：

| 字段 | 内容 |
| --- | --- |
| 事件、时点与来源 | 事件 ID、故事时点、素材位置或新增依据。倒叙、插叙另记呈现位置 |
| 起始处境与触发 | 人物要处理的事、相关角色 ID、阻力、事件开始的具体条件 |
| 反应与行动 | 人物感知和判断了什么，选择做什么、等待什么或被迫做什么。核对所需知识、权限、能力和资源 |
| 后果与连接 | 行动或不行动改变了什么，给下一段留下哪些条件。可跟踪信息、关系、风险、代价和可选行动 |

以能解释因果的粒度组织事件。允许偶然触发、并行支线和静态关系场面，检查它们是否改变判断、关系、处境或后续条件。一个主要结果可以来自多人行动，也可以由环境变化或人物未行动造成。合并无新增作用的重复冲突和解释，保留用户锁定事件。

### 冲突、转折与结局

- **剧情驱动。** 用处境、触发、感知和判断、行动、后果检查推进。后果应当让人物面对新的局面或选择。被动应对、合理误判、妥协和失败都有可成立的依据。
- **多方反馈。** 关键对抗先核[各方可行办法](characters.md#从诉求推到选择)，推演对手原本计划与主角干预改变的条件。下一轮反应继承损失、信息和资源，不靠对手降智、万能援助或重复误会重置。
- **冲突递进。** 写清压力从哪里来，原办法为何失效或代价如何变化。压力可以从外部风险转向承诺、关系或认知。可保留缓和与真实的阶段成果。
- **关键转折。** 写清此前路径、前置条件、触发、人物回应和转折后的路径。观众单独获知新信息可以是一次揭示，角色判断或故事走向发生变化时才把它写成对应的转折。
- **结局。** 明确核心冲突的结果、关键选择与代价、主角和主要关系的落点。高潮所需的能力、证据、机会和条件要在此前建立。交代主要叙事承诺的处理结果与明确保留的开放项。

### 信息差与伏笔

- 复用事实和认知记录。对于会改变判断和行动的信息，明确事实依据、角色取得和理解的范围、观众看到的时点，以及披露后产生的变化。谎言、猜测和误解保持其性质，当前行动留足理解条件。
- 对关键结果反查必要前置，对突出细节正查后续作用。记录埋设事件、可见对象、兑现事件及作用。前置内容可以是能力、资源、行为或关系条件，兑现可以是认知、行动或结果的变化。开放项保留适用范围。
- 区分计划中的披露、稿件已呈现的信息和人物当下知道的事。调整揭示顺序时，复核相关行动、转折和兑现点。

## 把故事目标转成观众期待

需要设计开场、爽点或持续观看动力时，按[期待与回报](expectation.md)确定首要期待、建立事件、阶段进展和兑现结果，把它们绑定到本稿事件，而不是在大纲外另列无关钩子。先确定高潮偿还哪项承诺，再检查前段是否让观众真正产生过该期待。大纲可掌握真相，角色行动只依据当时可得信息；事件表上的结局、隐藏动机和后文回收意图不能自动成为人物认知。调整开头或回报位置后复核伏笔、知情次序与结局。

## 交付形态

- **故事梗概。** 连贯叙述起因、主要矛盾、发展、高潮和结局方向。细节量服从用户给定的长度和披露范围。
- **全剧大纲。** 包含故事核心、主要人物处境、主线的完整因果过程、必要支线、转折、高潮、结局和有实质影响的未决项。采用适合故事的结构。简要说明主要行动与结果，细到可继续分集或拆场，避免展开逐场对白。
- **专项设计或局部修订。** 交付指定的事件链、压力递进、转折、信息安排、伏笔、结局或大纲段落，说明对相关后文的影响。复用已成立材料，保留无关事件的 ID。

人物决策需要深化时查 [人物卡](characters.md)。分集或剧本拆场分别查 [分集大纲](episodes.md) 和 [剧本正文](script.md)。需要检查成稿因果、连续性或改稿影响时查 [审稿](review.md)。
