# 类型体验与场面条件

作品依赖特定体验或用户要求修补该体验时读取；不要求每次加载全部类型。先确定主导感受、持续关切与结局约定，再用[期待与回报](expectation.md)排建立、进展和兑现。混合类型允许不同阶段主导，不把类型变成桥段配额。

## 不同类型怎样产生等待

| 类型 | 主要工作 | 常见失效与修法 |
|---|---|---|
| 悬疑／推理 | 分开真相、角色调查与观众问题；线索经历取得、辨认、解释，揭晓改变判断或行动 | 无关怪事不能代替可追查问题；临时身份不能解释一切。回查实际线索与误判依据，不撤销已确立事实 |
| 惊悚／恐怖 | 建立威胁、应对限制和仍可失去的安全边界；未知与已知危险都可产生压力 | 重复惊吓须改变认知、办法或安全范围。逃离与求助为何受阻需有条件，不让全员失智；允许短暂安全 |
| 爱情／关系 | 具体化靠近收益、表达成本、托付、边界与兑现；公开和私下态度可不同 | 知道秘密、被救或一句道歉不自动兑换亲密与原谅。让后续行为改变信任；简单误会不无理由拖成长线 |
| 喜剧／讽刺 | 人物认真追求与现实反馈错位；重复带来差异和累积后果 | 不让所有人说段子，不为包袱取消常识。用人物办法与规则运作制造变化，讽刺落到行为而非人群标签 |
| 动作／冒险 | 明确各方目标、空间、资源与策略；选择改变局势 | 不靠敌人加大或临时新能力升级。检查位置、物件与伤势的流转，结束留下可承接状态 |
| 幻想／规则型故事 | 能力与制度通过使用条件、边界和相关成本影响选择 | 优先组合已有规则；决定性便利提前建立。不是每项背景都必须付代价，也不能危机时取消已知限制 |
| 日常／现实 | 累积注意变化、生活差异、关系移动与理解迟到 | 不把安静当无进展，不强塞反派与灾难；选择性展开，不写无差别流水账，也不用总结人生代替落点 |
| 爽剧／连载 | 让想看到的满足具体化，阶段回报支撑长线等待，成果形成后续条件 | 不靠重复受辱、反派降智与假揭晓延期；能力、证据和援助有前因，实际改变权力、关系或处境 |

广告按传播目标、展示与证明安排等待，不照搬长剧情仇；用户指定风格与结局优先。类型描述是写作工具，不是平台规则或受众实测结论。

## 动作场面：追踪决定性条件

仅在复杂打斗、追逐、争夺等需要时，先确定各方要夺取、保护、拖延或逃离什么，手头资源、可付代价和退路是什么。局势变化来自换办法、环境使用、资源消耗、误判或身体限制，不只来自力度更大。

核对：人物位置与出入口；够得着、看得见和来得及的条件；物件落点及重新取得；动作先后依赖；伤势、时间与体力对后续的作用。画外与剪切可省过程，不能代替缺失条件。关键选择适当停留，重复动作可压缩，不逐拍写成说明书。

结束交接位置、身体、物件、资源、关系和知情中实际变化的部分；不要求胜利必须受罚，但不能无故重置。现实危险行为不扩展成可操作的伤害指南，内容风险按[审核](risk.md)处理。

## 世界与生活：只补会改变行动的规则

剧情依赖某项制度或能力时，问谁能取得、谁执行、如何使用、限制是什么，以及相关成本或弱点是否影响选择。按因果需要采用，不给所有设定强填四项。组织可有不同利益，也可合理合作，不强造内斗；主角不行动时，其他人仍有自己的事。

把规则落实到办事、等待、代办、欠情、资源分配和后果，避免靠百科介绍或一句演说解决制度。关键规则改变后沿人物办法、知情和终局回查。真实警务、法律、医疗等知识未核实不写成确定事实，按[研究](research.md)核查或按[审核](risk.md)标专业事实待核。

## 停止条件

当前体验有具体文本依据，角色受到已建立条件影响，关键回报不靠临时规则，结局回应约定，即停止补戏。审稿只指出实际缺口和最小修法，不因没套齐经典节拍继续加事件。
