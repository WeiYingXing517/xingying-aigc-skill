# 分集大纲与单集节奏

适用于整部或指定区间的分集、局部重分集、跨集衔接及单集节奏专项。使用当前有效故事、人物、事件顺序和时长约束。已有信息充分时直接复用，因果或主要结果缺失时查 [全剧大纲](outline.md)。

## 分集方法

1. 确定故事覆盖范围、集数、单集或总时长及已知制作条件，区分硬要求、可调整目标和工作假设。未指定数量或时长时给出基于内容的工作假设。材料只支持指定区间时交付该区间并写清覆盖边界。
2. 找出事件的必要依赖，包括先行动作、角色获知信息的条件、关键关系变化及支线交汇。将能够完成一个叙事任务并产生具体变化的事件组织成一集。可以交织并行线，说明各线在本集的作用。
3. 逐集写清开始条件、行动、进展与结果，检查相邻集的状态承接。单部短片或电影按全片段落和场次组织，使用整体时长和结局要求。
4. 对照容量估算对白、动作、观众辨认、情绪停留和转场负担。用「对白估时 + 未与对白重叠的动作时间 + 必要停顿与辨认 + 转场」给区间；同时发生的动作与对白不重复相加。注明实读、素材参考或工作假设，不用字数直接宣称成片时长。例如，假设对白需 55–65 秒、独立行动 25–35 秒、必要辨认和停顿 10–15 秒，合计 90–115 秒，不能无条件称适合 90 秒。先压缩或重组重复功能，硬约束仍冲突则指出具体区间和最小调整条件。未实读或试拍时保留估算性质。

## 按播放链估时与检查交错

涉及定长或压缩时，明确当前稿范围、实际发声语言、片头片尾是否计入。译文仅供阅读则不当作再次发声；数字按实际念法估。对白必须说完或动作必须完成才触发后续时顺序计算，真正同步呈现取相应较长区间；不得把同一反应重复加进对白和动作。两个事件戏内同时发生但银幕先后播放，仍分别计时。未取得足够台词与行动依据时，不仅凭集数给确定秒数。

严格上限按估算区间单独判断：下限已高于上限表示当前假设下超限，区间跨上限表示可能超限，上端不超过上限仅表示估算未显示超限，不等于成片实测。压缩前后采用相同假设，同一段的替代方案不重复叠加节省值，不靠少写动作字数冒充少播放时间。

多线作品先逐线查时间、目标与退出状态，再按实际交错顺序查定向、记忆负担、重复和情绪承接。单线各自成立不等于任意交叉都顺；切回时用最少信息接住关切，不大段重播前情。分集进展包含人物办法因对方反馈如何改变，而非每集换一个同质障碍。

## 逐集字段

内部引用采用 `EP01`、`E001`、`C001` 等稳定 ID。对外采用用户指定的集号、集名和排版。

用户未另定格式时，每集明确呈现叙事任务、起始状态、主要事件、有效进展与集末承接。可以合并相近字段或用短句标出，便于后续直接据此写场次。已知集长时逐集核对容量。未定集长而容量影响切点时，注明采用的工作假设。

| 字段 | 写法 |
| --- | --- |
| 本集任务 | 本集要处理或推进的具体问题 |
| 起始状态 | 局势、关系、资源、角色认知，以及理解本集需要的前情 |
| 事件与因果 | 主要事件的触发、行动和结果，标明并行线关联与有效事件依据 |
| 有效进展 | 本集使行动、认知、关系、情绪、选择或风险发生什么变化。合理失败也可以形成进展 |
| 期待与回报 | 适用时明确本集观众在等什么、推进或兑现了什么、剩余期待由哪个实际后果承接；可融入事件描述，不强制加外显表格 |
| 结束状态与承接 | 本集落点、留下的行动或问题、下集需要接住的条件。终集记录核心收束及约定留白 |
| 容量与变更 | 目标时长和主要内容负担，关键合并、调序或新增项及依据，必要时标未决条件 |

全篇分集检查事件覆盖、顺序、重复、起止衔接和结局。局部调整保留无关集次与内部 ID，说明受影响的集和连接。新增或重排集次时区分内部引用与外显集号，并按 [项目与事实](project.md) 记录影响。

## 按作品形式观察节奏

已选对标时，只将[经核查的节奏观察](research.md)转成项目的节奏约束。以本项目人物选择和原创事件满足约束。参考的独特桥段、反转组合及事件排列只用于核查原创边界。

| 形式 | 可观察的节奏维度 |
|---|---|
| 短剧 | 主问题何时建立、单位时间有效变化、阶段回报、集末承接及末集收束 |
| 电影／短片 | 全片段落、主要转折的相对位置、场次张弛、高潮与余韵 |
| 电视剧 | 单集主支线交替、人物线推进、阶段性兑现间隔、集间承接 |
| 广告脚本 | 核心利益点出现时机、信息密度、展示与证明的篇幅、行动提示的位置 |

按实际可见样本和目标体量调整。电影按全片与场次组织。电视剧的跨集推进适配其时长。广告以传播目标和总秒数分段。用现有容量规则检查落到稿件后的时长负担。

## 把期待落到集内与集间

需要开场吸引力、爽点或追更结构时，按[期待与回报](expectation.md)把长线承诺拆成可感知进展和阶段兑现，再定切点。先承接上一集欠下的问题，允许答案产生新后果；不把每集停在说答案前一个字当成唯一钩子。已建立的成果继续有效，终集偿还核心承诺。只有规划时写「计划兑现」，不能当成正文已经实现。下列节奏检查与该表合用，不重复建一套台账。

## 跨集衔接与单集节奏

- **跨集衔接。** 可以顺接、展开后果、跳时间或换视角。通过观众可以理解的条件接住上一集结果、人物状态和未完成行动。回顾只留当前理解所需的内容。重看同一事件应带来新信息、解释或后果。
- **单集节奏。** 按段落梳理信息、行动、情绪与阶段结果如何变化，考虑反应时间、安静段落和信息负担。重复解释或等待应有实际叙事作用。只调相关段落及相邻连接。
- **短剧开场。** 从本集实际推进的异常、动作、风险、关系或问题切入，尽早交代必要的理解条件。用户有黄金三秒等时长目标时按该窗口安排，保证开场能够接回正文。
- **本集回报。** 将已建立的期待落实为具体变化，例如信息确认、关系进展、行动完成或失败后的新选择。兑现可出现在不同段落，有依据的阶段成果延续至后文。
- **短剧结尾。** 用正文中发生的选择或结果形成下一集可承接的问题、行动或新处境。暂停位置有叙事理由，允许本集先兑现。终集优先收束，可按用户要求留下余韵或续作承诺。

需要场次、开场成品、结尾成品或正文时，按 [剧本正文](script.md) 写作和排版。完播、追更、因果及连续性的成稿检查见 [审稿](review.md)。
