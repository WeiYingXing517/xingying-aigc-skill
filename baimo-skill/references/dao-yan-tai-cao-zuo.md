# 建立与操作导演台

使用本地Python 3。没有可用Python时说明，不能只交损坏入口；可在授权范围使用等效本地静态服务。不要直接双击index.html，浏览器模块需要HTTP。

```text
python <skill目录>/scripts/create_project.py --output <当前项目目录>/whitebox
python <项目目录>/whitebox/serve.py --port 8765
```

服务只绑定127.0.0.1，不发布到外网。端口占用换端口，不停止不明进程。首次建项目不覆盖现有目标。浏览器访问服务地址。停止服务后项目文件仍保留，下次重新运行serve.py。

场景模式：添加盒体/圆柱/平面，数值编辑或拖拽，选择参考图仅本地显示，不上传。模式切换仅改变工作权限，不自动生成演员。分镜模式：添加人形，设置初始姿态，调整拍摄相机，点“新建镜头”保存当前起态；以后修改点击“保存当前镜头”。复制镜头保独立状态，切换未保存改动会询问。观察相机用鼠标左键环绕、中键缩放、右键平移；控件拖拽时暂停观察相机。拍摄预览拖动不会误改摄影机，使用“操作拍摄机”显式切换控制对象，或“观察视角→拍摄机”。

保存工程下载project.json，保存至项目目录；重新打开通过载入工程恢复。浏览器草稿是辅助可恢复项，采用时须显式点击；不自动覆盖文件或用户手动版本。撤销/重做针对工程编辑，不将自由观察纳入分镜变更。

“导出当前PNG”导出当前拍摄预览；已保存镜头批量导出按各镜保存状态，不把未保存工作副本冒充保存版本。导出尺寸可输入，保持相机画幅，PNG无网格/相机/选中辅助。批量下载可能被浏览器拦截，提示允许多文件或逐镜导出，不声称全部成功。

Agent制作：复制模板、编写project.json→载入→逐镜实际查看→导出请求PNG→查看导出文件→交付工程及图片。可以在本地浏览器自动化调用window.directorAPI获取/载入工程、切换镜头、导出数据URL，见模板README；不得调用不存在的工具或以截图代替指定分辨率PNG。开发调试文件放项目validation，不写进用户成品区。
