# 项目落盘结构与长篇滑动窗口协议

本文件定义多集剧本、长篇改编及跨会话续写的标准落盘结构与上下文滑动窗口协议。单次轻任务（如单场创作、15 秒单条广告、局部改词）若用户未指定保存目录，可在会话内直接交付，无需强建文件夹。

---

## 一、 标准项目目录结构

当用户指定项目目录，或进入多集整剧（≥3 集）/ 长篇小说改编主轨时，统一在项目目录下维护以下 4 张极简状态卡与分批正文：

```text
<项目根目录>/
├── 00_project_brief.md       # 立项锁：通道、题材风味、集数时长、下游模式、必保锚点
├── 01_story_bible.md         # 故事圣经：一句话主线、人物反应机制卡(C01..)、全局真相与底牌
├── 02_episode_map.md         # 分集/序列蓝图：逐集核心进展、期待兑现点、集末切点与原著映射
├── 03_handoff_state.md       # 动态滑窗快照：截至最新已写集的角色知情边界、未消情绪、道具伤势、待收伏笔
└── episodes/                 # 剧本正文分批存放（如 EP01-EP03.md、EP04-EP06.md）
```

---

## 二、 长篇续写「滑动窗口读取协议」（防上下文爆炸）

当项目推进到后续批次（例如正在创作 `EP07 ~ EP09`）时，**严禁将 `EP01 ~ EP06` 的全部历史正文塞回上下文**，只允许读取以下 4 项最小完备集（合计通常 `< 6KB`）：

1. **`00_project_brief.md` + `01_story_bible.md`**：锁定全局不变的人设声线、核心底牌与终局方向。
2. **`02_episode_map.md` 的局部窗口**：只截取 `EP06`（上一集）至 `EP10`（下一集预告衔接）的分集规划行。
3. **上一集最后一场原文**（即 `EP06` 最末一场的完整正文）：确保 `EP07` 第 1 场的动作、台词、空间位置与集末悬念严丝合缝顺接。
4. **`03_handoff_state.md`**：继承截至 `EP06` 结束时的角色认知边界、情绪余波与随身状态。

每完成一批正文并通过终检后，**立即覆写更新 `03_handoff_state.md`**（只保留对后续集数仍有影响的活跃状态，已彻底完结的局部小事及时归档剔除，保持快照永远精悍）。

## 三、 四张状态卡标准模板

### 1. `00_project_brief.md`（立项与规格锁）

```markdown
# 项目立项锁（星应剧本 3.5）

- **项目名称**：
- **锁定通道**：ch-short-drama | ch-series | ch-film | ch-commercial | ch-narrated
- **题材风味**：（如：现代都市·悬疑复仇）
- **体量规格**：共 __ 集 × 单集 __ 秒/分钟（画幅：9:16 竖屏 / 16:9 横屏）
- **素材来源**：原创 / 改编自《__》（已读范围：第 __ 章至第 __ 章）
- **下游模式**：实拍阅读版 / 对接星应分镜 3.5 · AI 漫剧管线版
- **必保红线与禁改项**：（用户明确锁定的身份、核心事件、结局方向）
- **当前执行基线**：以 [已确认分集稿 v1] 为准
```

### 2. `01_story_bible.md`（故事核与人物反应机制卡）

```markdown
# 故事圣经与人物档案

## 一、 核心引擎与世界防漂移锚点
- **一句话故事核**：（谁必须在什么期限/死局下做成什么事，否则付出什么不可承受的代价）
- **全局真相底牌**：（仅作者掌握的幕后真相，严禁未到揭示点提前漏进角色台词）
- **首要观众期待**：（观众追看全剧最想看到兑现的具体结果）
- **时代与视觉防漂移锚点** *(对接星应分镜 3.5 / AI 漫剧模式必填)*：精确年份/朝代与地域 + **3 项时代必现标志物** + **严禁出现的跨代穿帮物清单**（如近未来禁煤油灯/旧木梯，古风禁玻璃幕墙/电线杆）

## 二、 核心人物卡
### [C01] 姓名（身份 / 年龄段 / 身高体型）
- **表层目标 vs 深层软肋**：想要什么 / 最怕失去或被戳穿什么
- **开局双盲区**：开局能力缺口（不会什么） + 开局认知盲区（确信但实际错判的事）
- **压力反应机制**：遇压惯用手段（反问拿捏 / 假意顺从 / 冷脸算账 / 转移视线）及破防条件
- **对手独立计划**（反派必填）：若主角不干预，他原本在按什么时间表推进什么事、手里有哪些合法/灰色筹码（首战占优与三轮博弈规划）
- **声线与称呼锁**：句式节奏特征、对各主要角色的常态称呼及翻脸/决裂后的退回称呼
- **外观三件套与反漂移禁令** *(对接星应分镜 3.5 / AI 漫剧模式必填)*：职业硬标识物 + 服装形制材质 + **禁被画成何种邻近混淆职业**（如外卖员禁画成协警制服/对讲机）
```

### 4. `03_handoff_state.md`（跨批次滚动交接快照）

```markdown
# 动态交接快照（截至 EP__ 结束）

## 1. 角色知情与发言账本（严禁越权）
- **[C01 主角] 已知**：已知副手动过库房钥匙；**未知**：尚不知馆长才是幕后买方。
- **[C02 对手] 已知**：以为真底稿已被烧毁；**误判**：以为主角手里没有备份。
- **关键原话留痕**：EP02-S03 馆长只说「核实清楚前先停职」（系行政暂缓，后文不得错引为「你已经被开除了」）。
- **当前阶段称呼锁**：C01 对 C03 已从「周师兄」退回公事公办的「周副馆长」（未经破冰事件不得跳回熟称）。

## 2. 未消化情绪余波
- C01 对 C03（师兄）：因 EP02 师兄沉默未作证，目前仅维持表面工作配合，拒绝一切私下叙旧（未原谅）。

## 3. 物理连续性与资产状态栏
- **时间点与紧迫倒计时**：距最终评审封存还剩 14 小时（次日清晨 6:00）。
- **伤势/服装/核心道具状态**：C01 右手掌有烫伤纱布（后续动作受限）；原始修复日志在 C01 随身帆布包夹层；库房备用钥匙在 C02 手中。

## 4. 已埋未收伏笔与长线悬念存量（保持 ≥2 条活跃长线）
- [F01] EP01-S02 铭牌背面反常的二次打磨划痕 → 预计在 EP05 现场核验时作为翻盘铁证回收。
- [F02] 师父失踪前留下的半页残缺配方去向 → 跨阶段长线悬念（预计 EP12 揭晓）。
```

## 四、 局部改稿的依赖回查规程

当用户要求修改已成稿中的某一场（如修改 `EP02-S01` 中角色听到的信息或做出的决定）时：
1. **定界**：锁定被改动的事实、知情时点或道具去向。
2. **顺藤摸瓜**：通过 `03_handoff_state.md` 与 `02_episode_map.md` 定位下游哪几场戏引用了该条信息或道具。
3. **最小手术**：只重写当前目标场及受直接影响的下游关联句段，同步更新 `03_handoff_state.md`；无关场次原封保留，绝不借局部修改推翻整集重写。
