## 一、 原著锚点分级与改编边界锁

动笔前先将输入材料按以下三级划定边界（用户最新明确指令拥有最高覆盖权）：

1. **硬锁定锚点（未经用户明确授权严禁篡改）**：
   - 核心人物身份、主关系底色与正邪阵营归属；
   - 原著标志性名场面的核心因果（谁凭什么筹码赢/输）；
   - 最终结局走向与核心CP/主线归宿。
2. **默认授权改编区（可直接执行以适配视听规律）**：
   - 删减或合并功能重复的次要配角、同质化打脸过场与冗长背景铺垫；
   - 将前文慢热铺垫中的高冲突危机切片前置为开篇冷钩子（须守住时间线认知边界）；
   - 将大段心理描写、世界观设定说明转化为可见动作、道具交锋与对话博弈。
3. **缺章与断更纪律**：
   - 只拿到前几章、节选或梗概时，明确登记已读章节范围；
   - 后续补写走向必须显式标注为「【改编续写提案】」，绝不把推导或原创内容伪装成原著既有情节。
4. **原作压力条件与量词保真**：
   - 未经用户明确授权，严禁为追求短期刺激擅自篡改原著危机的**生效时限、触发条件与确定性量词**（如不得把「三天后验货不过才撤项」改成「今天停工当场开除」，不得把「可能受审」写成「已被除名」），防止撞碎后续章节因果链。

## 二、 小说心理与旁白「视听外化四法」

小说靠心理活动出彩，剧本靠外部视听立住。遇到原著大段心理描写或设定旁白时，按以下四法落地：

| 原著常见文本形态 | 视听外化手法 | 转化实操示范 |
| :--- | :--- | :--- |
| **情绪翻涌与犹豫心理**<br>（如：她心里乱极了，既怕签字背锅，又怕不签当场丢工作） | **1. 肢体阻滞与小动作外化** | `△ 笔尖悬在签名栏上方，墨点在纸上洇开一小团。周柠把笔帽重新扣死，指尖抵住合同第三页折角：「这一条违约金，我要先拍给法务看。」` |
| **前史回忆与人物执念**<br>（如：他想起五年前师父临终前交代绝不能开这只木匣） | **2. 往事二分外化法（对齐星应分镜 3.5）** | **严格二分**：仅一笔带过的情绪触动，一律转化为**当场指尖/眼神微顿半拍 + 随身旧物特写（绝不切时空开新场）**；确需展示当年关键动作证据时，才单列独立闪回场头（`1-2A 旧木屋（闪回） 夜 内`），杜绝为半句回忆乱建一次性场景资产。 |
| **复杂局势利弊分析**<br>（如：主角在脑中盘算三方势力谁是内鬼、用了五百字推理） | **3. 设局试探外化法** | 删掉脑内独白，直接设计主角故意放出一条半真半假的诱饵消息，用现场谁第一个跳出来拦截来让观众亲眼看到推理结果。 |
| **内心吐槽与表面伪装反差**<br>（网文高频爽点：表面乖巧应承，心里冷笑算计） | **4. 反差式短促 OS 法**<br>*(仅限短剧/漫剧/轻喜通道)* | 表面动作越恭顺，内心 `（OS）` 越冷脆（单句严格 `≤15 字`），绝不用 OS 重复解释表面已经演出来的动作。 |

## 三、 合角、缩线与调序安全复核

对长篇网文做大幅浓缩、合并配角或打乱章节顺序时，逐项过筛以下四道安全栓：

1. **合角四核**：把配角甲与配角乙合并为同一人前，检查——① 两人原先的知情时点是否冲突？② 对主角的善恶立场是否打架？③ 关键证物是怎么流转到他手里的？④ 结局承担的因果是否自洽？
2. **调序防早慧**：把原著第 10 章的冲突提前到第 1 集做钩子，或把两条支线交叉剪辑时，严查角色台词——**绝不能让第 2 集的角色说出第 5 集才获取的情报**。
3. **砍设定保门槛**：删减世界观背景说明时，**决定高潮胜负的那条核心规则或限制条件必须提前通过小事件演示给观众看**，不能高潮时突然掏出观众没听过的规则翻盘。
4. **保留原著灰度限定**：原著中角色「只是猜测」「道听途说」或「叙述者故意误导」的信息，改编进剧本时继续保持其不确定性，不擅自坐实为客观铁证。
