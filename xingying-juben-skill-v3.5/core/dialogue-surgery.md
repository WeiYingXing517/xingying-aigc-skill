# 台词手术刀与视听标记规范

本文件专治「AI 翻译腔、书面说明书、全员同一个嘴替、台词喘不上气」。写正文对白与精修润色时逐条执行。

---

## 一、 动笔前：每轮核心对话必过「四锚点」

落笔写任何关键对话前，先在脑中锁定四件事：
1. **手上正在干什么事**（边核对账单边说，还是堵在电梯口不让关门说？给对话挂上具体动作支点）。
2. **双方此刻的权力与亲疏**（求人的、拿捏人的、防备的，还是熟极而流？决定谁先开口、谁有资格打断谁）。
3. **这句话想逼/哄对方当场做什么**（台词是行动武器：试探、施压、甩锅、讨价还价、堵嘴或体面退场；没有当下行动目的的句子直接删掉）。
4. **哪半句咽回肚子里没说**（真正厉害的台词说七分留三分，把最痛的利益或顾虑藏在具体事务借口后面）。

## 二、 五刀切除「AI 模板腔」（病句 → 口语手术表）

| 病灶类型 | 典型 AI 坏台词（严禁出现） | 手术刀改法 | 改后可演台词示例 |
| :--- | :--- | :--- | :--- |
| **1. 书面连接词癌** | 「因此我认为这件事并不简单，然而我们目前没有证据，换句话说只能先等待。」 | **全删逻辑关联词**（因此/然而/不仅如此/换言之/总而言之/对我而言），碎成短促判断或直接给动作指令。 | 「这事不对。但现在没证据，先按兵不动。」 |
| **2. 心理自剖癌** | 「我之所以对你这么冷漠，是因为当年你走后我太害怕再次被抛弃了！」 | **禁止角色给自己做心理咨询诊断**。把脆弱藏进具体规矩、借口或驱赶动作里。 | 「钥匙放鞋柜上就行。太晚了，楼下不好打车，你先走吧。」 |
| **3. 工整排比金句癌** | 「你偷走的是我的署名，但偷不走我的才华；黑暗遮不住黎明，真相终将大白！」 | 除非角色正在台上发表公开演讲，否则**一律砍掉对仗升华口号**，换成直戳对方痛处的具体后果。 | 「铭牌你可以现在挂上去。明天上午十点专家组开封验底稿，希望你背得出第三层补色配方。」 |
| **4. 画面复述癌** | 「你竟然把茶杯摔碎在了地上！你为什么要发这么大火？」 | **眼睛能看见的动作，嘴上绝不复述**。直接写对方对摔杯子的即时反制或反应。 | `△ 茶盏砸在脚边溅湿裤脚。顾言眼皮没抬，把备用签字笔推过去。`<br>`顾言：摔完了？签字在右下角。` |
| **5. 明知故问科普癌** | 「哥，你忘了今天是我们亲妹妹林小雨二十岁生日、也是妈住院三周年的日子吗？」 | **双方共知的前史严禁硬塞进问句科普给观众**。改用现场道具加熟人半句话带出；**大背景数字与残酷规则优先塞进正在发火、算账或施压的对手/配角台词里喊出来**（如门外拍门骂「零下四十度停暖三天了你想冻死谁」，绝不用旁白干念设定）。 | `哥哥拎起桌上的栗子蛋糕看了一眼表：先去住院部。小雨在病房等切蛋糕。` |

### 附：分题材台词违和词红线表（古今严禁串味）

- **现代题材口语禁用公文虚词**（官腔人设或宣判词除外）：`是否 / 因此 / 从而 / 鉴于 / 予以 / 加以 / 可否 / 何以 / 颇为 / 甚为 / 以及 / 然而 / 兹`（一律改为 `是不是 / 所以 / 还有 / 直接动词`）。
- **古装与年代题材禁用现代词**：`逻辑 / 机制 / 系统（非系统流时） / 维度 / 定位 / 复盘 / 闭环 / 赋能 / 抓手 / 颗粒度 / 情绪价值 / 经济损失 / 心理阴影 / 物理意义 / 反馈 / 状态（抽象义）`。

### 附：「撒碎屑」四法与「带刺活人话」四式

- **撒碎屑四法（把工整书面句掰成真人活话）**：① **自我打断改口**（犹豫或藏事时说半句推翻重说）；② **半截掉尾**（威胁或难言之隐留给对方反应补齐）；③ **受惊只重复关键词**（不整句复读）；④ **嵌入自然垫词与句尾助词**（`那什么 / 得了 / 行吧`、`啊 / 吧 / 呢 / 嘛 / 呗`，彻底消灭零语气词机械腔）。
- **带刺活人话四式（把端着的总结金句改成当场能还嘴的交锋）**：
  1. **先接话茬再拐刀**：不自言自语抒情，顺着对方刚说的词顶回去（如把「我天天听着」改为「嚎这么大声干嘛，省点力气还能多撑半小时」）；
  2. **归谬拆解身份**：用对方的规矩当场卸掉对方道德高地（如「我还没过门呢，哪来的婆婆？」）；
  3. **陈述改反问+指令**：把旁白式表态变成当场压迫动作；
  4. **加生理/日常细节拆穿表演**：点破对方眼下的小动作（如「头磕这么响干嘛」），瞬间落地生活狠劲。

## 三、 人物声线差异化四维锁（遮名盲测法）

主要角色同场对话时，遮住角色名必须能分出谁是谁。不靠给每人编造尴尬口头禅，靠以下四个维度拉开差距：

1. **第一注意力不同**：同一场事故，财务先看损耗账目，法务先问谁签的字，老油条先找替罪羊，重情者先看人受没受伤。
2. **直接程度与防御习惯不同**：有人习惯单刀直入掀桌子；有人习惯先顺着夸两句再递刀子；有人遇事先拿规章制度挡箭；有人用装糊涂岔开话题。
3. **句长与词汇颗粒度不同**：久居上位者少解释、多给简短结论或反问；心虚圆谎者修饰词变多、急于补细节；专业人士用行话简称而非教科书全称。
4. **动态称呼四轴七态锁**：称呼由「身份 × 关系 × 公开/私下场合 × 当下情绪」四轴共同决定（公开尊称全称 / 私下简省 / 亲密昵称 / 求人升格敬称 / 恼火连名带姓 / 挑衅反讽敬称 / **决裂退回生疏尊称**）。关系破裂时，一句从「老陈」退回「陈总监」比喊十句狠话更有戏；同一关系阶段内称呼必须稳定，跨集改口必须有明确事件触发。

## 四、 呼吸气口与节奏标点硬规范

1. **单句气口阈值**：
   - **竖屏短剧 / 商业广告 / 口播解说**：单句两个标点之间的连续字数**默认不超过 18 字**；单轮连续台词不超过 3 句（高潮控诉或揭秘长段除外，且中间必须穿插对方反应或动作气口）。
   - **横屏剧集 / 电影**：单句连续字数**默认不超过 25 字**，确保演员一口气念得顺、上口不绕舌。
2. **打断与停顿标点**：
   - `——`（破折号置句尾）：代表话没说完被对方**硬生生抢话截断**或被突发声响打断，下一行紧接打断者的话或动作。
   - `……`（省略号）：仅在欲言又止、哽咽或试探留白时使用；**严禁每两句就挂一个省略号**导致节奏拖泥带水。

## 五、 剧本视听标记统一工业标准

除商业广告双栏/三栏表外，所有场次制剧本统一采用以下标准视听符号，确保导演、演员与下游 AI 分镜工具零歧义读取：

- **动作与环境行**：以 `△` 开头，独立成段。单段 `△` 不超过 3 行，不同景别或先后发生的动作分段书写。
- **角色台词行**：`角色名：台词正文` 或 `角色名（极简当下动作/语气）：台词正文`。表演提示仅在字面意思与实际语气相反（如笑着说狠话、压低声音）时标注，一目了然的情绪不标废话括号。
- **声音空间标记（严格防说话人解析污染）**：
  - `角色名（OS）：` —— 角色人在画面内、**闭口不配口型**的内心独白（短剧高频利器，须短促犀利，严禁与动作同义重复）。
  - `角色名（VO）：` / `旁白（VO）：` —— 跨时空画外旁白、回忆叙述音、信件/新闻播报声（无具名叙述者统一写 `旁白（VO）：`，解析时视为声音通道而非在场实体角色）。
  - `角色名（画外）：` —— 人在门外、走廊或镜头画框外的现场说话声。
  - `角色名（电话音）：` —— 听筒或免提传出的通话声（若需交替拍电话两头，在场头写明 `甲处/乙处（电话交叉）`）。
  - ⛔ **解析红线**：`（OS）`、`（VO）` 必须带圆括号紧贴角色名后，**严禁写成无括号的 `林遥 VO：`、`林遥 OS：`、`内心：` 或用 `人物：`、`主角：` 当说话人**，防止下游分镜与资产清单误生成名为「VO/内心/主角」的幽灵角色。
- **屏幕文字与关键音效**：
  - `【字幕：三年后 · 江城】` / `【花字：反转倒计时 02:00】` / `【系统弹窗：好感度 -50】`
  - `【音效：刺耳的急刹车声，紧接玻璃爆裂声】`
- **时空插入边界**：
  - 回忆、闪回或想象画面必须成对标注 `【闪回起】` 与 `【闪回止】`（或单列闪回场头 `1-3A 教室（闪回） 日 内`），严禁无标记混写导致时空错乱。
