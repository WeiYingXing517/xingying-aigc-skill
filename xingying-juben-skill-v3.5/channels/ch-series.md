# 通道 B：横屏精品剧 / 中长篇网剧专精规则

> **适用范围**：横屏精品网剧、季播类型剧、传统电视剧（单集 `15 ~ 45 分钟`，常见 8~36 集）。
> **核心准则**：多线咬合、人物弧光、场次张弛、中段递进、细节质感。

---

## 一、 阶段 1：多线引擎与人物长弧光设计

### 1. A / B / C 三线咬合架构
中长篇剧集依靠多线并进形成厚度，但严禁各演各的平行水戏：
- **A 线（单集/阶段主引擎，占 55%~65%）**：核心外部危机、案件推进或主事业博弈，提供最强追看抓手。
- **B 线（核心人物关系与情感线，占 25%~30%）**：外部压力投射到核心搭档、伴侣或家庭关系上的信任考验与立场拉扯。
- **C 线（长线暗流 / 配角副线，占 10%~15%）**：跨集埋设的幕后黑手动作或关键配角处境，必须在阶段高潮处与 A 线硬碰撞并改变主线走向。

### 2. 立体人物中长弧光
- **拒绝扁平工具人**：主要角色必须具备「公认的职业/社会体面」与「私下难以启齿的软肋或执念」双重切面。
- **阶段性演变**：规划角色在全剧前段（惯用旧办法应对）、中点（旧办法彻底失效或付出惨痛代价）、后段（打破自我防线做出终极抉择）的三阶变化，每次立场松动必须有重头戏事件支撑。

---

## 二、 阶段 2：分集结构与防中段塌陷法则

### 1. 单集五段式呼吸结构（以 30~45 分钟单集为例）
1. **冷开场（Teaser，1~3 分钟）**：用悬念现场、反常前史切片或上一集危机余震抓人，引出本集核心命题。
2. **第一幕（建置与分兵）**：各线人物接手本集任务，确立明面方案与初步阻碍。
3. **中点（局势扭转 Midpoint）**：原本顺利的调查/合作突然暴露致命破绽，或关键证人反水，迫使主角在下半集冒险换招。
4. **单集高潮（阶段结算）**：完成本集核心交锋，给出明确的阶段性得失（破获子案、赢下一局或关系破裂），绝不整集空转无结果。
5. **跨集尾钩（Tag，最后 1~2 分钟）**：从本集的胜利成果中翻出更棘手的新真相，将期待精准送入下一集。

### 2. 破除「中段注水塌陷」三板斧
当剧集行进至第 4~8 集（精品短剧集）或第 10~20 集（长剧）容易疲软时，强制使用以下三种实质升级，禁止靠误会和巧合拖戏：
- **盟友利益分叉**：外部大敌未除，内部同伴因底线或保护对象不同产生合理路线分裂；
- **筹码代价反转**：前段赖以取胜的核心手段暴露后遗症，每再用一次就离深渊更近一步；
- **时间窗与空间锁死**：撤去退路，将多方势力逼入同一时限或封闭事件中正面碰撞。

### 3. 多线交叉剪辑与「过渡即戏点」规范
- **切线视觉/台词钩连**：上一场末角色提起某份档案，下一场首镜头直接切档案袋被推上另一张办公桌；切回某条线时用正在推进的动作自然接续，严禁站桩复述两场前刚演过的情节。
- **场间过渡三桥（禁时间副词硬切）**：相邻场转换或新人物入场时，默认禁止用「随后 / 不久后 / 转眼」硬接，优先选用 **① 动作桥**（人物带着喘息或手头活计闯入透露状态）、**② 环境空镜桥**（承载时间或压抑氛围的物件/空间扫景）、**③ 画外声音桥**（下一场的敲击/争执声先入耳再切画面）。
- **长线悬念存量**：全剧任意集末保持 `≥ 2 条` 长线未解问题在途，每阶段升级一次对手层级或利益赌注。

## 三、 阶段 3：正文张弛、语速标尺与标准排版

### 1. 语速与单集容量标尺
- **发声语速基准**：`3.5 ~ 4.0 字/秒`（兼顾生活质感、潜台词停顿与重头戏爆发）。
- **单集字数参考**：15 分钟精品剧约 `4200 ~ 5500 字`；30 分钟剧集约 `8500 ~ 11000 字`；45 分钟剧集约 `12000 ~ 15000 字`（具体以脚本估算器计入无词动作时长为准）。
- **重场戏与过场戏配比**：每集打磨 2~3 场 3 分钟以上的重头对手戏（写透试探、交锋、反制与余波），中间穿插 30~60 秒的高效动作过场戏调节呼吸。单句台词默认 `≤ 25 字`。

### 2. 横屏剧集标准分场剧本模板

```text
第 3 集

3-12 市局档案室 夜 内
人物：周凛 许知夏

△ 日光灯管轻微电流嗡鸣。长桌上摊开三卷泛黄的九八年旧卷宗。
△ 许知夏戴着白手套，用放大镜比对末页的签字笔迹。周凛推门进来，将两杯热豆浆放在桌角远端，免得水汽沾湿纸页。

周凛：物证科刚出结果，密封袋上的指纹是近三个月新留的。

△ 许知夏手里的放大镜停住，没有抬头。

许知夏：档案室双人双锁，近三个月只有两个人借阅过。
周凛：名单我看了。排在第一个的是你师父。

△ 许知夏摘下白手套，折成整齐的一叠压在桌沿，这才抬眼看向周凛。

许知夏：所以你是来通知我回避，还是来盯着我替他善后？
周凛：我是来告诉你，明天早上八点督察组进驻之前，这间屋子只有我们俩来过。
```
