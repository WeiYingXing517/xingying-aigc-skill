# 知识检索与采用

先由当前流程和方法确定具体问题、已知事实及锁定项。已有依据足以成稿时直接写。需要专业判断时，先用方法中的条目直链，其次查对应领域索引。只读命中条目和必要关联。

| 当前要判断的内容 | 查阅入口 |
|---|---|
| 景别、角度、构图、轴线、焦点、空间、节奏、成像或光色 | [摄影专项索引](../知识库/摄影与画面/zhi-shi-ku/zong-suo-yin.md) |
| 面部、视线、身体动作、人声、听者反应、声源或拟音 | [人物与声音索引](../知识库/人物与声音/zhi-shi-ku/suo-yin.md) |
| 东方打戏、斗法的镜头任务、运镜、快慢、交会及残留 | [原创分镜案例索引](../知识库/动作与特效/动画案例/索引.md) |
| 交锋、接触、落空、脱手或武器归属 | [武打索引](../知识库/动作与特效/武打/zhi-shi-ku/suo-yin.md) |

| 图像、首尾帧、视频或音频参考能力 | [入口与参考能力](../知识库/生成资料/入口与参考能力.md) |

1. 已知编号时按领域和编号直达正文。武打 A03 和特效 A03 属于不同领域。查术语读基础定义，查具体使用条件读应用。
2. 按条件筛候选。对照本场的素材、人物可知信息、可见范围、空间、时间和已定结果。前提未知就保留未知，碰到硬冲突就排除。候选、例子和别名只提供参考。
3. 以「源镜号｜条目编号｜采用决定」记录实际采用的动作、特效和摄影结论。分镜写观看任务、拍法与关键结果，内部十四项保留执行细节，提示词从中转写。可直接用项目事实处理的缺口按已知关系写，影响锁定内容的实质歧义说明其影响。
4. Markdown 索引可独立使用。需要扩大召回时，按各领域索引提示使用包内检索脚本。脚本返回候选及定位，采用前读正文。

先判断要解决的是拍法、表演、动作连续性还是特效，再用该领域索引或脚本检索。摄影可输入「对峙」「吵架」，武打可用完整动作短句，例如「两个人从两侧夹击主角，主角向左转向」。查看命中理由和使用前提，确认候选是否保留原稿动作与结果。摄影 CLI 只覆盖摄影。脚本返回空时，用领域索引里的术语或编号继续定位。武打候选标为「冲突」时排除，标为「未定」时按原稿或本轮设计核对应条件，再决定是否采用。
