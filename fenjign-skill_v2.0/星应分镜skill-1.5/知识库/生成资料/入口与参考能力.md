# 生成入口与参考能力

参考职责描述素材能够提供的依据。素材类型、数量、标签、时长、画幅、分辨率和声音支持随实际入口变化。相同模型名称也可能对应不同平台或接入方式。是否接受音频参考与是否生成音轨是两种能力。

## 参考类型

| 输入类型 | 可声明的参考职责 |
|---|---|
| 图像参考 | 角色外貌、服装、道具、场地、构图或已确认画风。限定实际需要的对象和可见范围。 |
| 首帧、首尾帧 | 单帧能提供采用瞬间的姿态、构图与接触位置。运动方向与后续变化需要另有依据。 |
| 视频参考 | 场内运动、动作阶段、相机路径或表演节奏。同一视频的不同时段可提供不同参考。 |
| 音频参考 | 已采用音色、发声或声音用途。参考音频和生成音轨的能力分别确认。 |
