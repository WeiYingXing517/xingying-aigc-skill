# 景别

参照：[S03](../../lai-yuan/quan-wei-lai-yuan.md#s03)；本地原方法与用户规则L01/L02；应用综合为L03。参照只覆盖来源登记列明的事实，其他创作选择不是权威定律。知识状态：资料核对与文本组织，未实片验证。

本库提供定义与判断边界，具体裁切和角度以项目约定为准；软件参数只适用所标版本。

<a id="siz01"></a>
## SIZ01 大远景
- 定义与效果：环境占主导，主体很小或仅为位置标记。
- 边界与区分：面部情绪通常不能靠此范围精读。

<a id="siz02"></a>
## SIZ02 远景
- 定义与效果：主体与较广环境关系清楚，人物细节从属。
- 边界与区分：与大远景边界按实际范围写，不以固定距离定义。

<a id="siz03"></a>
## SIZ03 全景
- 定义与效果：人物主要以全身呈现，并保必要活动空间。
- 边界与区分：不意味着人物永远不裁边，动作脚部必要时明确保留。

<a id="siz04"></a>
## SIZ04 中景
- 定义与效果：人物常取头至腰附近，兼顾表情及部分手部关系。
- 边界与区分：坐姿与画幅影响范围，手到桌下不保证可见。

<a id="siz05"></a>
## SIZ05 近景
- 定义与效果：人物常取胸部以上，集中脸部与有限肩部活动。
- 边界与区分：手部未必入画，需同时看手就明写。

<a id="siz06"></a>
## SIZ06 特写
- 定义与效果：面部或物件局部占主要画面，突出特定细节。
- 边界与区分：不等于自动浅景深，物件特写不代表面部可读。

<a id="siz07"></a>
## SIZ07 细节特写
- 定义与效果：更局部的眼、指尖、刻度或接触细节。
- 边界与区分：失去整体关系，需与来源及结果接上。

<a id="siz08"></a>
## SIZ08 中全景与中近景
- 定义与效果：基础景别间的过渡口径，以膝附近或胸腰范围具体约定。
- 边界与区分：不是强制新增每场一套景别，必须给裁切。

<a id="siz09"></a>
## SIZ09 关系范围
- 定义与效果：为容纳多个主体及其距离选择的范围。
- 边界与区分：双人镜不是固定中景，横竖画幅不能同裁。

<a id="siz10"></a>
## SIZ10 动态范围
- 定义与效果：镜内从起始到结束的主体尺寸及可见范围变化。
- 边界与区分：运动中间关键过程也必须可读，不能只起终好看。
