# 空间与调度

参照：[S01](../../lai-yuan/quan-wei-lai-yuan.md#s01)、[S07](../../lai-yuan/quan-wei-lai-yuan.md#s07)、[S08](../../lai-yuan/quan-wei-lai-yuan.md#s08)；本地原方法与用户规则L01/L02；应用综合为L03。参照只覆盖来源登记列明的事实，其他创作选择不是权威定律。知识状态：资料核对与文本组织，未实片验证。

本库提供定义与判断边界，具体裁切和角度以项目约定为准；软件参数只适用所标版本。

<a id="spa01"></a>
## SPA01 场景参照
- 定义与效果：固定地标或声明方向形成可沿用坐标。
- 边界与区分：换机位不改变参照。

<a id="spa02"></a>
## SPA02 身体朝向
- 定义与效果：躯干面向的空间方向。
- 边界与区分：不等于眼睛视线或头部转向。

<a id="spa03"></a>
## SPA03 功能距离
- 定义与效果：能否接触、通行、观察等任务所需关系。
- 边界与区分：能见不等于可达，不必全部写米数。

<a id="spa04"></a>
## SPA04 遮挡关系
- 定义与效果：观察位置、目标部位、遮挡物和阶段共同决定可见性。
- 边界与区分：不笼统写全身看得见。

<a id="spa05"></a>
## SPA05 支撑与接触
- 定义与效果：身体或物件依托何处及接触释放状态。
- 边界与区分：未有动作依据不补具体执行。

<a id="spa06"></a>
## SPA06 通行与占用
- 定义与效果：路线上的可用空间、同时占用及门物件状态。
- 边界与区分：起终合法不代表途中可行。

<a id="spa07"></a>
## SPA07 调度节点
- 定义与效果：触发、起点、经过、停止条件、终点与朝向。
- 边界与区分：不是每个静态对白都必须移动。

<a id="spa08"></a>
## SPA08 持物与动态物件状态
- 定义与效果：手侧、物件位置、开闭和移动结果沿事件延续。
- 边界与区分：不改永久设定，不凭切镜重置。

<a id="spa09"></a>
## SPA09 空间省略与未知
- 定义与效果：未展示或未提供的空间状态。
- 边界与区分：未知不当事实，动作未见完成不自动完成。

<a id="spa10"></a>
## SPA10 观察条件与摄影可见
- 定义与效果：人物视点能见与摄影画面能见分别判断。
- 边界与区分：相机看到不等于角色看到。

<a id="spa11"></a>
## SPA11 战斗空间继承
- 定义与效果：既定攻防位移支撑和终态形成的空间需求。
- 边界与区分：本域只核可行，不另编招式或竞争路线。

<a id="spa12"></a>
## SPA12 空间重建
- 定义与效果：关系变化后用明确覆盖恢复人物与地标位置。
- 边界与区分：不要求每场画图，但复杂场景可俯视示意。
