# 镜头组织

参照：[S01](../../lai-yuan/quan-wei-lai-yuan.md#s01)、[S02](../../lai-yuan/quan-wei-lai-yuan.md#s02)、[S05](../../lai-yuan/quan-wei-lai-yuan.md#s05)、[S06](../../lai-yuan/quan-wei-lai-yuan.md#s06)、[S07](../../lai-yuan/quan-wei-lai-yuan.md#s07)、[S08](../../lai-yuan/quan-wei-lai-yuan.md#s08)、[S09](../../lai-yuan/quan-wei-lai-yuan.md#s09)；本地原方法与用户规则L01/L02；应用综合为L03。参照只覆盖来源登记列明的事实，其他创作选择不是权威定律。知识状态：资料核对与文本组织，未实片验证。

本库提供定义与判断边界，具体裁切和角度以项目约定为准；软件参数只适用所标版本。

<a id="org01"></a>
## ORG01 主镜与关系覆盖
- 定义与效果：在一镜内覆盖场戏主要人物或关键过程，建立可回溯的空间和行动关系。
- 边界与区分：不等于每场强制全景开场，也不一定覆盖整场台词。

<a id="org02"></a>
## ORG02 建立镜头
- 定义与效果：交代地点、地理或关系的功能镜头，景别随所需信息确定。
- 边界与区分：新环境需要信息才使用，不为格式加空镜。

<a id="org03"></a>
## ORG03 重建镜头
- 定义与效果：关系、轴线或地理改变后重新展示新布局的镜头。
- 边界与区分：不是任意远景；必须确实可读变化后的关系。

<a id="org04"></a>
## ORG04 正反打
- 定义与效果：围绕交流或行动关系在相对观察方向间切换。
- 边界与区分：反打不等于把摄影机放到轴线另一侧。

<a id="org05"></a>
## ORG05 过肩镜头 OTS
- 定义与效果：近处人物肩背或部分头部作为前景，拍其面对的另一主体。
- 边界与区分：不是固定景别、不是严格POV、不要求双机；肩不能挡目标脸或关键手。

<a id="org06"></a>
## ORG06 干净单人镜
- 定义与效果：主要呈现一个主体，画面无关系对象的显著肩背遮挡。
- 边界与区分：可暂时突出主体，不自动说明对方不在现场。

<a id="org07"></a>
## ORG07 带前景单人镜
- 定义与效果：画面含另一人物局部以保关系，前景不一定严格为肩。
- 边界与区分：不能与所有前景遮挡混称过肩。

<a id="org08"></a>
## ORG08 双人或多人镜
- 定义与效果：同镜呈现两人或更多主体的关系与必要活动。
- 边界与区分：人数定义不同于景别；多人并不都需面部同样大。

<a id="org09"></a>
## ORG09 反应镜头
- 定义与效果：覆盖已给信息引起且已有依据的反应或状态变化。
- 边界与区分：不能在信息到达前先反应，不能新增表演。

<a id="org10"></a>
## ORG10 插入镜头
- 定义与效果：突出主行动中有信息价值的物件、部位或状态。
- 边界与区分：同一次动作跨镜只发生一次。

<a id="org11"></a>
## ORG11 切出镜头
- 定义与效果：暂离主要行动，展示与本次任务相关的其他信息。
- 边界与区分：不凭空新增事件；不能自动修复跨轴。

<a id="org12"></a>
## ORG12 主观镜头 POV
- 定义与效果：将观察位置和可见范围明确绑定某角色的视点。
- 边界与区分：角色能看见的条件必须成立，过肩不自动等于眼睛视点。

<a id="org13"></a>
## ORG13 客观与受限覆盖
- 定义与效果：不绑定某角色眼位，或仅限制信息范围而非完全模拟其眼睛。
- 边界与区分：受限视角不等于原稿未知可以随意隐藏。

<a id="org14"></a>
## ORG14 动作轴与关系轴
- 定义与效果：由交流双方、移动路径或动作关系建立的方向参照。
- 边界与区分：多人可有主次轴，轴线更新需依据关系变化。

<a id="org15"></a>
## ORG15 屏幕方向与眼线匹配
- 定义与效果：剪接中维持观众可辨的行动方向及人物观察关系。
- 边界与区分：不是要求所有角色机械看相反边。

<a id="org16"></a>
## ORG16 动作匹配剪接
- 定义与效果：跨镜接同一动作的相应阶段，保持方向、手侧与终态。
- 边界与区分：可用时间省略但需明示，不能重复接触。

<a id="org17"></a>
## ORG17 J剪与L剪
- 定义与效果：J为后画面声音先进入，L为前画面声音延续到后画面。
- 边界与区分：只改变声画切换相对点，不篡改原句和已定事件先后。

<a id="org18"></a>
## ORG18 跳切与省略
- 定义与效果：移除时段造成可感跳变，或有依据省略非必要过程。
- 边界与区分：不能省掉必须看懂的因果，也不把未知写成完成。

<a id="org19"></a>
## ORG19 交叉剪接
- 定义与效果：在不同地点或行动线之间组织镜头。
- 边界与区分：是否同时发生必须由输入确定，不由交替形式证明。

<a id="org20"></a>
## ORG20 蒙太奇与匹配转场
- 定义与效果：通过一组选择性画面或形态声音匹配组织时间与关联。
- 边界与区分：不自动新增事件或令不同时间变成连续事实。
