# 人声与台词基础定义

版本0.1.0，本地表演口径，不是声学测量标准。来源与验证范围见[索引](../suo-yin.md)。

<a id="v01"></a>
## V01 交流意图与情绪

定义：交流意图是用话语完成的任务，情绪是当下状态。说“你来了。”可以确认或欢迎，不能只凭文字确定全部心理。

口径：先保留已知任务，再选说法；无依据不新增讽刺或试探。意图与音色身份不同，人物不用换声音才改变表达。例：欢迎可放松连贯，确认可自然收束，须服从实际语境。应用VA01。

<a id="v02"></a>
## V02 重音与清晰度

定义：重音为词句中的相对突出；清晰度为词音可辨程度。重点词清楚不等于已完成强调。

口径：标实际词及其信息作用，再选择必要实现方式，不强制所有强调都提高音量、升调、拖长或加停顿。例：“明天见。”突出“明天”用来区别日期，不能改成每字重读。应用VA04。

<a id="v03"></a>
## V03 音量与力度

定义：音量描述声音大小，力度描述表达中的坚定、松紧或作用感；情绪强度又是另一维。

口径：低音量、力度清楚、句尾短收等可并存；不是低声必虚弱或坚定必喊叫。例：安静场合表达明确要求，声音不大但话不散。已知声线沿用，不能凭低声增加威胁意味。应用VA03。

<a id="v04"></a>
## V04 节奏、停连与气息

定义：节奏是语流的组织；停连决定词段衔接；气息影响可持续发声状态。三者不是标点的自动翻译。

口径：前半句连贯、关键词前必要停顿、句内支撑、渐弱等，按实际任务选择。无音频只给估算。不能一律加吸气、叹气或每词间隙，笑声与完整词句不能无条件同时持续。应用VA02、VA05。

<a id="v05"></a>
## V05 句尾与话轮

定义：句尾含音高走向及收束方式；话轮决定说完、继续、等待或被打断。它们影响听者何时接话，但不决定切镜。

口径：平收、下降短收、柔收、延长、突然截断等按原意组合；问号不固定上扬。例：低声要求可短收等回应，不需改叹号。抢话和重叠需原依据，不能为自然感新增。应用VA03、VA06。

<a id="v06"></a>
## V06 音色、媒介与当下说法

定义：固定音色是身份相关声音特征；媒介是电话、设备、空间等呈现条件；当下说法是本段语气和节奏。三者分别维护。

口径：引用已确认音色，设计必要重音等，媒介交声音呈现。例：同人从平静转高兴可改变节奏和松紧，但不自动换成尖细新声线。无音频不能证明身份音色接续，支持视频参考也不保证支持声音继承。应用CA03。
