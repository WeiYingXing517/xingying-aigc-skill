# 面部与视线基础定义

适用版本0.1.0。以下为本地工作定义，不是人体解剖或情绪识别标准。来源与状态统一见[索引](../suo-yin.md)。

<a id="f01"></a>
## F01 可见形态与情绪目标

定义：情绪目标是希望观众读到的含义；形态是脸上实际能执行、观察的变化。两者需建立本次设计关系，不能相互替代。

口径：区域、方向、程度、张力、开闭与保持。例：“嘴角向两侧上提，面颊随之抬起”，比“喜悦”更可执行；但仅嘴角上提仍不能证明人物真开心。条件是已知角色及表达目标，不以形态诊断未写明心理。

近似区别：“眼神温柔”是效果词，“目光维持对方面部、眼周原有紧张减弱”是候选形态；不能据此宣布唯一温柔公式。风险是方法与目标脱节或更改固定脸型。应用见FA01、FA02。

<a id="f02"></a>
## F02 起态、变化与残留

定义：起态为变化前已有状态；变化为触发后的过程；终态为本段结束状态；残留为后续继续存在的部分。

口径：正在形成、保持、回收、被打断、已经完成。作用是避免切镜重置和重复表演。例：笑意减弱后嘴角仍略上提，下一段应从此开始，不重新笑起。不能因时间经过就认定回收完成，也不强制每段都经历全周期。应用见FA03和CA02。

<a id="f03"></a>
## F03 强度、控制与幅度

定义：内在强度、主动控制、可见幅度是不同变量。强烈情绪可被压住，轻微情绪也可直接显露。

口径：依据原文或已确认要求分别选择；不编数值评分当心理测量。例：“明显兴奋但不能打扰他人”可以主要通过面部和较轻人声表达，不必提高音量。无隐藏意图依据不能加“强装镇定”。区别于固定性格：本段控制不等于角色永远内敛。应用见FA05。

<a id="f04"></a>
## F04 发声中的表情

定义：嘴部在发音中变化，表情可由其他相关部位与句间状态延续。不是固定一个唇形说完整句。

口径：发声前必要松唇、正常发音、眼周面颊保持、句后回收；不逐字规定口型。例：浅笑说话时唇形随语音变化，面颊仍有笑意。持续紧压双唇和正常说话冲突。内心OS只排除逐字口型，不排除剧情需要的嘴部动作。应用见FA06。

<a id="f05"></a>
## F05 视线目标与可见性

定义：视线需指向角色或物体，区别于摄影机方向与主观效果词；可见性决定观众是否能读到已设计信息。

口径：看向对象、转移接点、停留或保持；背面、遮挡、画外是观察限制。例：递物时看交接点再回到对方，不必全程盯脸。视线转移不自动代表心虚。条件是目标可用且与当前行动相容，不能为看清表情擅自加特写。应用见CA06。

<a id="f06"></a>
## F06 时间关系与细节密度

定义：表情的先后、并行与持续是设计关系；细节密度是呈现所需的信息量。精细不等于多部位逐个开关。

口径：收到关键词后连贯变化、同步、稍晚加入、突然收住等；有实际素材才写实测秒数。例：喜悦的嘴角和面颊可协调出现，不必眼、眉、嘴、下颌顺序停顿。简单问候无需微表情串联。风险是过密导致僵硬或超时，替代为保留主要载体。
