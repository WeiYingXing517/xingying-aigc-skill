# 东方玄幻动作与特效原创样例

两例均为原创虚构场面。用于比较人物行动、观看任务、播放速度和特效阶段怎样互相约束。排镜读本例的场戏与镜号决定，转提示词时可对照同镜号的复制块。以下摄影数值、时长、段尾与接缝均为设计值。

- [DF08 一对二｜折光台](#df08)示范三方同时行动、第二方介入、同镜快慢与切宽复位。
- [DF09 两段大战｜沉潮门](#df09)示范多层幻阵的作用位置、两段各 30 秒及段间状态提取。

## DF08 一对二｜折光台

晏澄要把浮起的青白归位盘送回北槽。金色投影镜棱转移盘的导向，紫色投影雾折等待北槽被开启再封槽。三方交锋靠漂移和改变光路推进。南侧看台是机位侧，西侧黑石标、东拱和北槽为世界地标。北槽在画面中后方，镜棱全程由西侧入场，雾折从东拱沿东缘进入。

**场戏基准**　16:9，24fps，冷调写实材质与三维投影混合。上方柔冷天光稳定。归位盘由晏澄腕上的悬浮青环远程牵引，青白圆盘有一条实体感细亮边。镜棱投影有低饱和金色线框，雾折投影有半透明深紫外沿。无字幕、对白、旁白和配乐。

| 源镜／成片秒数 | 人物为何移动及对方怎样响应 | 镜头与特效的决定 |
|---|---|---|
| D08-01／0–6 | 晏澄沿南坡向中台滑行以缩短归位盘到北槽的距离。盘浮起使镜棱从西柱移向黑石标，投出金色导线带偏盘。雾折在东拱看到北槽初亮，沿东缘升到拱上方，等待盘靠近。 | 南侧全景，28 mm、f/5.6，高 2.2 m，俯 8°，固定，前景南坡到北槽可辨。观众先认三条路径。金线穿过黑石标顶后只改变归位盘的移动方向。盘偏西即切跟移。 |
| D08-02／6–14 | 晏澄为恢复导向从中台偏南沿外环低滑到黑石标南沿。镜棱在黑石标抬起金线，沿西弧退到西北标，保持导线对盘的拉引。两方牵引尚未解除，雾折已从东拱上方滑到北槽东沿，见槽口变亮就铺下紫幕。 | 南偏西中全景，35 mm、f/5.6，高 1.5 m，俯 4°。晏澄转向触发摄影机沿南缘向西平行跟移，6–9 秒 1.5× 后恢复 1×。北槽东沿和盘保持同框。雾折紫幕刚触到槽口上缘时切。 |
| D08-03／14–22 | 晏澄停在黑石标南沿，把盘的青线导向北槽正中。镜棱挂在西北标上方保持拉引姿态，雾折在槽东沿把紫幕落到槽口。青线碰到紫幕时，归位盘仍被金线牵住。盘的亮边沿槽口一掠，金线在盘西缘断开，镜棱随即向西标落回，晏澄继续盯住盘。 | 南侧中全景，45 mm、f/8，高 1.8 m，俯 6°。固定焦点在槽口，盘与紫幕接点同清晰。16–18 秒 0.5×，让人看清槽口中点亮芯接触、紫纹沿槽口裂开，晏澄与两投影的微动作同时减速。18 秒金线断开恢复 1×，紫幕碎光落下时切宽。 |
| D08-04／22–30 | 金线已断，晏澄沿西缘滑到北槽南唇，收环让盘落下。镜棱从西北标回西标后稳定，雾折失去紫幕后沿东缘回到东拱。槽口锁定才有一圈青影闭合。 | 南侧全景，32 mm、f/5.6，高 1.8→2.8 m，俯 8°，盘落下后摄影机升高，三方终点同框。常速。尾帧亮环停在北槽石边。 |

**内部十四项取值示范**　以 D08-03 为例。镜号沿用 D08-03。成片 14–22 秒，16–18 秒 0.5×。观看任务为读清两道效果的接点和金线结束。人物沿用黑石标南沿、西北标、北槽东沿三处站位，以盘被牵引到金线断开为动作主轴。南侧中全景、高 1.8 m、俯 6°、45 mm、f/8。起构图让槽口中点与盘西缘可读，固定机位不变焦，焦点在槽口。切出是紫幕已裂、金线消失、盘悬于槽南唇，下一镜切宽接碎光继续坠落。环境受冷天光，短亮芯只照槽沿。无台词。接触响与槽沿亮点同起，断线声在恢复常速时出现。紫纹细碎光继续下落，紫幕主体消失。无画内文字。

## DF09 两段大战｜沉潮门

天上的暗紫大阵压向沉潮门。近层一幅光帆横跨门面，中层数幅连成弧线，远层薄影铺满门后天际。守门的照陵用西柱阵芯释放青色前缘，沿门槛向东接台护住门面。闻铃移动到东接台以对准固定在转座上的导光盘。绛灯负责照亮西柱阵芯，完成后携灯离场。光前缘与阵面交会产生光量变化，人物不会被光抛起或遮没。

**场戏基准**　16:9，24fps，灰蓝石台、天光冷淡，远处深紫光帆为半透明层。镜头处于门南侧，画面左为西柱，画面右为东接台，中间门槛从西到东依次有第一、第二道横向刻槽。照陵灰青长衣，闻铃青黑短衣白肩缀。绛灯深红斗篷、手提橙灯。无字幕、对白、旁白和配乐。

| 源镜／成片秒数 | 人物为何移动及对方怎样响应 | 镜头与特效的决定 |
|---|---|---|
| D09-01／0–10 | 光帆前列压低时，照陵从南阶滑上主印台，闻铃顺东阶上东接台，绛灯举灯从西台内侧到西柱下。三个动作同期，分别指向主印台、东接台、西柱阵芯。 | 南侧大全景，24 mm、f/8，高 6 m，俯 10°。近层帆缘压低触发小幅前移，最终保留三人目的地和三层纵深。西柱橙亮切主印台。 |
| D09-02／10–20 | 绛灯照亮阵芯后，照陵左掌贴印并保持。闻铃在东接台半跪，右手扶导光盘使其朝西。青前缘开始推进时，绛灯从西柱回撤到西拱入口，给从西柱漫出的光路留出空间。 | 南偏西中全景，40 mm、f/6.3，高 1.8 m，俯 6°。左掌贴实触发摄影机沿门槛向东短横移，显出西柱低处向东开出的窄青光前缘。光的实芯贴门槛，薄光晕低于人物膝部。 |
| D09-03／20–30 | 照陵维持左手压印和向东看。闻铃在东接台扶盘，等青缘到位。前缘碰到第一道刻槽上方的近层紫帆下尖，迫近的队列光帆依次停住。绛灯确认西柱芯稳定后熄灯，28 秒从西拱退场。 | 南侧宽中全景，35 mm、f/8，高 2.2 m，俯 8°，固定焦点在门槛，三地标同框。24–26 秒 0.5× 读青白芯贴过第一槽，以及薄紫裂纹向帆顶分开。紫帆下尖脱落恢复 1×。30 秒前缘已越过第一槽，正在向第二槽前进。 |
| D09-04／30–39 | 照陵左掌仍贴印，看到前缘通过第二槽后才抬眼看闻铃，手保持。闻铃仍半跪扶盘，直到前缘抵达东台边缘才开始转盘。 | 同 D09-03 尾帧的南侧构图、焦段、光圈、位置、俯角与焦点。先固定，越过第二槽后向东横移，停在东接台与前缘同框。1×。紫碎光继续沉落，近帆裂面可见。 |
| D09-05／39–51 | 闻铃在接光时将盘转正，把入射光送入东柱。远层紫帆的下缘被东柱抬起的青光分开。照陵见接通才松开左掌并退一步，把主印台让给回流。 | 南偏东中景，50 mm、f/5.6，高 1.4 m，俯 10°，由盘边接点转焦东柱亮边，随后保持。需要读清盘转过的方向和青光的去向。 |
| D09-06／51–60 | 照陵停在主印台南边，闻铃留在东接台，盘退光后松手。两人抬眼看紫帆依次散成远处的淡影。 | 南侧大全景，24 mm、f/8，高 3→7 m，俯 12°。东柱亮边抵门顶后升机位，显出远、中、近帆依次解开。青光敛为门槛细边，收在稳定的门面全景。 |

**内部十四项取值示范**　D09-03 与 D09-04 为相邻源镜，分在两个独立输入。场内位置及屏幕投影由同一个门槛构图锚住。D09-03 的 24–26 秒 0.5× 已退出，30 秒 1× 切出。尾态为青前缘在两道刻槽之间、已通过第一槽、紫碎光仍落，人物在主印台和东接台保持各自姿态。D09-04 成片 30–39 秒、第二段局部 0–9 秒，镜头任务改为读前缘抵达；起景别、机位、焦点与景深继承尾态。固定起拍后，前缘越过第二槽才向东移机。持续冷天光、青线反光和低共鸣随同一时刻延续。均无对白和画内文字。段尾前缘抵达东台边缘，导光盘未接通，下一镜切盘边读转动。绛灯在前段退场，后段没有他参与的事件。
