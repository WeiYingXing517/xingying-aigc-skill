## 场景词与条件参数

[场景词表](chang-jing-ci.json)可直接输入动作句，例如“主角向左转向”“两个角色夹击主角”。命中的动作类型仍须结合原稿确认，原稿未给的结果保留未知。

把已知场面事实写入 JSON 文件，例如 `{"active-contact": true, "locked-result-conflict": false, "weapon-held": null}`，再从武打目录运行 `node jiao-ben/jian-suo.cjs A06 --tiao-jian facts.json`。键值对应当前镜头事实。已确认成立用 `true`，已确认不成立用 `false`，未知用 `null` 或省略。可选的 `--wu-qi` 接受 `unarmed` 或 `rigid-handheld`。必需事实为假或排除事实为真时，该候选标为冲突。

| 条件键 | 判断依据 |
|---|---|
| ability-conflict | 当前关系与已定人物能力冲突 |
| ability-rule-confirmed | 适用的人物能力规则已有依据 |
| active-contact | 当前仍有持续中的接触 |
| free-hand-available | 所需的空闲手可用 |
| grounded-state | 处于条目所需的倒地或地面状态 |
| hand-occupied-conflict | 手部已有占用，与候选冲突 |
| lateral-path-available | 原稿或空间布局确认侧向路径可用 |
| linear-path-available | 原稿或空间布局确认直线路径可用 |
| locked-result-conflict | 候选与已锁定的剧本结果冲突 |
| new-target-perceived | 人物已经感知新目标 |
| path-obstructed | 所需路径存在阻挡 |
| retreat-area-available | 后撤空间可用 |
| third-person-present | 第三人在这一拍已经在场，画外仍算在场 |
| three-person-start-states-known | 三人的位置、朝向和当前动作阶段可定位 |
| three-person-goals-known | 三人各自要完成或阻止的行动均有依据 |
| intervention-route-established | 第三人的移动路径可用，或已有能力规则解释如何到达 |
| three-person-perception-known | 本拍谁已感知、谁尚未感知第三人的介入有依据 |
| support-compatible | 当前身体支撑与条目所需状态相容 |
| weapon-available | 场面中所需器械可用 |
| weapon-held | 当前人物已持有所需器械 |
| weapon-unavailable | 已确认所需器械不可用 |

**CT** 是同一次接触的连续性记录。接触建立时登记对象和状态，跨镜保持时沿用原记录，解除后关闭。该释义依据本包[接触解除](dong-zuo-guo-du.md#a06)和[命中与落空](shen-ti-yu-jie-guo.md#r04)的用法。
