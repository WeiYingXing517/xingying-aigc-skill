# 成片症状诊断

先定位源镜号、成片秒点或段间切缝。对照采用版提示词、实际素材和生成设置。下表给出优先排查的假设。有文字稿时记录可能的风险，有可查看的成片时记录实际偏差。

<a id="director-diagnosis"></a>
## 导演与画面问题的排查顺序

“画面平”先定位具体镜号和观看损失，不直接加推近、换景别或拆镜。只有文字时判断设计风险；有可查看成片时才报告实际偏差。按下列顺序检查，允许多个原因并存，先处理上游依赖：

1. 原稿、原词、揭示与锁定项是否被改；剧情或目标确需变更回[01 场戏依据](../01-剧本理解/流程.md#part-9)，已有事实不清不靠摄影猜出新真相。
2. 空间、动作、接触与素材职责是否成立；设计缺口回[空间方法](../空间基准与调度.md#space-recovery)，绑定冲突回[实际素材绑定](流程.md#part-18)。
3. 本镜必须可见的信息、反应及先后是否读得清；查[03 观看顺序](../03-分镜/流程.md#attention-design)，不因情绪判断隐藏必要结果。
4. 拍法是否支持有依据的观众体验，切镜、停留及运镜是否有观看收益；缺设计回[03 导演决策](../03-分镜/流程.md#director-decision)，获准后只改受影响镜头。
5. 已采用的安排是否在成品文字中遗漏、矛盾或过载；漏写按[04 导演继承](流程.md#director-inheritance)补回，必要摄影参数再核[镜头继承](流程.md#镜头信息继承核对)。

先区分设计缺陷、转写遗漏、素材冲突与成片偏离。文字成立但生成偏离时，依据素材与实际观察修生成输入或设置，不反向篡改原稿和导演目标；没有回跑不宣称效果已经改善。

## 具体症状

| 症状 | 优先核对 | 第一轮修改 | 回跑看什么 |
|---|---|---|---|
| 变速太多或值得强调的节点未判断 | 是否把动作激烈、镜长不足或段预算当播放变速理由，03是否有明确收益 | 回[03速度选择](../03-分镜/流程.md#playback-design)恢复常速基准，仅保少量有效例外；已定漏写查04快慢，不把人物慢动作当慢放 | 普通剧情常速、例外有作用与恢复点、声画可衔接 |
| 关键线索或反应有写但没被看见 | 实际范围、注意力、焦点与显露点；是否只记录入画 | 回[03细节覆盖](../03-分镜/流程.md#detail-coverage)比较原镜调整与插入／特写；保唯一证据，不仅删除不可读细节 | 细节可辨且作用清楚，不提前揭示、不重演动作 |
| 同主体相邻切口微跳 | 比较两镜实际占幅、机位、背景、动作阶段与时间；是否有意省略 | 按[03近似切口](../03-分镜/流程.md#cut-continuity)决定留镜或有效新覆盖，不能硬插无关物件 | 连续关系清楚，正常同景别反打不被误改 |
| 信息都拍到了但重点不清 | 起始重点、次要信息与干扰源是否已定，亮点、焦点及运动是否相互争抢 | 缺设计回03观看顺序，漏写补具体取景与清晰关系，不强叠所有强调手段 | 关键节点是否先读到需要的信息 |
| 镜头变化很多但剧情没推进 | 每次切镜、推拉或停留的新增收益，是否重复同一反应或动作 | 按03导演复核保留有效变化；锁定拍法之外的调整先明确授权范围 | 变化是否带来新的理解、期待或后果，而非只换角度 |
| 只有情绪标签，没有对应画面 | 目标依据与可见证据是否缺失，是否把人物情绪当观众体验 | 在03将目标落实为已有关系、取景和表演的覆盖，再由04转写，不加新剧情或陈设 | 目标是否有画面承载，必要事实是否仍可读 |
| 揭示过早或反应像预知 | 人物与观众知情差、构图和声音是否提前泄露，转移触发是否被压掉 | 事实边界回01，拍法回03，漏写或时间映射回04，保留原词与既定结果 | 信息到达、反应、揭示是否按采用顺序发生 |
| 全景被拉成近景 | 正文是否要求看清当前景别读不到的睫毛、毛孔或微表情，参考帧是否偏近 | 若正文冲突，删减无法读到的细节，保留景别与关键动作 | 构图范围和动作是否都保住 |
| 固定物件自己移动 | 「门框滑走」等句子是否把物件写成运动主体 | 明确摄影机运动，写出物件相对场景的状态和画幅变化 | 构图变化时物件是否仍在原位 |
| 手入画后变成第一人称 | 手的归属或外部摄影机位置是否缺失 | 写清人物、哪只手和摄影机观察方位 | 手的归属和外部视角是否成立 |
| 跨段起身、换手或接触断裂 | 比较前段最后保留帧、A 的尾态、B 的首态及实际参考帧 | 根据已核实的接点修正 B 的开场描述或参考绑定，保留源镜号 | 姿态、持物手和接触关系是否衔接 |
| 反打后像换座或眼线接不上 | 场级基准是否明确，摄影机是否换侧，肩位与目光是否符合当前投影 | 缺设计回 03；漏写走空间继承核对；只改机位不得搬动人物 | 地标关系、双方朝向、肩身份和眼线是否同时成立 |
| 第三人再次出现时换位置 | 最近有效状态、画外期间是否有移动或跳时依据 | 恢复最后有效位置及实际变化，未知不擅补；更新受影响源镜与接入 | 留场者再现是否有可追溯位置和路线 |
| 远处直接碰到或走位穿障碍 | 功能距离、路线占用、障碍和动作阶段是否缺失或冲突 | 回 03 修未锁定站位或合法路径，再转写；锁定冲突先确认 | 到达后才接触，途中通行和身体支撑成立 |
| 换视角后门窗像换墙 | 场景布局版本、参考职责是否冲突，是否把画面左右当固定方位 | 明确固定地标关系与观察方向，核参考绑定；不为新机位重建另一房间 | 不同视点能否对应同一布局 |

空间问题先按[空间信息继承核对](流程.md#space-inheritance)区分上游未设计、转写遗漏或矛盾、素材职责冲突和成片偏离。分别回 03、04 或实际素材绑定处理；文字成立但成片偏离时，不无依据改掉空间基准。

优先调整一个可疑变量，回跑时尽量沿用同一模型、素材和设置。记录偏差、改动和验证结果。未回跑时标为待验证。锁定内容发生冲突时沿用现有局部修改流程。
