# 空间基准与调度

本方法统一管理场内位置与镜头观察关系。03 负责建立和更新，04 负责继承与转写；01 提供原稿事实，02 提供固定布局。采用后随[内部镜头记录](项目交接与恢复.md#内部镜头记录)保存，不另建平行台账。

<a id="space-entry"></a>
## 进入条件与执行范围

做分镜、视频提示词、分镜图方案或分镜图提示词时，先恢复本轮适用的空间基准。涉及人物互动、走位、反打、进出场、遮挡、取放接触或空间揭示时，必须完成对应空间设计与核对，不以是否检索知识库为前提。单人静镜或空镜只记录任务需要的位置、朝向及环境参照，不强造关系轴或移动。

- 新排镜：按[建立空间基准](#space-baseline)先定最小可执行关系，再选机位。
- 已有分镜、直接转提示词：先按[恢复与缺项](#space-recovery)读取已有关系；没有分镜时由 03 在内部完成必要设计，不要求用户重走完整步骤。
- 只出图：恢复源镜选定时刻的位置和摄影机状态，仅推导当帧可见内容，不为构图重排人物。
- 局部修改：区分改机位、改走位与改布局，只更新受影响状态及其依赖，核到后续重新一致。

导演选择按[03 导演决策](03-分镜/流程.md#director-decision)确定观众怎样观看；本方法规定站位、通路、距离和观察侧的可执行边界。先恢复空间再筛拍法，目标缺口回03，不在空间记录中另造情绪处方。摄影变化只重算投影，不为表达效果擅改人物位置；合法调度获准变化后，更新同一空间状态，再核[观看顺序](03-分镜/流程.md#attention-design)与下游[导演继承](04-提示词/流程.md#director-inheritance)。

## 建立空间基准

先对照当前要求、原稿、已采用资产与镜头。每项区分原稿或已确认事实、本轮执行设计、未知，注明来源及适用场次或镜号。冲突先核范围与版本，不能为了画面好看覆盖已采用事实。

按本场实际需要保存以下内容，简单场景几行即可，多人交叉或复杂路线可用站位表或俯视示意，不强制坐标和米数：

| 层次 | 最低需要明确的内容 |
|---|---|
| 场景固定关系 | 采用的场景资产与布局版本；能区分方位的固定地标或声明方向；关键区域、通路、障碍、支撑面及必要高低差。地标之间要有相对关系，不能只列物件名。 |
| 人物与物件初态 | 每个行动参与者及影响后续关系的留场者相对地标的位置、站坐或支撑、身体朝向；头与视线目标另记；关键物件位置、持有和接触。 |
| 功能距离 | 当前能否直接接触、是否隔桌或有阻挡、是否需要先走近；只在任务需要且有依据时用数值。 |
| 交流或行动关系 | 当前主要互动对象或运动方向。需要正反打或连续运动方向时，明确轴线由谁与谁或哪条路线形成，并用场内地标命名观察侧及适用阶段。多人不强套同一条轴。 |
| 必要变化 | 事件要求的进出、接近、转身、绕行、位移终点及触发。已定动作和结果由事件或专项决定，本方法核空间可行，不另编招式。 |

原稿没有具体左右而任务必须定站位时，03 可在不改变剧情、揭示、锁定拍法和素材职责的前提下作最小执行设计，并记录为设计值。优先利用已有地标、最短可行通路和稳定交流关系，不为丰富画面强加绕桌、起立、门墙或障碍。接触距离不能满足时先核必要接近或未锁定站位；只有观察遮挡问题才调整合法机位，移机不改变真实接触距离。不得靠切镜制造隔空接触。确需改变锁定内容或存在实质歧义时再集中确认。

<a id="space-transition"></a>
## 沿事件更新空间状态

每镜从同一采用版状态切入：继承起态，落实本镜实际变化，再保存切出状态和来源镜号。静态信息可引用场级基准，逐镜记录变化，不重复抄整份布局。

1. 移动写清触发、起点、必要经过方向、停止条件、终点与切出时朝向；运动中切镜则保留已到达地标和未完成阶段。核路线占用、障碍与接触距离，不能只看起终点合法。
2. 原地转头、转身、移步分别更新。人物转身不等于位移；摄影机环绕不等于人物转身。人物实际走位改变关系时，更新对应轴线和后续观察侧。
3. 出画、被遮挡、离开场地分开记录。没有位移或时间省略依据时保留最后已定位置；画外留场者仍在内部记录中，不因当前镜头或生成段没拍到而删除。
4. 隔镜再出现，从最近有效状态加上期间已有变化推导。明确跳时或缺少位置依据时保留未知，不硬认原位，也不无因补成新位；影响本镜执行时按恢复规则处理。
5. 接触、释放、持物、门椅移动和特效落点同步更新相关位置、通路及遮挡。武打或特效采用的位移与作用范围写回本记录，不另造竞争路线。

<a id="space-projection"></a>
## 从场内关系推导画面

先确定摄影机相对地标的位置与朝向、机位高度和俯仰，再推导当前画面左右、前后景、裁切与遮挡。机位必须能够观察目标且路径可行；不能为实现矛盾的构图挪动锁定人物或穿越实体。

- 场内方位用固定地标或明确朝向的身体参照；画面方位必须注明是本机位所见。人物手侧按本人身体辨认。
- 双人反打明确互动双方、轴线的地标参照侧、从谁哪侧肩后看谁、肩的画面侧及主体视线目标。仅写“同侧轴线”“沿用原轴线”而未能定位原轴线及观察侧，不算完成。
- 换机位后重算投影，不机械保住所有画面左右，也不把左右交换自动判成站位改变。核人物朝向、目光和地标关系是否共同支持该投影。
- 走位改变轴线或摄影机确需换侧时，按采用拍法交代可读的关系变化；可用连续移机或必要的关系覆盖，不因本方法强插全景，也不把任意插入镜当作完成重建。
- 画外但承担视线、声源、接触或即将入画的人物，保留本镜需要的场内位置；不把未知或不可见状态写成画面可见事实。

概念不清查 [SPA01 场景参照](../知识库/摄影与画面/zhuan-xiang/kong-jian-yu-diao-du/ji-chu-ding-yi-ku.md#spa01)、[SPA03 功能距离](../知识库/摄影与画面/zhuan-xiang/kong-jian-yu-diao-du/ji-chu-ding-yi-ku.md#spa03)；过肩、换侧与多人覆盖分别查 [ORG-A02](../知识库/摄影与画面/zhuan-xiang/jing-tou-zu-zhi/ying-yong-chang-jing-ku.md#org-a02)、[ORG-A05](../知识库/摄影与画面/zhuan-xiang/jing-tou-zu-zhi/ying-yong-chang-jing-ku.md#org-a05)、[ORG-A06](../知识库/摄影与画面/zhuan-xiang/jing-tou-zu-zhi/ying-yong-chang-jing-ku.md#org-a06)、[ORG-A07](../知识库/摄影与画面/zhuan-xiang/jing-tou-zu-zhi/ying-yong-chang-jing-ku.md#org-a07)。读取以当前疑问为限。

<a id="space-check"></a>
## 交付前的空间核对

逐镜核以下适用项，再沿全场人物变化检查隔镜再出现的状态；局部改动只沿实际依赖检查：

- 起态能否追到场级基准或前一有效状态？人物无因换位、转向或离场了吗？
- 场内位置、摄影机位置和所写画面投影是否一致？过肩身份、视线目标、遮挡和裁切是否成立？
- 接触前距离是否可达，途中是否可通行，必要身体或物件是否有支撑？
- 本镜实际变化是否已写入切出状态，后续是否继续而非重启？画外留场者是否仍可恢复？
- 每个独立生成块是否写齐本块必要空间依据，不能只写“同上”“延续上一段”？换场或跳时是否区分新基准与真实延续项？

没有完成适用项时，回缺失的空间设计或转写位置补齐，不以“注意站位一致”的口号替代。交付文字可以简短，但涉及互动的人物必须能确定场内位置、身体朝向和任务所需距离；当前机位的左右与纵深写在构图中。纯画外且不影响本次执行的状态不必塞进成品，但内部保留。

<a id="space-recovery"></a>
## 恢复与缺项

先读与当前采用稿版本相符的场级基准和源镜状态。记录缺失时，从用户指定或已采用稿、参考职责与明确动作恢复；不得从单个近景的画面左右倒推出整场唯一布局。只缺普通执行细节时由 03 按最小设计补入本轮内部记录，04 随后转写，不在转写时逐镜另猜。会改变锁定关系的冲突先确认，尚未解决的部分标待核，不把冲突方案当作可直接执行的成品。

实际成片与计划不同，先分清文本缺陷、素材职责冲突或成片偏离；采用实际终态须有可查看依据及相应授权，计划与实测分开。保存和恢复继续使用[项目交接与恢复](项目交接与恢复.md)。
