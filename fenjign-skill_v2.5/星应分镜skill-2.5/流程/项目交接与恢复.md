# 项目交接与恢复

需要跨会话续做或管理多稿时，在已确定且可写的项目目录保存 `采用版.md`。有现行项目记录时复用其位置和格式。实际稿件和内部镜头记录独立保存，入口登记当前采用版本、适用范围、锁定例外和待处理事项。项目目录未确定或无法写入时，在本轮保留设计依据。需要跨会话交接时说明尚未落盘，用户要求保存或交接内容时提供可直接保存的记录。

## 记录格式

按集、场或用户指定范围记录。路径以项目目录为基准。不同范围采用不同版本时分别列行。

| 步骤 | 范围 | 采用稿相对路径及版本 | 关键锁定、依赖或待处理项 |
|---|---|---|---|
| 01 剧本与基准 | 第 03 场 | 剧本/第03场-v04.md | 9:16、AI 生成、二维手绘质感 |
| 02 资产 | 第 03 场 | 资产/资产表-v03.md | P003 使用参考图 v2，详细职责见资产表 |
| 03 分镜 | 第 03 场 | 分镜/第03场-v05.md | S07 + S08 合为 S07，切出点锁定 |
| 04 提示词 | 第 03 场第 1 段 | 提示词/第03场-B-v02.md | 基于分镜 v05、资产表 v03，第 2 段待确认 |
| 内部镜头记录 | 第 03 场 | 分镜/第03场-内部镜头-v05.md | 对应分镜 v05、资产表 v03、B v02 的已采用分组 |

示例路径按项目实际情况替换。资产号、镜号、源镜对应和详细锁定状态随正式稿保存。

## 内部镜头记录

采用或锁定分镜、提示词时，将本轮已定的设计和分组依据写入项目记录，并在 `采用版.md` 登记路径、版本及适用范围。记录头部注明对应的剧本与制作条件、资产、分镜版本和已有的 A/B 稿版本。已有完整分镜表时可引用其中对应的十四项，补记该表之外的采用决定、时长预算和分段映射。

| 记录对象 | 按采用范围保存 |
|---|---|
| 场次与导演目标 | 保存01对应事件的观众理解、知情与揭示边界、适用体验目标及依据；明确事实、推断与本轮表达设计。按[03 导演决策](03-分镜/流程.md#director-decision)采用，不另建方案台账。 |
| 源镜号与导演决定 | 记录关联事件号、观看任务、起始重点及可见证据、必要转移触发与后续重点、限制信息及切出收益。关键拍法保留采用理由、相关条目和确有取舍的替代限制；执行细节引用本镜十四项，不重复抄录。 |
| 场次与空间基准 | 按[空间基准与调度](空间基准与调度.md#space-baseline)保存场景资产与布局版本、地标关系、人物初始位置与身体朝向、功能距离、适用轴线及地标参照侧。区分原稿事实、执行设计与未知，注明来源和范围。复用本内部记录，不另建平行台账。 |
| 源镜号与空间变化 | 保存切入依据、实际走位与转向、切出位置和朝向、接触与通路变化，以及由该机位推导的投影。未变项引用基准或前一有效状态；画外留场者保留最后有效状态和来源镜号，直至有实际变化或未知依据。 |
| 源镜号 | [内部十四项](03-分镜/流程.md#视频转写前的内部十四项)中的有效信息、镜号发生变更时的源镜对应及锁定状态。已定摄影参数保留数值与单位。未定项标明依据缺口。 |
| 源镜号与条目 | 已采用的条目或案例编号、解决的问题及具体采用决定。可以直接由项目事实得到的决定，记录对应事实和已选做法。 |
| 源镜号与时长 | 采用镜长与单位、必要过程和实际并行关系、可压缩节拍及其余量依据、锁定秒点与变速接点。估算标为计划，已检验的实测单列。 |
| A/B 稿版本与独立段号 | 分组所含源镜、生成总长、局部保留区间和成片区间、采用的压缩和换算。记录最终可复制块中切出状态的对应镜号、保留点及计划或实测来源，保留后续仍需复用的人物、空间、持物、动作、声音、光和特效余态。 |

内部记录用于续做。场级常速基准可记一次，仅对[03采用的少量速度例外](03-分镜/流程.md#playback-design)补作用、进入／结束事件、后接速度、声音处理及生成／后期职责，不逐镜制造变速理由。细节插入保存源事件、切入动作阶段、主行动是否继续与接回状态；近似切口保存采用的构图差异、连续或省略关系，均附在上述源镜记录，不另建台账。恢复时同时恢复这些决定，未知理由不补造，04不得因分段重启速度、重复动作或丢掉细节镜。

对话里按用户要求交付分镜、提示词或其他成品，内部十四项仅在明确要求时展示。

## 保存与恢复

1. 用户明确采用、锁定或授权定稿时，先保存对应稿件及适用的内部记录并核对路径，再更新该范围的采用记录。试稿、备选和待审稿独立保存。
2. 续做时先定位项目及范围，读取采用记录，再加载本轮所需的稿件和版本相符的内部镜头记录。先恢复本场导演目标与揭示边界、匹配布局版本的场级空间基准，再按源镜号恢复观看重点、转移触发、关键采用理由及最近有效位置、朝向、关系轴、拍法、采用依据和锁定时长；画外或隔镜人物不能只看紧邻上一镜。按独立段号和提示词版本恢复分组与尾态。用户本轮明确指定的文件优先用于指定范围。仅有更新的文件名或修改时间时，继续按采用记录恢复。
3. 记录缺失、引用无法读取或同范围存在冲突时，先从可核的采用稿恢复已写明的镜头信息与尾态。空间记录缺失时按[恢复与缺项](空间基准与调度.md#space-recovery)从可核稿件恢复，普通缺项由 03 内部补最小设计，不能逐镜另猜；有时间省略而位置不明时保留未知。导演理由缺失时只恢复稿中明确的任务和可见安排，不推断作者心理或因此重排；影响执行的缺项回03补本轮决定，再经[04 导演继承](04-提示词/流程.md#director-inheritance)核对。采用依据、可压缩余量或实测数据缺失时标记待核，按本轮实际需要补查。只确认影响当前任务的版本或锁定项。能从用户明确指定的稿件恢复时，可据此建立采用记录。
4. 上游更新后，按事件号、资产号、源镜号和范围标记受影响的导演决定、内部记录及下游稿待复核。目标或揭示变化由01交03，03更新观看顺序及拍法后再传04；仅转写漏项不反向改导演目标。局部调整沿信息依赖与空间接缝检查到重新一致，不无因重排全场。有多个分组版本时，按本次分组和最终提示词版本读取对应尾态。04B 的生成时间调整记在 B 稿及其分组记录，继续引用 03 的采用镜号和镜长。用户确认变更分镜后，再更新 03 对应范围。
