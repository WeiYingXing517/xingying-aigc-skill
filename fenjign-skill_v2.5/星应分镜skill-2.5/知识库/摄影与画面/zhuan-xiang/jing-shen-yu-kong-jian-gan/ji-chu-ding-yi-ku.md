# 景深与空间感

参照：[S13](../../lai-yuan/quan-wei-lai-yuan.md#s13)、[S14](../../lai-yuan/quan-wei-lai-yuan.md#s14)、[S15](../../lai-yuan/quan-wei-lai-yuan.md#s15)；本地原方法与用户规则L01/L02；应用综合为L03。参照只覆盖来源登记列明的事实，其他创作选择不是权威定律。知识状态：资料核对与文本组织，未实片验证。

本库提供定义与判断边界，具体裁切和角度以项目约定为准；软件参数只适用所标版本。

<a id="dep01"></a>
## DEP01 对焦平面与清晰范围
- 定义与效果：理想对焦位置附近存在按观看标准可接受清晰的范围。
- 边界与区分：不能将所有距离目标无条件同时最清楚。

<a id="dep02"></a>
## DEP02 景深
- 定义与效果：物方可接受清晰的距离范围。
- 边界与区分：依画幅、光圈、距离、放大率和观看标准，定义不提供统一米数。

<a id="dep03"></a>
## DEP03 浅景深与深景深
- 定义与效果：相对窄或宽的可接受清晰范围。
- 边界与区分：不是情绪模板，也不等于画面一定更有层次。

<a id="dep04"></a>
## DEP04 光圈与清晰范围
- 定义与效果：其他条件相同时收小光圈一般增加景深。
- 边界与区分：实拍同时影响曝光，软件或生成不一定相同联动。

<a id="dep05"></a>
## DEP05 主体背景间距
- 定义与效果：主体与背景在空间中的分离条件。
- 边界与区分：背景越远不代表需要隐藏的所有信息都可无条件消失。

<a id="dep06"></a>
## DEP06 散景
- 定义与效果：焦外区域的形态与视觉质感。
- 边界与区分：与景深宽窄不同，散景好坏带审美与镜头条件。

<a id="dep07"></a>
## DEP07 必须清楚与可辨识
- 定义与效果：前者需读细节，后者仅需认身份、位置或进入。
- 边界与区分：可辨识不是完全失去信息。

<a id="dep08"></a>
## DEP08 焦点交接
- 定义与效果：注意力与对焦目标随已有信息转移。
- 边界与区分：起止清楚不证明转换中不漏动作。

<a id="dep09"></a>
## DEP09 深焦构图与分阶段清晰
- 定义与效果：多距离同时可读或各阶段不同目标可读。
- 边界与区分：不把分阶段先后写成全部全程最清楚。

<a id="dep10"></a>
## DEP10 分焦镜或合成选择
- 定义与效果：用特殊光学或合成获得不同清晰关系。
- 边界与区分：需明确制作或风格授权，不是普通深景深默认工具。

<a id="dep11"></a>
## DEP11 遮挡与层次
- 定义与效果：既有物件的重叠给前后关系与深度线索。
- 边界与区分：不新造前景、不用模糊挡住关键接触。

<a id="dep12"></a>
## DEP12 视差与尺度关系
- 定义与效果：机位移动时不同距离投影变化、大小和位置关系提供深度线索。
- 边界与区分：固定机位变焦与横移视差不同。
