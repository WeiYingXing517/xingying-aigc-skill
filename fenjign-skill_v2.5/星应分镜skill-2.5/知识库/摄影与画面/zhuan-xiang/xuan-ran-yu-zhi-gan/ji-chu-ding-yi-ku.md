# 渲染与质感

参照：[S16](../../lai-yuan/quan-wei-lai-yuan.md#s16)、[S17](../../lai-yuan/quan-wei-lai-yuan.md#s17)、[S18](../../lai-yuan/quan-wei-lai-yuan.md#s18)；本地原方法与用户规则L01/L02；应用综合为L03。参照只覆盖来源登记列明的事实，其他创作选择不是权威定律。知识状态：资料核对与文本组织，未实片验证。

本库提供定义与判断边界，具体裁切和角度以项目约定为准；软件参数只适用所标版本。

<a id="ren01"></a>
## REN01 视觉呈现风格
- 定义与效果：写实、绘制、卡通或其他已给表现方式的整体约束。
- 边界与区分：未给不自行指定，不能只用一词当全部执行说明。

<a id="ren02"></a>
## REN02 表面材质
- 定义与效果：表面对光及纹理的呈现条件。
- 边界与区分：不为好看改产品真实材质。

<a id="ren03"></a>
## REN03 粗糙度与反射
- 定义与效果：粗糙程度影响反射扩散与高光形态。
- 边界与区分：不等于所有材质更亮就更高级，软件数值需对应模型。

<a id="ren04"></a>
## REN04 金属与非金属
- 定义与效果：不同反射特性的材质类别。
- 边界与区分：金属不必镜面，塑料不因亮就金属。

<a id="ren05"></a>
## REN05 基础色与光照色
- 定义与效果：物体固有表面色信息与照明及显示共同形成画面色。
- 边界与区分：不可拿彩灯改产品身份颜色。

<a id="ren06"></a>
## REN06 次表面散射
- 定义与效果：光进入表面后散射再离开的效应，可影响皮肤等外观。
- 边界与区分：不等于皮肤都应蜡质发光，软件参数非通用。

<a id="ren07"></a>
## REN07 纹理与法线凹凸
- 定义与效果：表面图案与微几何表现。
- 边界与区分：凹凸图不一定改变真实轮廓，不随镜头随机增加伤痕。

<a id="ren08"></a>
## REN08 透明 折射与反射
- 定义与效果：透过、偏折或反射环境的不同可见现象。
- 边界与区分：玻璃不能既完全不影响视线又任意反射未知人。

<a id="ren09"></a>
## REN09 高光溢出与眩光
- 定义与效果：亮部散射或光学现象的呈现。
- 边界与区分：不自动添加，不可遮字与面部关键信息。

<a id="ren10"></a>
## REN10 胶片感与颗粒
- 定义与效果：可包含颗粒、色调响应和其他已指定视觉特性。
- 边界与区分：不是强黄滤镜，不同胶片及处理条件不一。

<a id="ren11"></a>
## REN11 风格化明暗与描边
- 定义与效果：按既定风格简化明暗分区或轮廓。
- 边界与区分：不等于几何与接触不必一致。

<a id="ren12"></a>
## REN12 时序质感一致性
- 定义与效果：相邻镜或运动中纹理、反射与身份稳定。
- 边界与区分：生成闪烁需区分执行偏差与设计本身。
