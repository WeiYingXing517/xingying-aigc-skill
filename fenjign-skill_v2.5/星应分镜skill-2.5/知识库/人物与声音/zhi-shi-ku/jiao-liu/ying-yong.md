# 交流与连续性应用场景

版本0.1.0，有条件创作候选，未做媒体验证。来源见[索引](../suo-yin.md)。

<a id="ca01"></a>
## CA01 关键词触发倾听反应

- 条件与目标：能定位角色获得信息的实际词段，反应不能提前。
- 候选与理由：此前保持关注，听清必要词后开始对应变化；可在整句结束前发生，避免统一句后反应。
- 配合：不要求每句点头，也不要求听者全脸冻结。
- 排除与替代：电话可听范围或OS归属未知时先保留关键缺口；原剧情有预料可另设计准备状态。
- 正反例：“未被录用”需收到足以判断的信息，不在只听到“录用”字样就欢喜；凭观众字幕提前反应为反例。关联C01。

<a id="ca02"></a>
## CA02 说听双方跨镜保持

- 条件与目标：连续时间、无重置依据，双方均有已有终态。
- 候选与理由：分别继承表情、视线、手物、未完动作与话轮，只有新信息才转变。
- 配合：听者不自动准备开口，说话者不重复起句；画外过程仅按有依据设计继续。
- 排除与替代：回放、时间省略另标关系，不把重复观察当第二次事件。
- 正反例：已有浅笑与持杯保持；切镜后中性、空手或重复惊讶为反例。关联C02。

<a id="ca03"></a>
## CA03 同句跨生成单元

- 条件与目标：制作边界切开同一句，无剧情停顿。
- 候选与理由：前段最后词、后段剩余词、句内语调气息、面部残留与未完动作逐一对应；直接续说。
- 配合：听者状态也承接，固定音色不变，不自动插入吸气闭唇。
- 排除与替代：实际前段演错不能自动锁定，先说明修前段或接受变化。无音频只交设计，不承诺声学无缝。
- 正反例：前段“我真的很高兴”，后段只说“你能来。”；重播或重起调为反例。关联C03、V06。

<a id="ca04"></a>
## CA04 已知时间省略

- 条件与目标：原稿明确经过时间或转场，需保持可解释的变化而非机械冻结。
- 候选与理由：列已知完成和仍未定项目，按已有事件更新；经过时间本身不自动完成所有动作或情绪回收。
- 配合：有后续依据时改变姿态、表情与语气；无依据不新增做过的事。
- 排除与替代：连续同句不能套省略；关键状态未知时局部确认。
- 正反例：“稍后，已收好文件”可更新归属；只写“稍后”就凭空关门收包为反例。关联C02、C03。

<a id="ca05"></a>
## CA05 同段协调与有据反差

- 条件与目标：身体、面部、人声需合成同一过程，或明确有内外反差。
- 候选与理由：共享触发，保留必要同步和先后；若无掩饰依据，修正面部已放松而声音全程紧绷等冲突。
- 配合：笑意由眼周面颊维持，嘴正常发音；动作与对白按原并行。
- 排除与替代：不擅造“其实害怕”解释所有不一致；原文明示掩饰时不得强行让全部通道都开心。
- 正反例：统一过程但有合理分工；脸、声、动作各自重新启动为反例。关联C04、FA06。

<a id="ca06"></a>
## CA06 关键面部变化不可见

- 条件与目标：已有镜头背面或遮挡，关键含义依赖不可见面部细节。
- 候选与理由：说明该细节无法承担已展示信息；在原授权表达内选择可见身体或可听说法，或向分镜提出需要看到的变化。
- 配合：不自行加特写、转身或夸张动作；没有必要身体变化时可只提出呈现需求。
- 排除与替代：成片观察不能编出遮挡后的五官变化；创作可以设计但标非已展示。
- 正反例：说明“需让观众辨认笑意形成”，由分镜决定呈现；直接宣称背面看见眼周微笑为反例。关联C06、F05。
