# 新项目启动与参考选择

用于新建剧本项目、从新小说启动改编，以及用户主动要求重新确定创作方向。续写、单项提取、审稿和局部修改复用当前项目依据。用户明确要求直接出稿时，采用已给条件和可逆的工作假设，仍需核实用户指定且对交付有影响的参考。

## 1. 确认创作需求

新项目缺题材或作品形式时，主动给出创作需求选项。先确认作品形式，再问影响创作的缺项。作品形式和题材分别记录，例如「短剧」和「都市悬疑」。用户已经给出的信息直接带入。一句话能补齐的字段可放同一轮，当前任务的缺项补齐后就进入参考选择。

| 作品形式 | 可按需询问的内容 |
|---|---|
| 短剧 | 子题材、时代与地点、核心处境、目标平台或横竖版、集数与单集时长 |
| 电影／短片 | 子题材、时代与地点、核心处境、目标片长 |
| 电视剧 | 子题材、故事背景、目标集数与单集时长、主要人物线 |
| 广告脚本 | 产品或服务、受众、传播目标、渠道、成片时长和必须传达的信息 |

仅询问会影响本次产物的字段。小说改编同时记录已提供素材范围和必须保留的锚点，具体处理见 [小说改编](adaptation.md)。创作背景或目标时长由用户授权补充时，明确为工作假设。

## 2. 选择文风与节奏

题材和基本体量明确后，按 [研究](research.md) 进行候选级检索。能独立进行的文风与节奏候选检索可并行。候选级检索确认作品真实、与任务匹配、可取得的材料范围，以及能够支持哪些简短观察。用户已有指定参考时，直接带入并核实。用户明确只要方向选项或将对标留到下一轮时，先交相应选项，具体作品的检索留在约定阶段。

**小说文风卡。** 提供两到三个有据、同子题材或叙事语域相近的作家或作品选项。有多少可信候选就列多少。每项写清作家、具体作品、适用理由、可查来源和对白方面的可参考特征。优先说明人物如何开口、如何接话、面对不同关系怎样改变表达，以及何时用动作或停顿承接。用户可选一个参考或其中几项特征，也可自带参考或跳过。仅提炼抽象的文风和对白习惯。参考作品中的人物、设定、情节、原句及独特表达不进入新稿。额外的文风参考与用户指定改编原著分别记录。

**节奏与对标卡。** 提供符合当前题材与时长的节奏方向，说明各方向的信息密度、回报间隔和张弛，例如悬疑短剧可选择快速抛出疑点、稳步推进线索或慢燃关系。先索引同形式、同子题材、体量相近的作品，再提供可查的对标候选。短剧优先检索有公开热度证据的同类作品。候选说明作品、平台及版本、匹配依据、热度口径和可分析片段。证据不足时注明同类参考或缺口。用户可选一部主要对标、自带参考或跳过。按 [分集与节奏](episodes.md) 区分短剧的集内和集间节奏、电影的全片张弛、电视剧的阶段推进，以及广告的信息出现次序和时长配比。

节奏卡固定显示以下说明。

> **对标作品仅供节奏参考。人物、设定、台词、桥段、事件链及有辨识度的情节组合均由本项目独立创作。**

客户端支持交互选项时使用该能力，同时保留直接填写。仅支持文本时，用简短编号选项和示例回复。用户已经回答的选项不重复弹出。没有可靠候选时提供可确认的风格方向，用户可补链接、样本或跳过。可访问资料不足时注明实际可见范围，核查状态留待补。

## 3. 确认后核查，再进入创作

本次需要的文风与节奏选择确定后，先阅读或观看实际可得的所选材料，再写所请求的产物。用户只选方向且仍想挑作品时，先提供可核候选供选择。用户明确委托选作品时，在已确认方向内选择并说明来源。用户选择只用方向或跳过时，按已确认的抽象偏好写作。只取得简介、预告、片段或字幕时，按实际证据限制观察和时间定位。已确认且仍适用的研究依据可以复用。

将结果整理为简短的项目依据：创作需求和约束、文风来源及对白写法、节奏来源及抽象参数、实际覆盖范围和待核项。按 [项目状态](project.md) 区分候选、已确认、已查和待查，沿用会话或约定项目目录。只改文风时复核人物声音和相关对白，只改节奏时复核分集或场次。写对白继续先核知情与接话，再用文风规则调整声音。交付范围依用户目标，必要时按 [审稿](review.md) 复核相似性和本项目原创因果。
