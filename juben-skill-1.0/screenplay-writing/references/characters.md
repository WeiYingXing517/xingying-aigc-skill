# 人物卡、关系与小传

适用于从创意、小说、大纲或剧本建立人物卡，从已有材料提取小传，深化人物或设计指定关系。以一份人物记录支持各项交付，按任务选择字段。来源、有效状态和故事时点遵循 [项目与事实](project.md)。

## 确定人物与补充范围

- 用户指定名单时按其范围。未指定且任务是全篇人物卡或主要人物小传时，沿关键事件检查谁行动、施压、帮助、阻拦、隐瞒或传递信息，或实际改变转折与结局。低频但有实质作用的角色应收录，背景群众按需要简述。
- 复用当前姓名、别名、人物 ID 与关系设定。按 `C001` 形式分配新人物 ID。只有材料明确同一身份时合并别名，可能同名或身份尚未揭示时保留原有区分。
- 提取任务只整理可核对信息，合理推断注明依据。未知的年龄、经历、动机、声音等标明未提供或待补。授权创作时可补有剧情用途的细节并标明来源，涉及受保护的身份、关系和结局时遵循用户边界。

## 人物卡字段

主要人物详写，功能性角色围绕其作用简写。内部以人物 ID 关联事件、关系和场次，交付使用用户所需的角色名称与格式。

| 字段 | 写法 |
| --- | --- |
| 身份与当前处境 | 姓名、称谓、相关身份、此刻面临的问题。按需记录不同年龄阶段和身份变化 |
| 剧情作用与关键经历 | 人物如何推动、阻碍或改变关键事件，哪些经历影响当前判断与选择。需要时引用事件 ID |
| 诉求与行动依据 | 想得到、保住、回避或承担什么，为什么。写通常关注的线索、理解偏差、压力下的应对和会改变决定的条件 |
| 能力与认知边界 | 能做什么、有什么资源与权限、知道或相信什么、通过何种渠道得知。具体认知状态引用项目记录 |
| 关系与选择 | 与谁存在信任、利益、责任、依赖或冲突，这些条件如何改变表达、判断和行动 |
| 表达与声音 | 记录人物先注意或先问什么、表达有多直接、面对不同对象或压力时怎样开口、回避或改口。已有用户认可的台词可作声线参考。纯提取时，材料未给出的习惯留待补。需要配音或小传时写年龄感、音区、质感、吐字、语速及辨识特点，提取缺失时如实注明 |
| 变化方向 | 在什么条件下成长、退缩、坚守或显露原本倾向，保留已有选择与结局边界 |

角色可以主动、被迫或由他人和事件牵引。让行为与角色当前处境、认知和限制相符。通过行动、表达和选择形成差异，避免把创伤、口头禅、成长弧或职业刻板印象设成必填条件。

项目选定小说文风后，用[参考核查](research.md)得到的抽象对白观察完善人物的关注点、直接程度及不同关系下的说话方式。结合该角色的身份与经历形成差异；用户认可的项目台词和既定关系继续作为直接依据。

## 关系与小传专项

- **关系。** 用双方人物 ID 引用同一关系。分别说明双方的诉求、认知、信任、表达边界和实际影响。允许不对称、同时合作与对抗，以及多方共同资源或约束。说明什么条件会改变关系，具体的触发事件由 [大纲](outline.md) 组织。
- **小传。** 从有效人物卡组织身份、经历、关系、剧情作用和声音。按故事时点核对年龄、称谓、关键经历和跨阶段声音变化。对外宣传稿按用户指定的剧透边界取材。
- **局部修改。** 更新相关人物和关系字段，定位依赖该人物能力、认知或选择的事件及场次。出现两套依据时记录冲突与实际影响，按 [项目与事实](project.md) 处理有效版本。

交付前用关键事件核对收录范围、行为依据、主要角色差异及角色认知边界。已成稿的人物行动、对白或关系变化需要回修时查 [审稿](review.md)。
