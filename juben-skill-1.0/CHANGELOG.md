# 变更日志

## 1.2.0

- 加入同功能参考片段对照、现场与行动连贯检查，以及对白当下用途检查。修订后再做观众顺读。
- 新增[场景与参考对照回归](tests/场景与参考对照回归.md)。

## 1.1.1

- 完整剧本交稿前增加观众视角顺读，按成稿可见可听信息区分悬念、留白和理解断点，修订后回读受影响段落。
- 新增[观众顺读回归](tests/观众顺读回归.md)。

## 1.1.0

- 新增新项目选项卡，依次处理创作需求、小说文风、节奏与对标。用户选定后查证样本再写作。
- 按短剧、电影／短片、电视剧及广告分别提炼节奏。作家参考只进入抽象表达规则，作品对标仅供节奏参考。
- 增加[选项卡与参考回归](tests/选项卡与参考回归.md)。

## 1.0.1

- 新增对白分步回修，先查知情来源和接话，再修人物声线与口语。
- 新增 [对白回归样本](tests/对白回归.md)。

## 1.0.0

- 将旧剧本创作 Agent 的 41 项保留职责归并进 `screenplay-writing`，共用创作入口，按任务读取专项参考。
- 增加小说改编流程，支持章节覆盖、关键改编取舍、原文与集场的追溯，以及长篇分批处理。
- 支持独立交付全剧大纲、人物卡、分集大纲、场次蓝图和剧本正文，以及对应专项审稿和局部修订。
- 移除分集资产拆解和资产确认。场次的出场名单和用于故事连续性的关键道具状态纳入正文与审稿。
- 增加项目续写、确认和结构兼容规范，以及维护流程和合成回归样本。

已执行检查见 [验收记录](tests/验收记录.md)。后续按 [回归规范](tests/回归规范.md) 复跑。
