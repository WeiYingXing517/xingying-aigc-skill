**剧本创作 2.0 · 星应分镜 3.0 · Three.js 白模导演台**

从故事点子、小说章节或已有剧本出发，写成能演的戏，拆成有观看重点的镜头，再把关键镜头摆进可编辑的三维场景。三个 Skill 都可以独立使用。

## 🎥 制作流程

    故事点子／小说／已有稿件
        ↓
    剧本创作 2.0 ── 大纲、分集、场次蓝图、剧本正文
        ↓
    星应分镜 3.0 ── 理解剧本 → 核对资产 → 导演排镜 → 提示词交付
        ↓
    白模导演台 ── 复现关键镜头的站位、机位和首帧构图

遇到多人换位、越肩反打或狭窄场景走位，可以在正式出图或生成视频前，先用白模检查人物、道具和摄影机的位置，再回到分镜确认拍法。

## ✍️ 剧本创作 Skill 2.0

从零创作、小说改编、接稿续写和局部改稿走不同路线。可以交付完整剧本，也可以单独做人物卡、梗概、分集、场次蓝图或专项审稿。

[查看剧本创作 Skill](./juben-skill-2.0/screenplay-writing/SKILL.md)

| 输入 | 创作流程 | 交付物 |
| --- | --- | --- |
| 一句话创意 | 明确作品形式与目标 → 建立人物与冲突 → 排事件与起伏 → 分集或拆场 → 写正文并顺读 | 人物卡、大纲或剧本 |
| 小说原文 | 核对范围 → 标出必保人物、关系和事件 → 确定改编取舍 → 调整结构与篇幅 | 改编大纲、场次蓝图或正文 |
| 已有大纲 | 核对因果、人物动机与篇幅 → 补齐缺口 → 写指定范围 | 指定集大纲、场次蓝图或正文 |
| 待审稿件 | 定位场次 → 核对前情、人物反应和对白 → 局部回修 → 检查后续影响 | 审稿意见、修订稿或续写 |

- **人物反应有来路。** 区分作者、人物和观众掌握的信息，按角色实际知道的事和当下目的写反应与对白。
- **钩子、进展和回报贯穿大纲到正文。** 大纲建立期待，分集安排推进与收尾，正文通过行动或结果兑现铺垫。
- **按作品形式调整结构。** 短剧看集末落点，电影和短片看全片段落与余韵，电视剧兼顾单集与阶段人物线，广告围绕传播目标和总时长。
- **改稿可以精确到一场戏。** 核对人物视角、情绪反应、对白和后续影响，专项审稿时给出问题位置与最小修订条件。

## 🎞️ 星应分镜 Skill 3.0

先确定观众此刻需要看懂什么，再用动作、道具、站位、视线、焦点和切镜把信息拍出来。

[查看星应分镜 Skill](./星应分镜skill3.0/SKILL.md)

| 步骤 | 实际工作 | 交付或记录 |
| --- | --- | --- |
| 开工核对 | 核对项目、集场段、采用稿、进度与阻塞 | 采用材料、制作条件和范围 |
| 剧本理解 | 拆解事件、人物状态和场次任务，决定信息何时揭示 | 场戏理解与状态依据 |
| 资产清单 | 梳理角色、场景与道具，核对参考图、版本与用途 | 资产清单与采用素材 |
| 导演排镜 | 建立空间基准，设计站位、走位、视线、机位与切点 | 双栏简版、十四项完整分镜或分镜图选帧 |
| 提示词交付 | 转写镜头、动作、声音与参考素材 | 分镜图提示词、连续或独立分段视频提示词 |
| 交付核对 | 回查原文、素材和源镜，核对段间动作与空间状态 | 可续做和局部修订的项目记录 |

- **先明确观看任务，再选拍法。** 认出一个人、发现手机上的信息和等待答复，对应的画面重点不同。
- **控制信息什么时候入画。** 例如这一镜只拍余川抬眼、右手停住拧瓶盖，扫码留到指定镜头。
- **把空间和状态接起来。** 逐镜追踪朝向、持物与动作阶段，核对前段尾态、后段承接描述和入画起态。
- **提示词继承已定镜头。** 核对机位、高度、运镜、焦点和声音归属，成片偏离时定位到对应镜头修订。
- **换对话也能接着做。** 从项目记录恢复采用版本、已完成范围和待处理项。

## 🧱 白模 Skill · Three.js 导演台

把参考图或已定分镜落实到可编辑的三维场景，检查人物距离、道具遮挡、视线方向与摄影机取景。

[查看白模 Skill](./baimo-skill/SKILL.md)

    确认参考图、分镜或已有工程
      → 选择场景白模、分镜起始白模或局部修改
      → 搭建或复用场景，设置对象和摄影机
      → 保存镜头并实际打开核对
      → 检查导出的 PNG，交付可编辑工程

| 工作模式 | 实际工作 | 交付物 |
| --- | --- | --- |
| 场景白模 | 搭建筑、家具和主要物件，匹配参考视角，注明看不到的空间和尺寸假设 | 可编辑场景与参考视角 |
| 分镜起始白模 | 复用场景，按源镜布置站位、朝向、姿态、持物和机位 | 默认每个源镜一张起始构图图 |
| 局部修改 | 载入工程与镜头，调整指定对象、机位或构图 | 更新后的工程及 PNG |

- **观察相机和拍摄相机独立。** 从侧面检查遮挡，再切回拍摄机位查看构图。
- **镜头和摆位一起保存。** 记录源镜号、版本、拍摄相机与对象起始状态。
- **交付可以打开核查。** 提供导演台入口、可载入的 `project.json` 和实际导出的 PNG，也可指定其他关键帧继续预演。

## 🎬 一场校园戏，三套 Skill 怎么接力

以「军训休息时，林清瑶找余川加联系方式，集合哨打断谈话」为例。

1. **编剧**交付分场正文，写清林清瑶如何开口、余川如何从意外转为简短应答，以及集合哨打断的时机。
2. **分镜**安排先让观众看见谁、余川何时停住拧瓶盖，以及扫码时两部手机怎样依次入画。逐镜延续左手水瓶、右手手机和双方视线。
3. **白模**预演扫码的越肩镜头，检查前景肩膀是否挡住屏幕、两人的距离是否自然，再保存工程与首帧构图。
