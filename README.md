# AIGC 视频创作 Skills

一套面向 **AI 视频全链路制作**的 Skills，覆盖剧本创作、资产规划、分镜设计、视频生成提示词与白模预演。可以从一个创意开始，也可以带着已有剧本或分镜，从对应环节接着做。

**剧本 → 资产清单 → 双栏分镜 → 分段视频提示词**

需要制作分镜图或白模预演时，将审定后的双栏分镜展开为 **14 栏完整分镜**。

## 剧本 Skill

[剧本 Skill v1.5](juben-skill-1.5/) 聚焦爽点的铺垫与兑现，以及人物如何通过选择和行动调动观众情绪。创作时先确定观众在期待什么，再安排人物如何加深期待，最后通过行动、揭晓或反转收回铺垫。

为避免大纲信息直接进入人物对白，创作时区分三个视角：

| 视角 | 要明确的问题 |
| --- | --- |
| 作者 | 故事的因果是什么？哪里铺垫，哪里兑现？ |
| 人物 | 角色此刻知道什么、相信什么？以他的处境和目的，会怎么说、怎么做？ |
| 观众 | 观众目前知道什么、期待什么？什么时候应该知道真相？ |

1. **确定题材、文风和节奏。** 信息不足时，Skill 会补问关键设定。可以提供参考作品，也可以让 Skill 推荐文风与节奏参考。
2. **制作人物卡和故事大纲。** 明确人物动机、关系与冲突，并在大纲里安排关键爽点及其铺垫。
3. **输出剧本。** 长篇可以先做分集大纲再逐集写，方便核对节奏与承接。也可以直接写正文，快速看一版效果。

## 分镜 Skill

[分镜 Skill v2.5](fenjign-skill_v2.5/) 将剧本理解、资产整理、镜头设计和提示词转译拆成独立步骤。每一步集中处理当前需要判断的信息，沿用前一步确认的设定和约束，便于高效产出、审阅与修改。

1. **理解剧本，确定分镜方向。** 明确题材、情绪和节奏，它们会影响景别、切镜和镜头停留时间。比如，可以要求「惊悚、快节奏，优先保留推动信息变化的镜头」。
2. **列出资产清单并绑定参考。** 梳理角色、场景和道具。可以用生图 Skill 或其他 AI 工具制作图片，再交给智能体绑定到对应资产，供分镜和提示词引用。
3. **先审双栏分镜，按需展开为 14 栏。** 核对画面内容、景别、动作和时长。如需制作分镜图、分镜白模、白模预演或其他依赖完整镜头信息的交付，再展开为 14 栏完整分镜。仅转视频提示词时，可以直接用审定后的双栏分镜。
4. **转成分段视频提示词。** 先确认分镜对应的提示词，再选择分段方式。选项决定每段的目标时长和镜头如何归组。即使选择指定时长，也可能在合适的叙事节点提前结束，以免靠重复动作或拉长停顿硬凑秒数。

## 白模 Skill

完成 **14 栏分镜**后，使用 [白模 Skill](baimo-skill/) 在正式出图或生成视频前检查构图、空间和动作衔接。

1. **分镜白模**：按镜头搭出角色站位、景别和构图。
2. **空间白模**：搭出场景空间，检查人物、道具和机位的相对位置。
3. **白模预演**：按镜头顺序查看走位、动作和切镜，提前发现单张分镜图里不容易看出的衔接问题。
