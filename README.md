## 🔥 核心硬核优势：为什么流程这么简单，出片效果还好？

1. **流程极简，开箱即用不折腾**
   - **轻量单场免建档**：单场/单段短剧情直接开写，不强制建目录和复杂配置文件；需要做多集长剧时再一键开启建档。
   - **缺项主动弹卡确认**：片型、画幅、主色调、分段秒数等关键规格由星应主动给选项，点选即定；支持中途随时插话提观感建议（如「太拖」「不够爽」「气场弱」），自动冻结未改区并追平下游。
2. **彻底解决「视频接缝」与「跳切」问题**
   - **段间强承接**：多段视频提示词在【场景空间与开场站位】后强制生成【上一段承接点】，写透 0 秒人物姿态、手部持物、语气状态与跨段进场，杜绝上一段左手拿杯、下一段突然变右手或人物瞬移。
   - **切口连续性校验**：排镜阶段自动执行《近似切口检查》与《持续动作覆盖》，区分「反打」与「无意同景别跳切」，保证切镜顺滑自然。
3. **锁死「空间站位」与「视线轴线」，复杂戏直接 3D 排雷**
   - **场级空间基准贯穿始终**：01 提事实 → 02 定布局 → 03 设计站位/走位/朝向 → 04 继承转写，人物出画也不丢位置状态，绝不无因换边或反打眼线错位。
   - **白模导演台实景验证**：多人换位、狭窄空间或越肩镜头怕遮挡？直接在内置 Three.js 导演台摆出人物与双机位，确认构图后再导出首帧 PNG 喂给生图/视频模型。
4. **长项目管理「不断流、不失忆」**
   - **跨对话无缝恢复**：长剧模式通过 G0–G5 门禁与 `项目.json` 管理集场段进度、采用稿版本、真实资产图 ID 绑定，以及人物下线/受伤/场景损毁的变更传播；换新对话也能秒接上。
   - **双层防失忆机制**：剧本 3.5 采用 `03_handoff_state.md` 滑窗续写（不重读全书防上下文爆炸）；分镜 4.0 每轮顶部固定输出一行进度锚点，写几十集依然稳如首场。
5. **专业级「构图、光影、分镜运镜」与声画控制**
   - **镜头语言可观测、可执行**：拒绝用「氛围感」「震撼」等空洞情绪词堆砌，双栏分镜第一版起即写清机位高度、俯仰角度、焦段/景深、主色调与光影变化；只用「观看任务 + 可见证据」决定怎么拍。
   - **内置动作与节奏知识库**：涵盖打斗拆招、特效、三式速度坡道（常速/慢镜/提速物理参照），让 AI 视频真正动得起来、打得清楚。
   - **防漂移与成片诊断**：角色声纹锁只在块首绑定一次并禁止声波文字入画；默认常规资产/纯文字直出（不强索首尾帧）；若成片仍出现全景变近景、道具漂移等跑偏，直接走《成片症状诊断》精准定位到具体镜号修改。

### 🌟 分镜 4.0 十大硬核亮点

1. **轻量单场 + 长剧双模式自由切换：** 单场短片免建复杂目录，发剧情直接排镜出词；多集长剧自动启用 `项目.json` 与 `项目管理.cjs` 跨对话恢复，换对话也不丢进度、不猜采用稿。
2. **每轮顶部进度锚点 + 中途插话不断流：** 每轮最上方固定输出一行 `【星应进度锚点】` 防多轮失忆；审稿途中随时吐槽或局部改戏，自动触发《中途建议与局部修订专册》，把口语建议转译为物理视听动作，并同步追平**时间码、空间战损、手部持物、内部十四项、下段承接**五条链路。
3. **十四项唯一母稿直转，告别双套失真：** 不再维护两套容易打架的提示词稿，04 直接以「内部十四项」为唯一母稿转写；双栏简版从第一版起即写清机位高度、俯仰与焦段/景深。
4. **段间接缝强承接（专治视频断档）：** 续段在【场景空间与开场站位】后自动填写【上一段承接点】，写透 0 秒人物开场姿态、持物与语气，禁写过去动词并交代跨段新增人物进场；剪辑转场术语进复制块必转为可见物理画面。
5. **场级空间基准 + 持续动作与切口检查：** 01 提事实 → 02 定布局 → 03 定站位/走位/视线 → 04 继承转写，人物出画也不丢位置；排镜自动检查《持续动作覆盖》《细节覆盖》与《近似切口检查》，避免无意同景别跳切与画面微跳。
6. **默认常规资产直出 + 声纹锁防文字入画：** 全流程默认常规资产或纯文字直出，绝不强索首尾帧（仅用户主动要求时启用）；角色声纹锁只在 04 块首绑定一次并明写禁声波图形或文字入画，缺状态图时智能走纯文字锁或「正常图+文字补状态」不死锁。
7. **文风锁与可观测写法（弱模型也稳）：** 内置《文风锁与黄金样板》与《可观测写法》，边说边动同步、主语与声源归属明确，杜绝用抽象形容词糊弄、也杜绝机械重复人名。
8. **12 大摄影专项 + 武打特效 + 声音表演知识库：** 内置构图、光线、机位角度、景别、景深空间感、色彩、运镜焦点、时间节奏（含三式速度坡道与物理参照）、武打拆招、动画案例与人物表演声音库，并配检索 CLI 按需调用。
9. **成片症状诊断，哪里偏修哪里：** 实际生成的视频如果出现全景变近景、道具漂移、视角错误或节奏软绵，直接对照《成片症状诊断》反查对应镜号与修改点，无需推倒重写。
10. **自带自动化验收测试套件：** 配备 `检索.test.cjs`、`链路.test.cjs`、`项目一致性.test.cjs` 与基线清单，保障整套分镜规则与工具链长期稳定可靠。

## 🧱 白模 Skill · Three.js 导演台（可选扩展 · 按需使用）

> **📌 使用说明：** 本 Skill **可不参与主流程使用**，日常使用「剧本 3.5 + 分镜 4.0」即可完成全套创作与视频提示词交付。**本工具专为「白模生成视频」爱好者，以及想在生图/生视频前提前用 3D 验证复杂站位与遮挡的创作者提供，大家按需取用。**

把参考图或已定分镜直接落实到可编辑的三维场景，低成本排查人物距离、道具遮挡、视线方向与摄影机取景。

[查看白模 Skill](./baimo-skill/SKILL.md)

```text
确认参考图、分镜或已有工程
  → 选择「场景白模」「分镜起始白模」或「局部修改」
  → 搭建或复用场景，布置人物、道具与摄影机
  → 导演台实际打开核对，保存镜头与状态
  → 导出干净 PNG 首帧，交付可编辑 project.json 工程
```

| 工作模式 | 实际工作 | 交付物 |
| :--- | :--- | :--- |
| **场景白模** | 搭建筑、家具和主要物件，匹配参考视角，注明隐藏空间和尺寸假设 | 可编辑场景与参考视角 |
| **分镜起始白模** | 复用场景，按源镜布置站位、朝向、起始姿态、持物和拍摄机位 | 默认每个源镜一张起始构图 PNG |
| **局部修改** | 载入工程与镜头，仅调整授权对象、机位或构图 | 更新后的 `project.json` 及 PNG |

- **零外部 CDN 依赖：** 模板内置 Three.js r180 源码，本地直接打开即可稳定运行。
- **观察相机与拍摄相机独立：** 从侧视/顶视检查穿帮与遮挡，再切回拍摄机位查看实际取景，导出 PNG 自动隐藏网格与辅助线。
- **可继续编辑与复盘：** 镜头参数与对象状态一起存入 `project.json`，支持随时微调再导出。
