# 色彩

参照：[S18](../../lai-yuan/quan-wei-lai-yuan.md#s18)、[S21](../../lai-yuan/quan-wei-lai-yuan.md#s21)；本地原方法与用户规则L01/L02；应用综合为L03。参照只覆盖来源登记列明的事实，其他创作选择不是权威定律。知识状态：资料核对与文本组织，未实片验证。

本库提供定义与判断边界，具体裁切和角度以项目约定为准；软件参数只适用所标版本。

<a id="col01"></a>
## COL01 色相
- 定义与效果：颜色类别的描述。
- 边界与区分：名称不是精确显示值，需具体参考才谈色准。

<a id="col02"></a>
## COL02 明度与亮度
- 定义与效果：视觉明暗与物理亮度等概念有不同测量口径。
- 边界与区分：分镜可用相对明暗，不混称实测照度。

<a id="col03"></a>
## COL03 饱和度
- 定义与效果：颜色鲜明程度的相关描述。
- 边界与区分：降低饱和不自动更高级或更悲伤。

<a id="col04"></a>
## COL04 冷暖关系
- 定义与效果：在上下文中相对冷暖的颜色组织。
- 边界与区分：不是固定情绪结论，源光色温也不等同最终画面感受。

<a id="col05"></a>
## COL05 参考主色调
- 定义与效果：一场戏的整体色彩参照范围。
- 边界与区分：不要求每镜和每物都同色，不覆盖来源与本色。

<a id="col06"></a>
## COL06 局部色彩重点
- 定义与效果：用已有颜色在画面中强调任务对象。
- 边界与区分：不能随意改关键物件身份色。

<a id="col07"></a>
## COL07 本色与光色
- 定义与效果：表面属性与照射条件共同影响可见颜色。
- 边界与区分：红衣在冷光下不表示衣服换款。

<a id="col08"></a>
## COL08 白平衡
- 定义与效果：拍摄或处理对中性参照的解释。
- 边界与区分：不是每镜用来随意改场景光。

<a id="col09"></a>
## COL09 颜色对比与分离
- 定义与效果：色相明暗饱和等差异支持主体辨识。
- 边界与区分：不能只有色差而不核实际可读。

<a id="col10"></a>
## COL10 色彩管理与显示转换
- 定义与效果：管理不同设备文件和显示条件的一致性。
- 边界与区分：ACES或LUT不是自动创作风格，也不等于所有设备完全一样。

<a id="col11"></a>
## COL11 画面匹配与合理差异
- 定义与效果：相邻镜保持物体身份与基准，允许来源位置变化。
- 边界与区分：不同机位正常局部变化不等于跳色。

<a id="col12"></a>
## COL12 单色或限色风格
- 定义与效果：已指定的受限色彩呈现。
- 边界与区分：不能删除剧情必须识别的颜色而不确认。
