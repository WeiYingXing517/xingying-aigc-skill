# 构图

参照：[S21](../../lai-yuan/quan-wei-lai-yuan.md#s21)、[S02](../../lai-yuan/quan-wei-lai-yuan.md#s02)；本地原方法与用户规则L01/L02；应用综合为L03。参照只覆盖来源登记列明的事实，其他创作选择不是权威定律。知识状态：资料核对与文本组织，未实片验证。

本库提供定义与判断边界，具体裁切和角度以项目约定为准；软件参数只适用所标版本。

<a id="cmp01"></a>
## CMP01 中心构图 原G01
- 定义与效果：主体或关系围绕画面中心组织。
- 边界与区分：可服务正视或稳定，不因中心自动判呆板。

<a id="cmp02"></a>
## CMP02 三分与偏置 原G02
- 定义与效果：借三分区域或偏置安排主体与辅助信息。
- 边界与区分：不是固定网格坐标义务，不为三分裁掉关键手。

<a id="cmp03"></a>
## CMP03 对称 原G03
- 定义与效果：已有画面结构在轴两侧形成近似对应。
- 边界与区分：不对称场景不能造建筑或人物。

<a id="cmp04"></a>
## CMP04 引导线 原G04
- 定义与效果：既有边缘路径形成指向主体的信息路径。
- 边界与区分：不把线条心理效应当普遍事实。

<a id="cmp05"></a>
## CMP05 框景 原G05
- 定义与效果：已有开口或边缘围合被拍主体。
- 边界与区分：不能加门窗树枝，不能遮关键过程。

<a id="cmp06"></a>
## CMP06 层次分组 原G06
- 定义与效果：按已有前后位置与关系组织主体主次。
- 边界与区分：不是每镜必须三层，更不是越多越好。

<a id="cmp07"></a>
## CMP07 留白 原G07
- 定义与效果：为已有视线、运动、关系或已定文字保区域。
- 边界与区分：留白不是新增眼神、路线或文案授权。

<a id="cmp08"></a>
## CMP08 清晰重心 原G08
- 定义与效果：用可读性与明暗等既定条件区分主要和辅助信息。
- 边界与区分：浅景深不是唯一手段，关键辅助信息仍需辨认。

<a id="cmp09"></a>
## CMP09 头部空间与裁切
- 定义与效果：头顶留量和身体切口按具体范围设计。
- 边界与区分：固定百分比不普适；碰巧裁关节需核动作意义。

<a id="cmp10"></a>
## CMP10 肩前景构图
- 定义与效果：肩头作为空间联系，主体大小及遮挡范围受控。
- 边界与区分：过肩不要求固定比例，也不必肩清楚。

<a id="cmp11"></a>
## CMP11 动态重心
- 定义与效果：主次与位置随主体及相机变化调整。
- 边界与区分：起始位置不是全程硬锁。

<a id="cmp12"></a>
## CMP12 文字空间与画幅
- 定义与效果：为已给实体字、字幕或后期文案安排可读区域。
- 边界与区分：不主动加字，安全区由实际平台确定，不能编统一百分比。
