# 机位与角度

参照：[S01](../../lai-yuan/quan-wei-lai-yuan.md#s01)、[S02](../../lai-yuan/quan-wei-lai-yuan.md#s02)；本地原方法与用户规则L01/L02；应用综合为L03。参照只覆盖来源登记列明的事实，其他创作选择不是权威定律。知识状态：资料核对与文本组织，未实片验证。

本库提供定义与判断边界，具体裁切和角度以项目约定为准；软件参数只适用所标版本。

<a id="ang01"></a>
## ANG01 水平正面
- 定义与效果：从主体正面方向观察，项目方位角记0°。
- 边界与区分：不等于角色必须直视镜头。

<a id="ang02"></a>
## ANG02 斜侧与四分之三
- 定义与效果：介于正面与纯侧面的方向，具体写左／右及角度。
- 边界与区分：不存在所有人物都最佳的固定45°。

<a id="ang03"></a>
## ANG03 纯侧面
- 定义与效果：主体侧方约90°方向。
- 边界与区分：可能遮掉另一侧手或面部，需核关键细节。

<a id="ang04"></a>
## ANG04 背面
- 定义与效果：主体背部方向约180°，可拍背部及其面向环境。
- 边界与区分：不是自动角色POV。

<a id="ang05"></a>
## ANG05 俯拍
- 定义与效果：光轴向下，项目约定负俯仰值。
- 边界与区分：不自动表达弱势，也不等同无人机或顶拍。

<a id="ang06"></a>
## ANG06 仰拍
- 定义与效果：光轴向上，项目约定正俯仰值。
- 边界与区分：正常高低差不需特殊心理理由。

<a id="ang07"></a>
## ANG07 平拍
- 定义与效果：光轴近水平，项目设计记0°。
- 边界与区分：相机可以高于主体某部位；对准点必须兼容。

<a id="ang08"></a>
## ANG08 顶拍与近垂直观察
- 定义与效果：镜头主要从上方观看平面或空间关系。
- 边界与区分：需有上方视线空间与明确角度，不凭顶拍露出原不可知信息。

<a id="ang09"></a>
## ANG09 滚转与倾斜
- 定义与效果：摄影机绕光轴旋转，使画面水平参照倾斜。
- 边界与区分：区别俯仰和水平侧拍；默认0°，需理由再用。

<a id="ang10"></a>
## ANG10 观察位置与对准点
- 定义与效果：相机所在空间和光轴目标分别描述。
- 边界与区分：方位角不是机位坐标，不同距离同角度画面不同。

<a id="ang11"></a>
## ANG11 相对角与世界参照
- 定义与效果：相对主体角度随其朝向变化；世界参照固定在场景。
- 边界与区分：主体转身不证明相机转动。

<a id="ang12"></a>
## ANG12 眼线与拍摄侧
- 定义与效果：视线目标及相机位于关系轴哪侧共同决定画面方向。
- 边界与区分：近景或过肩名称不能证明匹配。
