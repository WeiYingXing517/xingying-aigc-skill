# 运镜与焦点

参照：[S04](../../lai-yuan/quan-wei-lai-yuan.md#s04)、[S12](../../lai-yuan/quan-wei-lai-yuan.md#s12)、[S15](../../lai-yuan/quan-wei-lai-yuan.md#s15)；本地原方法与用户规则L01/L02；应用综合为L03。参照只覆盖来源登记列明的事实，其他创作选择不是权威定律。知识状态：资料核对与文本组织，未实片验证。

本库提供定义与判断边界，具体裁切和角度以项目约定为准；软件参数只适用所标版本。

<a id="mov01"></a>
## MOV01 固定 MOV原M01
- 定义与效果：相机位置与朝向保持，允许主体在框内活动。
- 边界与区分：固定不等于画面没有变化。

<a id="mov02"></a>
## MOV02 水平摇摄 MOV原M02
- 定义与效果：相机主要原位水平转向。
- 边界与区分：不是横移，不自动改变摄影机空间位置。

<a id="mov03"></a>
## MOV03 俯仰摇摄
- 定义与效果：相机原位上下转向。
- 边界与区分：与机位升降不同。

<a id="mov04"></a>
## MOV04 横移 MOV原M03
- 定义与效果：机位沿横向路径移动，前后景相对位置可能变化。
- 边界与区分：有实体通行条件，不只写从左到右。

<a id="mov05"></a>
## MOV05 推近 MOV原M04
- 定义与效果：机位向目标靠近，取景与透视关系随路径变化。
- 边界与区分：不等同变焦，不因紧张必推。

<a id="mov06"></a>
## MOV06 拉远 MOV原M05
- 定义与效果：机位远离目标，扩大关系或露出新信息。
- 边界与区分：无信息不自动代表舒缓。

<a id="mov07"></a>
## MOV07 跟随 MOV原M06
- 定义与效果：机位随已有主体移动以保持必要覆盖。
- 边界与区分：人物路线不是为跟随任意改写。

<a id="mov08"></a>
## MOV08 环绕 MOV原M07
- 定义与效果：围绕既定主体或关系移动观察方向。
- 边界与区分：角度更新、轴线和路径需要全程明确。

<a id="mov09"></a>
## MOV09 升降
- 定义与效果：相机位置垂直变化，可同时调整朝向。
- 边界与区分：不等于光轴上下转，不自动需要航拍设备。

<a id="mov10"></a>
## MOV10 变焦 MOV原M09
- 定义与效果：改变镜头焦距以改变视角和取景范围。
- 边界与区分：相机未移位时透视视点不因此变成推近。

<a id="mov11"></a>
## MOV11 焦点转换 MOV原M08
- 定义与效果：在既有画面内改变对焦目标或距离。
- 边界与区分：不是机位移动，也不保证所有过程清楚。

<a id="mov12"></a>
## MOV12 手持与稳定运动
- 定义与效果：手持允许受控身体微动，稳定运动强调平顺轨迹。
- 边界与区分：手持不必强抖，稳定器不授权穿障碍。

<a id="mov13"></a>
## MOV13 甩镜
- 定义与效果：快速转向产生过渡模糊的表现。
- 边界与区分：未展示关系的模糊不自动解决跨轴或瞬移。

<a id="mov14"></a>
## MOV14 推拉变焦组合
- 定义与效果：位移和反向变焦配合改变背景关系与主体大小。
- 边界与区分：强烈效果需明确依据，普通对话不默认。

<a id="mov15"></a>
## MOV15 运动段与停留段
- 定义与效果：信息进入、运动完成和结果辨识的不同时间区间。
- 边界与区分：运动结束后须按任务留必要读清时间。
