# 音源与音效

参照：[S05](../../lai-yuan/quan-wei-lai-yuan.md#s05)、[S19](../../lai-yuan/quan-wei-lai-yuan.md#s19)、[S20](../../lai-yuan/quan-wei-lai-yuan.md#s20)；本地原方法与用户规则L01/L02；应用综合为L03。参照只覆盖来源登记列明的事实，其他创作选择不是权威定律。知识状态：资料核对与文本组织，未实片验证。

本库提供定义与判断边界，具体裁切和角度以项目约定为准；软件参数只适用所标版本。

<a id="snd01"></a>
## SND01 原始音源
- 定义与效果：实际产生声音的人或物。
- 边界与区分：画面拍谁不改变谁发声。

<a id="snd02"></a>
## SND02 播放载体
- 定义与效果：电话音箱等传播或播放原声音的媒介。
- 边界与区分：载体位置不同于远端说话人位置。

<a id="snd03"></a>
## SND03 画内与画外声音
- 定义与效果：声音来源是否在当前画面内。
- 边界与区分：画外不等于不存在或已离场。

<a id="snd04"></a>
## SND04 故事内与非故事内声音
- 定义与效果：属于故事世界或外加表达层的声音。
- 边界与区分：非故事内不自动授权配乐或主观音。

<a id="snd05"></a>
## SND05 事件音
- 定义与效果：绑定已给具体事件及接点的声音。
- 边界与区分：不得把持续底声改名事件音绕过授权。

<a id="snd06"></a>
## SND06 环境声
- 定义与效果：持续或整体空间听觉背景。
- 边界与区分：默认不自动添加，原稿指定才采用。

<a id="snd07"></a>
## SND07 细节音
- 定义与效果：衣料轻触等微小动作声音。
- 边界与区分：默认对应动作近距离覆盖门槛；近景也非必配。

<a id="snd08"></a>
## SND08 剧情声音线索
- 定义与效果：承担信息、打断或因果的既定声音。
- 边界与区分：不按普通微声省掉，不补未知来源。

<a id="snd09"></a>
## SND09 同步点与尾音
- 定义与效果：声音与动作词段对应的进入、结束及衰减。
- 边界与区分：切镜不必截断，也不任意拖长覆盖下一事件。

<a id="snd10"></a>
## SND10 声音桥 J与L
- 定义与效果：跨画面持续或先行的既有声音组织。
- 边界与区分：桥接不证明两场同时或同地。

<a id="snd11"></a>
## SND11 声音透视
- 定义与效果：按听觉位置、空间和已给表现确定远近清晰感。
- 边界与区分：镜头近远不机械决定响度，实际拾音非摄影位置。

<a id="snd12"></a>
## SND12 媒介表现
- 定义与效果：电话扬声器等已有载体的必要声音特征。
- 边界与区分：不编具体频带参数，不把媒介切换当语气重设计。

<a id="snd13"></a>
## SND13 主观听觉与静默
- 定义与效果：已明确角色听觉限制或表达性的省略。
- 边界与区分：不能为了气氛自动心跳耳鸣或抹去剧情声。

<a id="snd14"></a>
## SND14 对白完整与语言静音锁定
- 定义与效果：完整保词段与既定可听规则。
- 边界与区分：清楚≠背景必全无；全静音锁定不得自行解除。

<a id="snd15"></a>
## SND15 反射与混响目标
- 定义与效果：空间对声音延续和清晰的影响描述。
- 边界与区分：只依已有环境作必要目标，不包办实测混响或混音。

<a id="snd16"></a>
## SND16 声音存在与呈现
- 定义与效果：物理可能发声和分镜选择让其可听不同。
- 边界与区分：省略非必要微声不代表物体不曾存在。
