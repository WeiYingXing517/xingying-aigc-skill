# 身体与操作应用场景

版本0.1.0，有条件创作候选，全部未做媒体验证；来源见[索引](../suo-yin.md)。

<a id="ba01"></a>
## BA01 稳定递交与急切递交

- 条件与目标：已持物，接收对象和范围明确，目标是成功交接。
- 候选与理由：伸向可接范围，目标前控制速度，对方接稳后释放。急切可加快启动、按条件略增加上身参与，但不能牺牲交接成立。
- 配合：视线可检查交接处；对白按原并行继续，不强制停住等递完。
- 排除与替代：距离不可达时提局部空间需求，不延长手臂或移动家具。手侧已锁定不另改。
- 正反例：接稳后释放且物件唯一；双方同时松手为硬错。关联B03、B04。

<a id="ba02"></a>
## BA02 从支撑面拿起物件

- 条件与目标：物件位置、可接触条件成立，任务是拿起而非展示。
- 候选与理由：从现有手位接稳物件再离开支撑，抬至本次需要的持物位置；接近终点时自然控制。
- 配合：已有对白并行，不为每一阶段加停顿；根据需要短暂看物件，不固定先看手。
- 排除与替代：手已占用不直接多拿；需要换手先完成接管。未知功能不假装启动设备。
- 正反例：终态明确谁持哪件；物件先飞起后手接触为反例。关联B01、B04。

<a id="ba03"></a>
## BA03 轻放与急放

- 条件与目标：已有可用支撑，原事件是放置而非投掷或砸落。
- 候选与理由：轻放在接触前减速、稳定后释放；急放可较快到达但仍交代接触和稳定。力度和速度分别控制。
- 配合：情绪可通过动作质感表达，不自动增加撞击音；声音交分镜。
- 排除与替代：不把愤怒直接改成摔碎，不新增道具损坏。支撑缺失则提出条件。
- 正反例：同一放置结果不同速度；悬空松手或擅自砸桌为反例。关联B03—B05。

<a id="ba04"></a>
## BA04 从已有坐姿起身

- 条件与目标：需要起身，已有承托、下肢支撑和可用空间。
- 候选与理由：按当前姿态安排必要重心前移，支撑转移后身体上升，接稳定站姿或既定后续行动。
- 配合：急起或稳起按目标调整启动和收束；台词并行则保持，不逐阶段停顿。
- 排除与替代：不统一撑扶手；未知身体限制不编伤病，战斗起身不在本条重做。
- 正反例：继承原坐姿连贯站起；每个关节单独动作、站起后自动重新微笑为反例。关联B02、B05。

<a id="ba05"></a>
## BA05 边操作边说

- 条件与目标：原事件明确并行，动作与发声、注意条件相容。
- 候选与理由：动作连续推进，台词按原接点发声；真实判断或等待才停，不为说明细节创造停顿。
- 配合：视线按操作和交流目标切换；面部选择可维持状态，不要求一直对视。
- 排除与替代：原定先操作后说不能套用；口部动作与完整发声冲突则提出具体协调需求。
- 正反例：递文件同时说完整句；改先递完再开口为反例。关联B06、CA05。

<a id="ba06"></a>
## BA06 稳定倾听与动作接续

- 条件与目标：没有新增行动任务，人物需要听或保持当前操作状态。
- 候选与理由：维持已有支撑、手部和视线，必要信息到达才有反应；进行中操作按条件继续，不重启。
- 配合：允许安静无动作；若原操作要求持续关注，可保留操作目标，不能宣称同时一直对视。
- 排除与替代：不靠随机摸脸、摆手、点头证明自然；明确剧情打断时才停止动作。
- 正反例：听者保留已持杯和浅笑；切镜后杯子消失、听者重置为中性为反例。关联B05、C02。

<a id="ba07"></a>
## BA07 进食中切镜

- 条件与目标：切点落在连续的吃、喝或吹奏过程，接触阶段或可见痕迹会改变下一镜的读法。
- 候选与理由：持物人、手侧、握点和接触阶段可以延续，画面投影随换机位而变。若切出时食物已离嘴且已有咬痕，咬痕属于后续状态。若只是抵近，后镜可沿原动作继续接触。
- 排除与替代：上镜尚未咬合时，下一镜出现咬痕需有实际咬合或明确省略依据。遮挡使接触未知时，可以从可见的手物关系衔接。
- 正反例：糖葫芦仍抵唇时切到侧脸，保留接触再拉离；切镜后无故重新举起或提前出现缺口会改写动作进度。关联 [B07](ji-chu.md#b07)、[C02](../jiao-liu/ji-chu.md#c02)。
