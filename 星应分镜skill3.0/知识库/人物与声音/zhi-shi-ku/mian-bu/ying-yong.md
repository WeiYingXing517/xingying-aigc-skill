# 面部与视线应用场景

版本0.1.0；全部为条件化创作候选，非心理诊断，未做媒体验证。来源见[索引](../suo-yin.md)。条目应结合人物、原态和可见条件选择，不按情绪名直接套脸。

<a id="fa01"></a>
## FA01 直接收到好消息

- 条件与目标：角色已经理解好消息，直接喜悦，无掩饰要求。
- 候选与理由：双唇原有张力减弱，嘴角上提、面颊抬起，眼周按幅度参与，目光保持消息来源；把收到信息后的变化具体化。
- 配合：开口后正常唇形，人声选择符合词义的轻快或放松说法，身体可以不新增动作。
- 排除与替代：不自动露齿、拍手或大笑；未听懂不提前笑。明确克制时改用FA05，礼貌回应用FA02。
- 正反例：好例为听清“通过”后形成笑意并回应；反例为全段只写“表情喜悦，眼睛发亮”。关联F01、F04。

<a id="fa02"></a>
## FA02 礼貌回应

- 条件与目标：明确要求礼貌，不足以判断真心高兴或伪装。
- 候选与理由：短暂目光接触，嘴角适度牵起，回应结束后自然回收；或者稳定关注、不笑但清楚回应，均可满足礼貌。
- 配合：声音尊重、自然收束，不为了热情喊叫。
- 排除与替代：不加“眼底冰冷”“假笑”或强烈喜悦；角色已明确真心开心可用FA01。
- 正反例：回应后浅笑回收是候选；由眼周不明显就断言虚伪是错误。关联F01、F03。

<a id="fa03"></a>
## FA03 笑意收敛

- 条件与目标：有新信息使已有笑意减弱，未明确转怒。
- 候选与理由：嘴角牵拉减弱、面颊随之回落，眼周与原态衔接，留下必要张力；使变化有过程和终态。
- 配合：如同时说话，维持正常口型，人声变化只在情境需要时设计。
- 排除与替代：不自动皱眉瞪眼；若原文明确转怒，另设计对应外显，不能仅靠收笑完成。
- 正反例：收到指定信息后逐渐收住，下段继承；切镜即中性或无触发再次收笑为反例。关联F02。

<a id="fa04"></a>
## FA04 意外且正向的信息

- 条件与目标：角色实际收到有依据的意外好消息，需表达从意外到高兴。
- 候选与理由：理解信息时上眼睑短暂抬起，确认后转为适当笑意；也可根据人物直接停住片刻再笑，不固定阶段。
- 配合：不自动张口吸气或加“啊”，台词仍用原词。
- 排除与替代：普通预期好消息不强加惊讶；未确认正向含义不能直接欢喜。只需喜悦时用FA01。
- 正反例：意外后笑意连贯形成；统一先瞪大眼再露齿笑为模板化反例。关联F03、F06。

<a id="fa05"></a>
## FA05 明确要求压住兴奋

- 条件与目标：兴奋及控制要求均有依据，例如不愿打断正在进行的交流。
- 候选与理由：嘴角产生可辨认但受控的上提，面颊少量参与，身体保持；不是全脸冻结来表示克制。
- 配合：低或适中音量、词句仍有轻快感，保持固定音色；无需每句强忍笑的气声。
- 排除与替代：不能凭“开心”自行增加隐藏关系；画面看不见细节时提出信息需求或选择可用载体。直接外显用FA01。
- 正反例：有控制依据的小幅笑意；同时攥拳、跳动、喊叫破坏约束。关联F03、CA06。

<a id="fa06"></a>
## FA06 笑着完整说话

- 条件与目标：已有笑意且需发声，兼顾情绪可读和口型。
- 候选与理由：开口前唇部可放松，发声中正常唇形，眼周面颊延续笑意，句后回到适度笑态。
- 配合：按词义设计人声，不要求持续笑出声。
- 排除与替代：不固定全程露齿或双唇闭合；明确要笑声时单独检查与词段关系，不能遮词。
- 正反例：说话时笑意不消失但嘴型自然改变；固定笑脸念词是反例。关联F04、VA02。

<a id="fa07"></a>
## FA07 难过但不落泪

- 条件与目标：原文或用户已明确难过，且不哭或不落泪；不据脸部反推动机。
- 候选与理由：依据起态选择眉头略收、嘴角原有牵拉消退或唇部轻压等少量变化，视线按当前交流保持；具体组合避免把脸上每处都拉成悲伤。
- 配合：发声前松开妨碍口型的紧压；声音可较收敛，但不默认沙哑、哽咽或每词停顿。
- 排除与替代：不加眼泪、吸鼻、抽泣和新心理；需要强烈情绪却幅度受限时通过已有对白意图与合理身体张力补足。
- 正反例：明确变化并保留不落泪要求；“眼眶湿润、声音哽咽”若无授权即违背本条件。关联F01、F03、V04。
