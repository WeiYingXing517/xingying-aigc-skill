# 知识检索与采用

先由当前流程和方法确定具体问题、已知事实及锁定项。已有依据足以成稿时直接写。需要专业判断时，先用方法中的条目直链，其次查对应领域索引。只读命中条目和必要关联。

## 必经检查不依赖检索

先按[统一调用门槛](../SKILL.md#必经调用与完成门槛)确定责任步骤。视频共同入口、空间恢复、信息保真、主语与可执行表达、分段时间和承接是流程必做，不等关键词命中；知识库只为具体专业缺口提供候选，不是启用开关。

| 请求/症状 | 精确入口与写回 |
|---|---|
| 跑、走、等待、寻找或重复操作空耗，换景别但没有推进 | [03持续动作覆盖](03-分镜/流程.md#action-coverage)，估时前比较留镜/相关对象/插入/省略，写回镜头任务、切入切出和主行动进度 |
| 主语不清、他她指代、镜头或人物谁在动不明 | [可执行表达](04-提示词/可观测写法.md#executable-check)，每份视频正文必检，04修对应句；设计缺口回03源镜 |
| 套话、微表情堆积或文字精炼 | [成稿精炼](04-提示词/可观测写法.md#prose-polish)，先保真和消歧再删重复，不能删原词与执行条件 |
| 分段卡遗漏或未确认分组 | [04共同入口](04-提示词/流程.md#视频提示词)，补未知设置，已确认不重复 |
| 段总长出现小数 | [自然分段后局部调时](04-提示词/流程.md#分段时长与压缩)，只改合法内部节拍及映射，不先凑数字 |
| 转写漏信息或只列部分镜头 | [信息去向](04-提示词/流程.md#information-mapping)，逐源镜对照最终块并完整展开 |
| 有空栏、无文字仍列文字、漏无字幕无水印 | [前置约束与空栏目](04-提示词/流程.md#fixed-constraints)，删不适用项但保留固定生成约束 |

方法采用后必须产生对应镜头/文字/映射，交给下游复核，不能停在“参考了该文档”。已有决定不重选；只修当前缺陷。

## 空间执行检查

做分镜、视频提示词或分镜图时，先按[空间基准与调度](空间基准与调度.md#space-entry)恢复适用空间。互动、反打、走位、进出场、遮挡或接触必须确认位置、朝向、功能距离和所需观察侧已经成立，再选对应专业做法。检查是执行要求，查知识库则按具体疑问进行；不要求全量预读。

空间设计缺口交 03，已定内容漏写交[04 空间信息继承核对](04-提示词/流程.md#space-inheritance)。打斗或特效采用的位移、落点、范围及通路变化写回同一份场级基准和源镜状态，不能空间流程与专项各编一条路线。按“源镜号｜条目编号或项目事实｜采用决定”保留来源，转写时直接继承。

采用后按“事件号／源镜号｜项目事实或条目编号｜观看目标与具体采用决定”写回03十四项，关键理由和必要替代限制随[内部记录](项目交接与恢复.md#内部镜头记录)保存；进入04时按[导演继承](04-提示词/流程.md#director-inheritance)检查可见证据及顺序，不能停在知识引用。只改机位或运动时保留主体动作、原词与空间事实。知识正文变更同步索引、场景词及检索数据，不新增平行情绪库。

## 事件识别与专项调用

按当前事件逐项判断。题材标签、片名、镜头快慢本身不改变判断。

| 判断 | 判定和调用 |
|---|---|
| **是否发生打斗？** | 人物之间发生肢体冲突碰撞，一律判「是」。有明确的互攻、阻挡、闪避或对抗性拦截，即使未发生碰撞，也判「是」。判「是」查下表的武打索引，按人数、接触状态和本镜问题读命中条目。日常接触、单人动作、单纯追赶和偶然相碰按原事件处理。 |
| **是否出现特效？** | 剧情、已采用参考、用户要求或已确认设计包含需呈现的视觉特效，判「是」，查下表的特效索引。常规照明、发色或画风沿用原流程。 |

两项独立。打斗为「否」时跳过武打，即使特效为「是」。特效为「否」时跳过特效。均为「是」时分别查命中条目，按同一事件接点合并采用结论。有意省略或只在画外发生的过程保留原本的可见范围。专项读取以当前镜头的任务和缺口为限。可按需补查摄影或案例，常规任务不预读案例库。

| 当前要判断的内容 | 查阅入口 |
|---|---|
| 景别、角度、构图、轴线、焦点、空间、节奏、成像或光色 | [摄影专项索引](../知识库/摄影与画面/zhi-shi-ku/zong-suo-yin.md) |
| 面部、视线、身体动作、人声、听者反应、声源或拟音 | [人物与声音索引](../知识库/人物与声音/zhi-shi-ku/suo-yin.md) |
| 需要对照具体拍法、运镜、节奏或效果接续时 | [原创分镜案例索引](../知识库/动作与特效/动画案例/索引.md) |
| 打斗识别为是 | [武打索引](../知识库/动作与特效/武打/zhi-shi-ku/suo-yin.md) |
| 特效识别为是 | [特效索引](../知识库/动作与特效/特效/zhi-shi-ku/suo-yin.md) |
| 图像、首尾帧、视频或音频参考能力 | [入口与参考能力](../知识库/生成资料/入口与参考能力.md) |

1. 已知编号时按领域和编号直达正文。武打 A03 和特效 A03 属于不同领域。查术语读基础定义，查具体使用条件读应用。
2. 按条件筛候选。对照本场的素材、人物可知信息、可见范围、空间、时间和已定结果。前提未知就保留未知，碰到硬冲突就排除。候选、例子和别名只提供参考。
3. 以「源镜号｜条目编号｜采用决定」记录实际采用的动作、特效和摄影结论。分镜写观看任务、拍法与关键结果，内部十四项保留执行细节，提示词从中转写。可直接用项目事实处理的缺口按已知关系写，影响锁定内容的实质歧义说明其影响。
4. Markdown 索引可独立使用。需要扩大召回时，按各领域索引提示使用包内检索脚本。脚本返回候选及定位，采用前读正文。

先判断要解决的是拍法、表演、动作连续性还是特效，再用该领域索引或脚本检索。摄影可输入「对峙」「吵架」，武打可用完整动作短句，例如「两个人从两侧夹击主角，主角向左转向」。查看命中理由和使用前提，确认候选是否保留原稿动作与结果。摄影 CLI 只覆盖摄影。脚本返回空时，用领域索引里的术语或编号继续定位。武打候选标为「冲突」时排除，标为「未定」时按原稿或本轮设计核对应条件，再决定是否采用。
