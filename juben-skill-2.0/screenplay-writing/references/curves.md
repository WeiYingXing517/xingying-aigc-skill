# 起伏图与结构递进

用于整体故事、分集重排、结构专项或用户要求的起伏图。纯提取、格式整理和不涉及结构的局部改词不启用。已定故事不因画图重开选题；事件和结局的保留边界仍有效。与[大纲](outline.md)、[分集](episodes.md)和[期待与回报](expectation.md)共用事件及承诺，不另建一套重复事实。

## 1. 先选路况，再选曲线

复用作品形式、题材、长度、目标体验、有效材料和结局约束。结构会实质影响本次交付且用户尚无偏好时，给两到三个相符方向，允许自定义、跳过或委托选择；不重复询问已答项。用户要求直接成稿时，可注明可逆的工作假设后推进，不强制等确认。

| 方向 | 操作含义与边界 |
|---|---|
| 递增波浪 | 大段落的峰谷落差逐轮扩大，局部可缓冲；最大核心变化在后段，不要求每场更激烈 |
| 高开蓄力再攀升 | 开场强变化，随后建立投入与办法，后段以新条件超越前峰；不反复重播冷开场 |
| 下坠后反弹 | 处境和可选办法逐步收紧，再由有前因的行动逆转；不得一键撤销全部损失 |
| 双峰／多峰 | 阶段高潮承担不同任务，后峰继承前峰结果；不靠重复误会归零 |
| 慢燃爆发 | 表面变化可小，投入、顾虑或限制持续积累，后段集中改变；不把无进展当慢燃 |
| 自定义／其他方向 | 可指定上升、下坠、开放、反高潮、平台段等，写清目标和结局约定；不强制圆满或大爆发 |

同时明确曲线对象、横轴单位、峰谷含义、结局方向、期望幅度及不接受的升级办法。不能用一串高低数字替代选择说明。

## 2. 两层图分开，人物情绪另附节点

**局势得失图。** 横轴采用事件、场、集或阶段；纵轴针对一个明确目标表示有利／不利程度。可用 -5 至 +5 作同一项目的相对刻度，0 是已注明的参照，不是客观测量。每个关键点注明事件、谁的选择、实际得失和不可逆后果。中途目标改变时标出转接及新基准，不能把不同目标的值直接比较。群像可分线，不把多人的得失混成含义不明的总分。

**预期观众体验图。** 同一横轴标注希望、担忧、憋屈、释放、悲伤等体验方向和预期强度；可用 0 至 5 的独立刻度。强度高不等于正面，快乐也不是紧张的反义值。人物以为安全而观众知道威胁时，两图可以背离。它是创作假设，不声称实际观众已如此感受。

人物自身的真实感受、理解、外显办法与离场余情附在节点或蓝图中，按[情绪变化链](script.md#情绪变化链与跨场余波)核对，不把人物开心等同观众放松。

## 3. 从节点生成图，不用图代替故事

内部复用事件记录，必要字段为：节点及位置、目标与基准、触发和选择、实际后果、局势值、预期体验及强度、人物情绪与后续承接。规划位置与正文实际位置分开。用户要图时交付：

1. 简短说明所选形状、目标、横纵轴及刻度。
2. 局势折线图和预期体验图，关键节点标事件名；节点多时分阶段，不塞满一张。
3. 必要的节点说明，解释峰谷为什么成立、下一段如何继承。

支持图形时用真实折线图；仅支持文本时可用 Mermaid 折线语法或明确注明的文字折线示意，并附可核节点数据。两图分开，不混用刻度。数值、标签、节点数量和连线顺序须一致，不把一张节点表冒充已渲染图。不能确认客户端渲染时说明是图代码／文字示意，不谎称已查看图像。

## 4. 幅度、节奏和升级分开

幅度是相邻重要峰谷的落差；节奏还涉及间隔、持续、反应时间和信息负担。提高代价、关系投入、不可逆性、选择难度及兑现分量，可以扩大冲击，不一定增加事件规模。不得机械相加这些维度形成伪精确总分。

递增波浪只约束已约定的大轮次，用同一目标和刻度比较；局部可以平台、回落、小胜、休息和余韵。高潮后的收束不必更高。其他形状按用户选择验收。短剧区分全剧、阶段和单集尺度；电影按全片与场次；电视剧保留各线差异；广告仅在有叙事需要时画图，不硬造人生谷底。

每次大转折核对：旧办法为什么变化，人物做了什么，新条件是什么，实际代价或所得如何显现。不能靠对手降智、突然万能援助、梦境撤销、反复误会或撤回已付成果造波峰谷。安静段可用于接收结果、加深关系或调整办法，不强制每场反转。

## 5. 成稿反推与修改边界

规划图不代表正文实现。结构任务或完整成稿按实际正文定位关键节点，反推实现曲线，与规划比较：有无只说危机却无损失、只放金句却无兑现、前段过度透支、连续同质打击、缺接收时间或峰谷无事件依据。发现差距先修最早根因，再更新授权范围内的正文与图；不为凑数字擅改锁定结局。局部情绪修改只查受影响节点与相邻承接。文本内部检查、独立审读和受众反馈分别记录；无实际数据不宣称曲线提高完播或爽感。
