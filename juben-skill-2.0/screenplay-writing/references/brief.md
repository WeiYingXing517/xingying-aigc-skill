# 新项目启动与参考选择

用于新建剧本项目、从新小说启动改编，以及用户主动要求重新确定创作方向。续写、单项提取、审稿和局部修改复用当前项目依据。用户明确要求直接出稿时，采用已给条件和可逆的工作假设，仍需核实用户指定且对交付有影响的参考。

## 1. 确认创作需求

仅补会阻塞本次产物的需求。空白开局可先给作品形式与题材选项，已有信息直接带入，不机械问满表格。作品形式和题材分别记录，例如「短剧」和「都市悬疑」。可同轮回答的关键缺项集中询问；用户委托自由创作时采用可逆假设直接推进。只要梗概不先索要完整分集参数，纯提取不询问创作偏好。需求足够即进入目标产物；参考选择是按需分支，不是必经审批。

| 作品形式 | 可按需询问的内容 |
|---|---|
| 短剧 | 子题材、时代与地点、核心处境、目标平台或横竖版、集数与单集时长 |
| 电影／短片 | 子题材、时代与地点、核心处境、目标片长 |
| 电视剧 | 子题材、故事背景、目标集数与单集时长、主要人物线 |
| 广告脚本 | 产品或服务、受众、传播目标、渠道、成片时长和必须传达的信息 |

仅询问会影响本次产物的字段。小说改编同时记录已提供素材范围和必须保留的锚点，具体处理见 [小说改编](adaptation.md)。创作背景或目标时长由用户授权补充时，明确为工作假设。

## 起伏与文风偏好：按需的设计分支

完整结构、起伏专项或显著重排按[起伏设计](curves.md)复用已定偏好；未定时给两到三个适配方向，允许自定义、跳过或委托提案。说明曲线对象、幅度含义、缓冲与结局，不只让用户选数字。用户要直接成稿时可注明工作假设后推进，不强制等确认。局部改词、提取和格式任务跳过。

用户希望文风稳定时，按[文风档案与校准](style.md)区分动作细腻度、对白质感、情绪外放、直接／潜台词、交流节奏和修辞边界。可用同条件原创短场景试稿，用户明确认可后才记为已确认。未确认采用清楚、具体、有接话、情绪可追溯的默认。[内置候选样本](style-samples.md)不是用户口味，也不是跨模型能力保证。只选抽象方向或调用内置原创样本不启动外部研究。

## 2. 选择文风与节奏

只在用户要求选择表达方向、找作品、做对标开发或核查指定参考时进入本节。只选「自然直接」「克制留白」等抽象偏好，不必先找一部作品；用户未要求逐步选择时，可在授权内采用合适写法直接交稿。需要具体作品时，按 [研究](research.md) 轻量核实候选真实、与任务匹配、可访问材料及能支持的观察；选定后深入核查。只启动实际需要的一路，已有选择不重复询问。资料不可访问时说明限制，改用用户样本或抽象方向继续，不循环搜索等用户。

**表达与对白卡。** 按作品形式选择剧本、成片对白、小说试读或广告案例，不把小说作家设为所有任务的默认来源。需要作品选项时提供两到三个同类可信候选，有多少列多少。每项写清创作者或来源、具体作品、适用理由、可查出处和可参考的表达特征。优先说明人物如何开口、如何接话、面对不同关系怎样改变表达，以及何时用动作或停顿承接。用户可选一个参考或其中几项特征，也可自带参考或跳过。仅提炼抽象的文风和对白习惯。参考作品中的人物、设定、情节、原句及独特表达不进入新稿。额外的文风参考与用户指定改编原著分别记录。

**节奏与对标卡。** 提供符合当前题材与时长的节奏方向，说明各方向的信息密度、回报间隔和张弛，例如悬疑短剧可选择快速抛出疑点、稳步推进线索或慢燃关系。只选节奏方向时到此即可；需要具体对标作品时，再索引同形式、同子题材、体量相近的作品并提供可查候选。短剧优先检索有公开热度证据的同类作品。候选说明作品、平台及版本、匹配依据、热度口径和可分析片段。证据不足时注明同类参考或缺口。用户可选一部主要对标、自带参考或跳过。按 [分集与节奏](episodes.md) 区分短剧的集内和集间节奏、电影的全片张弛、电视剧的阶段推进，以及广告的信息出现次序和时长配比。

节奏卡固定显示以下说明。

> **对标作品仅供节奏参考。人物、设定、台词、桥段、事件链及有辨识度的情节组合均由本项目独立创作。**

客户端支持交互选项时使用该能力，同时保留直接填写。仅支持文本时，用简短编号选项和示例回复。用户已经回答的选项不重复弹出。没有可靠候选时提供可确认的风格方向，用户可补链接、样本或跳过。可访问资料不足时注明实际可见范围，核查状态留待补。

## 3. 核查已选参考并进入创作

进入了具体作品参考分支时，阅读或观看实际可得的所选材料，再把有证据的观察用于写作；没有进入该分支则直接创作。用户只选方向且仍想挑作品时，先提供可核候选供选择。用户明确委托选作品时，在已确认方向内选择并说明来源。用户选择只用方向或跳过时，按已确认的抽象偏好写作。只取得简介、预告、片段或字幕时，按实际证据限制观察和时间定位。已确认且仍适用的研究依据可以复用。

按实际启用范围整理简短项目依据：创作需求与约束、表达和节奏偏好；使用具体参考时再附来源、抽象写法、覆盖范围与待核项，不为未启用的研究补空表。按 [项目状态](project.md) 区分候选、已确认、已查和待查，沿用会话或约定项目目录。只改文风时复核人物声音和相关对白，只改节奏时复核分集或场次。写对白继续先核知情与接话，再用文风规则调整声音。交付范围依用户目标，必要时按 [审稿](review.md) 复核相似性和本项目原创因果。
