# 对白回归

用同一模型、同一任务分别跑旧版和候选版，隐去版本后读成稿。先核知情与接话，再评自然度。保留必要信息和原有结局。

| 输入 | 通过条件 |
|---|---|
| 《最后一排》。第 1 集周伯指照片说妻子曾引座。第 2 集许宁照座位，周伯碰到台阶。另跑删除前集照片的版本。 | 停步触发搀扶或照明请求。删照片后，许宁能否理解“她”须有本场依据。 |
| [雨夜电话](样本/雨夜电话.md)。分别提供整句和末尾半句。 | 两种听见范围产生相符回应。改完定位依赖知情的下一场。 |
| 快递员问取件时间。店员周五三点才能开门。 | 时间交代清楚，允许直问直答。 |
| 妹妹问哥哥是否把退租告诉母亲。哥哥正在把房东来信塞回抽屉，母亲在隔壁。 | 回避有现场理由，妹妹的回应接住回避，不替观众宣讲内情。 |
| 值班员必须向新同事交代七点停电、用东门。 | 具体时间和入口完整，说明发生在有交接需要的时机。 |

硬门槛为关键接话有依据、知情范围正确、必要信息完整。再比较声线、可表演性和口语。记录原失败场、反例和受影响后续场的实际结果。
