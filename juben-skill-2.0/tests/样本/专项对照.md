# 专项对照

以下素材为合成文本。用于测试实际依据、原创对照和方法验证。

## 一、原创对照节选

- **节选甲。** 唐絮看到门上「暂缓开门」的纸封条。纸角已经浸软，她把半湿的纸角折起，下面露出签字，尾笔向左斜。她记得昨天维修回单上的同一笔字，于是去找值班员核对。
- **节选乙。** 余杉见邻居抱着快递往回走，先误以为快递被取错。看见楼道贴着临时门牌表后，她用运单尾号向快递站核实。

比较两段和《潮痕》的相似位置、表达及情节组织，并说明仅依据给定节选可以判断什么。

## 三、对白写法对照

- **甲稿。** 交接员对许芃说「钥匙在桌上纸袋里，刚才我放进去的」。许芃看了纸袋一眼，把它递给下一班。
- **乙稿。** 许芃打开写着「交接」的纸袋，露出钥匙。她把袋子递给下一班，指了指签收栏。

两个版本均要求观众知道钥匙在哪里。谁放进纸袋在这一场只于甲稿交代。比较在「只需交代位置」和「后文要追究放置人」两个条件下，简化对白的收益与信息损失。
