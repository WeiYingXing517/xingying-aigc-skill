# 末班收发箱

本素材用于原创短剧、短片、单项交付和制作适配测试。

## 用户设定

老小区的公用仓库今晚清理。许芃代理收发员，负责一只旧铁收发箱的处理。住户叶琴反对直接扔掉，箱里有一封等着归还的信。许芃的叔叔只在一张待交接清单上被提到，整段故事都未出现。允许补足合理的过渡动作和对白。

必保结局是收发箱完成清空，信归还给有权收取的人，叶琴在场但没有看信。人物始终没有撬开信封。可以重新安排场景和配角。人物音色没有预设。

## 已确认故事走向

1. 清运前，许芃在仓库贴公告。叶琴拦住推车，指出箱里的未领信件。许芃看到公示栏还挂着交接电话，于是留出半小时核实。
2. 信封上只有旧房号，叶琴记得早年住户常把地址写成旧楼号。两人找到公示栏的楼号变更图，核对出对应的新房号。许芃不确定现住户是否能签收，因此先给值班室打电话。
3. 值班室确认签收人是原登记住户，并让其带交接凭证到一层。对方出现并领取封好的信。叶琴帮许芃把空箱推到门口，在旧箱拆走前贴上一张清空日期。

## 适配条件

使用制作适配用例时，按该用例的新限制处理场景和呈现。若仅两位演员能出镜，签收可由许芃在门内核对并交给画外来访者。正文应保留可感知的签收依据和交接结果，具体呈现可自行选择。
