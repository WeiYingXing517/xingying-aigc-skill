# 时间与节奏

参照：[S05](../../lai-yuan/quan-wei-lai-yuan.md#s05)、[S06](../../lai-yuan/quan-wei-lai-yuan.md#s06)、[S12](../../lai-yuan/quan-wei-lai-yuan.md#s12)；本地原方法与用户规则L01/L02；应用综合为L03。参照只覆盖来源登记列明的事实，其他创作选择不是权威定律。知识状态：资料核对与文本组织，未实片验证。

以下为本地条件化应用建议，正反例是设计检验样例，不是真实成片记录。情绪与事件来自输入，本库不重新解释内容、不补表演或剧情。每次仍需核当前锁定项。

<a id="tim-a01"></a>
## TIM-A01 纯对白镜
- 触发与前提：原台词完整但无实录。
- 推荐与理由：按已给读法和停顿估时，注明范围或计划值；不能固定统一字速。
- 不适用或排除：凭字数宣称精准、压尾词。
- 替代：已有实录优先实测。
- 正反例：正：预估并注明待校准；反：写3.217秒称实测。
- 关联定义：[TIM04](ji-chu-ding-yi-ku.md#tim04)、[TIM05](ji-chu-ding-yi-ku.md#tim05)、[TIM06](ji-chu-ding-yi-ku.md#tim06)。
- 验证：文本可用条件建议；未进行本项目实拍、白模或生成效果验证，遇实际反例进入维护。

<a id="tim-a02"></a>
## TIM-A02 对白动作并行
- 触发与前提：原稿边动作边说。
- 推荐与理由：用起止区间重叠，镜长覆盖最后必要结果。
- 不适用或排除：对白时长加整段动作导致重复，或强改先后。
- 替代：单一时间线清楚列阶段。
- 正反例：正：对白0—4秒，动作1—3秒；无其他必要占用时合计4秒。反：把4秒对白和2秒动作串行算成6秒。
- 关联定义：[TIM07](ji-chu-ding-yi-ku.md#tim07)、[TIM08](ji-chu-ding-yi-ku.md#tim08)。
- 验证：文本可用条件建议；未进行本项目实拍、白模或生成效果验证，遇实际反例进入维护。

<a id="tim-a03"></a>
## TIM-A03 转焦或运镜限时
- 触发与前提：摄影必须结束再读信息。
- 推荐与理由：核运动、稳定和辨识是否有时间，不足删非必要运动或报差额。
- 不适用或排除：切出时还没对准却写任务完成。
- 替代：直接切目标或固定。
- 正反例：正：终点读数有时间；反：一秒推绕转焦看全文。
- 关联定义：[TIM08](ji-chu-ding-yi-ku.md#tim08)、[TIM09](ji-chu-ding-yi-ku.md#tim09)。
- 验证：文本可用条件建议；未进行本项目实拍、白模或生成效果验证，遇实际反例进入维护。

<a id="tim-a04"></a>
## TIM-A04 渐紧段落
- 触发与前提：已定威胁问题与重点结果。
- 推荐与理由：减少重复、适度集中必要信息，在结果读清后停止叠强调。
- 不适用或排除：每镜更近更快，原内容未释放却突然舒缓。
- 替代：稳定但信息递进。
- 正反例：正：重要节点后进入回应；反：结果后继续三次重复强调。
- 关联定义：[TIM09](ji-chu-ding-yi-ku.md#tim09)、[TIM10](ji-chu-ding-yi-ku.md#tim10)。
- 验证：文本可用条件建议；未进行本项目实拍、白模或生成效果验证，遇实际反例进入维护。

<a id="tim-a05"></a>
## TIM-A05 渐松与收束
- 触发与前提：输入明确压力已释放。
- 推荐与理由：完成已有后果和新状态，减少无用切换，及时进入下一事。
- 不适用或排除：无因空镜、拉远或慢动作拖长。
- 替代：保稳定镜至结果可读。
- 正反例：正：关系恢复后切下一事件；反：没解除威胁先抒情。
- 关联定义：[TIM10](ji-chu-ding-yi-ku.md#tim10)、[TIM09](ji-chu-ding-yi-ku.md#tim09)。
- 验证：文本可用条件建议；未进行本项目实拍、白模或生成效果验证，遇实际反例进入维护。

<a id="tim-a06"></a>
## TIM-A06 跨镜对白与接续
- 触发与前提：同句分配到相邻镜。
- 推荐与理由：逐镜实际词段且内部声线连续，保持原始顺序。
- 不适用或排除：每镜重读整句、换听者就换声。
- 替代：声音不切画面切。
- 正反例：正：一句总时长只算一次；反：三镜同句变三遍。
- 关联定义：[TIM02](ji-chu-ding-yi-ku.md#tim02)、[TIM11](ji-chu-ding-yi-ku.md#tim11)。
- 验证：文本可用条件建议；未进行本项目实拍、白模或生成效果验证，遇实际反例进入维护。

<a id="tim-a07"></a>
## TIM-A07 打斗速度与可读
- 触发与前提：动作链已给，需判断常速可读性或确有局部变速收益。
- 推荐与理由：默认常速先保方向、支撑、接触和结果；仅在短暂事件有独立体验收益且不损因果时按03采用少量局部变速，写进入、结束及恢复阶段，不把每次命中当慢放信号或用变速凑段长。
- 不适用或排除：快切使方向结果不可辨，慢放改武打事实。
- 替代：简化非必要摄影或分段。
- 正反例：正：动作阶段连续；反：一招切两次命中。
- 关联定义：[TIM08](ji-chu-ding-yi-ku.md#tim08)、[TIM11](ji-chu-ding-yi-ku.md#tim11)、[TIM12](ji-chu-ding-yi-ku.md#tim12)。
- 验证：文本可用条件建议；未进行本项目实拍、白模或生成效果验证，遇实际反例进入维护。

## TIM-A08 时长超目标
- 触发与前提：计划晚于指定结束。
- 推荐与理由：报目标、计划及差额，先去空耗再摄影简化，仍不足给选择。
- 不适用或排除：擅删词、塞过密、加速说话。
- 替代：调整时长或范围需确认。
- 正反例：正：列出缺2秒原因；反：把最后一句截掉。
- 关联定义：[TIM04](ji-chu-ding-yi-ku.md#tim04)、[TIM08](ji-chu-ding-yi-ku.md#tim08)、[TIM09](ji-chu-ding-yi-ku.md#tim09)。

## TIM-A09 局部延时
- 触发与前提：某镜增加且余镜设计不变。
- 推荐与理由：按增量平移后续时间，当前过程核边界，保原点与镜号。
- 不适用或排除：所有镜重新设计，起止差不等时长。
- 替代：只更新受影响时间与接点。
- 正反例：正：后续累计加1秒；反：下镜仍原起点意外重叠。

## TIM-A10 原素材转用或变速
- 触发与前提：已有时间码或明确变速要求。
- 推荐与理由：区分素材区间、采用时间、播放映射，标实测范围。
- 不适用或排除：源时间直接当全片坐标，生成长度当镜数模板。
- 替代：保现有采用范围再列差异。
- 正反例：正：源10—15秒映到本片0—5秒；反：自动按15秒切全片。

<a id="tim-a11"></a>
## TIM-A11 速度坡道（快慢转换）与物理快慢显形
- 触发与前提：常速基准下，某个生死擦身、破场突进、重击落定或情绪骤变节点确有局部慢速、爆发提速或快慢反差收益（文武戏通用）。
- 推荐与理由：AI 视频模型无法按剪辑倍速曲线或伪帧率参数（如 `240fps`、`1:2000快门`、`0.02s半帧`）精准渲染，必须改用**三式黄金速度坡道＋物理参照物**：① **急→微慢→急爆（闪避反击坡道）**：常速逼近→擦身瞬间微慢延展 0.5–1 秒（主体动作舒展看清间隙，同框既有雨滴/火星/碎屑半空近似悬停缓飘，形成帧内双速差）→蓄力点收紧瞬间骤然提速爆发；② **压簧微缓→骤提速→咬合顿挫（破场重击坡道）**：起势半拍沉腰屏息压弹簧→蹬地瞬间跨距突进配 20–24mm 广角透视拉伸、脚下介质向两侧高速后掠与衣摆受控拖影→命中点兵刃/拳锋咬死短促凝滞半拍（物理 Hit-stop 显出凹陷与悬停火星，不搞长定格或黑白负片闪屏）随即震开；③ **高频急促→骤降慢放（绝杀/情绪重击坡道）**：激烈交锋、追逃或争执在致命结果/噩耗刺入瞬骤降局部慢速，环境杂音同步压空只留呼吸心跳或低频余振。单镜最多允许 **1 次**速度坡道转换，局部慢放窗严控在 **0.5–1.5 秒**有效微事件。
- 不适用或排除：只干写“开启慢动作/拉快2倍”致画面变成水下打太极或原地鬼畜、单镜内“慢→快→慢→快”反复横跳、整镜慢放拖满五六秒凑段长、堆砌 `240fps/0.02s抽帧` 等伪参数。
- 替代：常速下借景别切近与短促停顿强化重音（[TIM-A07](#tim-a07)），或纯静帧微粒对比（[MOV-A18](../yun-jing-yu-jiao-dian/ying-yong-chang-jing-ku.md#mov-a18)）。
- 正反例：正：黑衣人常速直刺逼近，刀尖贴鼻尖掠过这 1 秒降入局部慢放——雨珠在半空近乎悬停、主角后仰眼神锁死刀柄，腰腹一收瞬间恢复常速爆起贴身反撩；反：写“240fps升格接0.02秒顿帧再拉快3倍”，或整段6秒全程慢动作对砍。
- 关联定义：[TIM08](ji-chu-ding-yi-ku.md#tim08)、[TIM09](ji-chu-ding-yi-ku.md#tim09)、[TIM12](ji-chu-ding-yi-ku.md#tim12)。
- 验证：文本可用条件建议；未进行本项目实拍、白模或生成效果验证，遇实际反例进入维护。

<a id="playback-guidance"></a>
## 播放速度与节拍

采用判断统一走[03 播放速度选择](../../../../流程/03-分镜/流程.md#playback-design)。正常剧情与常规交锋默认常速，全场无变速完全成立，不设次数或快慢配比；只在有明确观看或体验收益的少量节点采用局部慢放、爆发提速或速度坡道（[TIM-A11](#tim-a11)）。严格区分四件事：**人物发力快慢、摄影机运镜加减速、无信息过程快进压缩、以及画面播放慢放**，措辞绝不混用。

先修取景和覆盖，再判断是否值得做速度反差；辨认困难本身不是慢放理由。「过程快进」仅用于走向已读清且无新增信息的过场压缩（不因段长不足强用）；「爆发提速」则靠压重心前摇、广角透视与地面介质后掠在常速或坡道恢复瞬释放冲击力；「局部慢放」须有同框悬浮微粒等双速参照物并将窗口锁在 0.5–1.5 秒微事件，单镜最多执行 1 次速度转换，完成后立即恢复常速或切入常速后镜。

执行写明进入触发、物理参照表现、结束恢复点及声音协同（局部慢放常压空环境杂音留呼吸/低频余振，提速爆发配破空风压卡点；同步对白期间不擅开慢放拖变形人声），区分生成直出与后期职责。以成片实际占用核算时间，跨镜和跨段交接真实速度阶段；04 仅继承并转译为可观测画面，不为凑分段时长私自加减速。
