# 时间与节奏

参照：[S05](../../lai-yuan/quan-wei-lai-yuan.md#s05)、[S06](../../lai-yuan/quan-wei-lai-yuan.md#s06)、[S12](../../lai-yuan/quan-wei-lai-yuan.md#s12)；本地原方法与用户规则L01/L02；应用综合为L03。参照只覆盖来源登记列明的事实，其他创作选择不是权威定律。知识状态：资料核对与文本组织，未实片验证。

本库提供定义与判断边界，具体裁切和角度以项目约定为准；软件参数只适用所标版本。

<a id="tim01"></a>
## TIM01 全片时间与原点
- 定义与效果：本次设计采用的累计时间坐标。
- 边界与区分：片段可从零或继承原时间，必须声明。

<a id="tim02"></a>
## TIM02 镜内局部时间
- 定义与效果：相对于本镜开头的过程时刻。
- 边界与区分：0秒不是全片0秒，跨镜声音可连续。

<a id="tim03"></a>
## TIM03 采用时长
- 定义与效果：最终计划使用的镜头区间长度。
- 边界与区分：不等于生成请求时长或原素材总长。

<a id="tim04"></a>
## TIM04 指定时长
- 定义与效果：输入明确要求的时长。
- 边界与区分：仍核内容是否能容纳，不能因指定就假称可行。

<a id="tim05"></a>
## TIM05 设计估时
- 定义与效果：根据已有过程及假设作计划值或范围。
- 边界与区分：不能冒充实测；读法未知保不确定性。

<a id="tim06"></a>
## TIM06 实测时长
- 定义与效果：依据实际音频视频或计时结果确定的范围。
- 边界与区分：注明素材与测量对象，不将部分测量推全场。

<a id="tim07"></a>
## TIM07 顺序与并行
- 定义与效果：先后过程累计，真实重叠过程共享时间。
- 边界与区分：不能全部相加，也不能全塞一秒。

<a id="tim08"></a>
## TIM08 关键路径与余量
- 定义与效果：必须完成过程的最晚终点及辨识所需空间。
- 边界与区分：余量由内容确定，不固定所有镜加半秒。

<a id="tim09"></a>
## TIM09 切点与结果可读
- 定义与效果：选择从某阶段转入下镜的时刻。
- 边界与区分：不靠节奏掩掉必须观察的结果。

<a id="tim10"></a>
## TIM10 渐紧 渐松与稳定
- 定义与效果：按已有触发和结果组织信息密度与保持。
- 边界与区分：渐紧不每镜推进，渐松不自动空镜拉远。

<a id="tim11"></a>
## TIM11 跨镜词段映射
- 定义与效果：同一声音或动作按实际阶段覆盖相邻镜。
- 边界与区分：不重复整句整招，不因换镜重置状态。

<a id="tim12"></a>
## TIM12 变速与时间省略
- 定义与效果：已有授权改变呈现速率或省去部分过程。
- 边界与区分：不能擅改已给对白、事件结果或同时关系。

<a id="tim13"></a>
## TIM13 素材余量与生成区间
- 定义与效果：实际制作可能保额外头尾用于剪接。
- 边界与区分：不把生成段长作为镜头切分硬公式。

<a id="tim14"></a>
## TIM14 局部时长重算
- 定义与效果：修改当前时长后更新后续累计坐标。
- 边界与区分：不借重算重排无关设计，保持新旧映射。
