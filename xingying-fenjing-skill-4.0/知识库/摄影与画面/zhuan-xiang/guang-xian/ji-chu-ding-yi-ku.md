# 光线

参照：[S10](../../lai-yuan/quan-wei-lai-yuan.md#s10)、[S11](../../lai-yuan/quan-wei-lai-yuan.md#s11)；本地原方法与用户规则L01/L02；应用综合为L03。参照只覆盖来源登记列明的事实，其他创作选择不是权威定律。知识状态：资料核对与文本组织，未实片验证。

本库提供定义与判断边界，具体裁切和角度以项目约定为准；软件参数只适用所标版本。

<a id="lit01"></a>
## LIT01 实际光源
- 定义与效果：太阳、天空、窗门透光、已有灯具或屏幕等有依据来源。
- 边界与区分：不得因场景类型自动新增可见灯。

<a id="lit02"></a>
## LIT02 主要受光 原L01
- 定义与效果：主体主要亮面及其来源作用。
- 边界与区分：主光是作用，不是凭空新灯。

<a id="lit03"></a>
## LIT03 补光与反射 原L02
- 定义与效果：填补暗部所需的已有反射或明示制作选择。
- 边界与区分：补不等于抹平所有对比。

<a id="lit04"></a>
## LIT04 遮光与负补光 原L03
- 定义与效果：减弱某区域受光的遮挡或吸光制作选择。
- 边界与区分：不新造剧情障碍，不擅改人物路线。

<a id="lit05"></a>
## LIT05 轮廓分离 原L04
- 定义与效果：主体边缘与背景形成可辨亮暗。
- 边界与区分：不是每人每镜自动发光边。

<a id="lit06"></a>
## LIT06 硬光 原L05
- 定义与效果：阴影边界相对清楚的光质。
- 边界与区分：软硬与亮暗不是同一维度。

<a id="lit07"></a>
## LIT07 软光 原L06
- 定义与效果：阴影过渡相对平缓的光质。
- 边界与区分：不等于没有阴影或全场同亮。

<a id="lit08"></a>
## LIT08 局部光区 原L07
- 定义与效果：来源与遮挡形成的照射范围。
- 边界与区分：离开光区要更新受光，不能每镜复位。

<a id="lit09"></a>
## LIT09 混合来源 原L08
- 定义与效果：多个来源分别具方向颜色与范围。
- 边界与区分：不为炫彩无因冷暖叠加。

<a id="lit10"></a>
## LIT10 双人受光 原L09
- 定义与效果：共享场景来源，两人按各自位置朝向获得不同明暗。
- 边界与区分：不要求画面中两脸总同一侧亮。

<a id="lit11"></a>
## LIT11 体积可见光束 原L10
- 定义与效果：光路与已有介质等条件形成可见束。
- 边界与区分：无介质不造烟尘，也不遮关键接触。

<a id="lit12"></a>
## LIT12 整体明亮与局部明暗 原L11 L12
- 定义与效果：照射范围和信息优先决定整体亮或局部突出。
- 边界与区分：不等于过曝，不把犯罪固定映射黑暗。

<a id="lit13"></a>
## LIT13 剪影 原L13
- 定义与效果：主体相对背景暗，以轮廓承载信息。
- 边界与区分：同时需细读表情时不能全剪影。

<a id="lit14"></a>
## LIT14 遮挡投影 原L14
- 定义与效果：来源、遮挡物和承接面形成的阴影。
- 边界与区分：窗格形状与方向不能随机换。

<a id="lit15"></a>
## LIT15 反光材质 原L15
- 定义与效果：已有材质通过反射显示亮边或环境。
- 边界与区分：不把墙反光当自发光，不改产品材质。

<a id="lit16"></a>
## LIT16 光色辨识 原L16
- 定义与效果：源光色与对象本色在画面中的必要区分。
- 边界与区分：混光不允许关键产品身份颜色被任意替换。

<a id="lit17"></a>
## LIT17 动态与特效照明
- 定义与效果：开关、移动灯或已给特效发光对环境的影响。
- 边界与区分：特效本体不是本域设计，未给强度范围则保条件。

<a id="lit18"></a>
## LIT18 光源种类与限制
- 定义与效果：直射日光、天空、窗、室内／局部灯、屏幕、火焰、晨昏、暮光、月夜、霓虹、车灯、闪电、制作补光。
- 边界与区分：仅当来源已给或授权且可见作用合理，名称不代表固定色温强度。

<a id="lit19"></a>
## LIT19 直射日光
- 定义与效果：明确太阳方向形成直射和阴影，受天气遮挡与时段影响。
- 边界与区分：不能只凭白天确定具体方向或色温。

<a id="lit20"></a>
## LIT20 天空散射光
- 定义与效果：天空作为较广来源参与照明，阴晴与遮挡影响分布。
- 边界与区分：不等于各方向同亮或没有阴影。

<a id="lit21"></a>
## LIT21 窗门透光
- 定义与效果：已有开口引入外部来源并受开口与遮挡限制。
- 边界与区分：窗口不是无条件自发光，夜景外源需依据。

<a id="lit22"></a>
## LIT22 室内灯具
- 定义与效果：已有顶灯或空间照明来源。
- 边界与区分：灯具位置及状态继承，不为镜头反打漂移。

<a id="lit23"></a>
## LIT23 局部灯具
- 定义与效果：已有台灯手电等对局部起作用的来源。
- 边界与区分：范围与指向需合理，不自动照亮整室。

<a id="lit24"></a>
## LIT24 屏幕光
- 定义与效果：已有屏幕显示对近处对象产生可见照明。
- 边界与区分：取决内容与亮度等条件，不能凭手机存在就全脸强光。

<a id="lit25"></a>
## LIT25 火焰光
- 定义与效果：已有火焰作为动态来源参与照明。
- 边界与区分：不自动新增蜡烛火把，变化不过度掩关键信息。

<a id="lit26"></a>
## LIT26 已给发光特效
- 定义与效果：专项已明确的光效对周围产生照明。
- 边界与区分：照明不负责补特效本体，触发结束继承。

<a id="lit27"></a>
## LIT27 制作补光
- 定义与效果：不作为剧情实体的拍摄照明选择。
- 边界与区分：需明示并在授权范围，不凭空新增画内灯。

<a id="lit28"></a>
## LIT28 低角度日光
- 定义与效果：太阳高度较低时的有条件方向性照明。
- 边界与区分：不以标签直接断言金黄或适合所有情绪。

<a id="lit29"></a>
## LIT29 暮光
- 定义与效果：日落后天空等来源参与的光线条件。
- 边界与区分：不等于纯黑或固定蓝色，具体条件需依据。

<a id="lit30"></a>
## LIT30 月夜条件
- 定义与效果：既定夜景来源及可能月光的表现选择。
- 边界与区分：未给不强加可见月亮、蓝色或超强月光。

<a id="lit31"></a>
## LIT31 霓虹与发光标识
- 定义与效果：已有发光标识形成局部颜色与反射。
- 边界与区分：标识文字与颜色不能为美感擅造或修改。

<a id="lit32"></a>
## LIT32 车灯与移动来源
- 定义与效果：随已定物体运动改变照射方向与范围的来源。
- 边界与区分：移动路线和进入退出接点需明确，不恒定贴脸。

<a id="lit33"></a>
## LIT33 闪电与短暂来源
- 定义与效果：输入已给的短时发光事件及影响。
- 边界与区分：不为惊吓自动添加，不能用频闪遮唯一关键过程。
