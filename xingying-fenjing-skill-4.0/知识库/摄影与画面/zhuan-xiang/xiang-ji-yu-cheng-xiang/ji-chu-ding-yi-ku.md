# 相机与成像

参照：[S11](../../lai-yuan/quan-wei-lai-yuan.md#s11)、[S12](../../lai-yuan/quan-wei-lai-yuan.md#s12)、[S13](../../lai-yuan/quan-wei-lai-yuan.md#s13)、[S14](../../lai-yuan/quan-wei-lai-yuan.md#s14)；本地原方法与用户规则L01/L02；应用综合为L03。参照只覆盖来源登记列明的事实，其他创作选择不是权威定律。知识状态：资料核对与文本组织，未实片验证。

本库提供定义与判断边界，具体裁切和角度以项目约定为准；软件参数只适用所标版本。

<a id="cam01"></a>
## CAM01 相机与镜头分工
- 定义与效果：机身记录成像，镜头组织投影，画面还受照明和处理影响。
- 边界与区分：品牌不是情绪或电影感保证。

<a id="cam02"></a>
## CAM02 画幅与有效成像区
- 定义与效果：实际使用传感器区域和裁切模式决定视角条件。
- 边界与区分：全画幅名称不等于所有模式同视角。

<a id="cam03"></a>
## CAM03 Super35与全画幅
- 定义与效果：常用成像区类别，具体尺寸依设备模式。
- 边界与区分：不把任一焦距跨画幅视角等同。

<a id="cam04"></a>
## CAM04 焦距与视角
- 定义与效果：焦距配合有效成像尺寸影响取景角度。
- 边界与区分：不能单凭焦距定义景别，距离也决定主体大小。

<a id="cam05"></a>
## CAM05 视点与透视
- 定义与效果：相机位置决定前后物体的几何相对投影关系。
- 边界与区分：长焦压缩常包含后退机位，不单是焦距魔法。

<a id="cam06"></a>
## CAM06 广角与长焦效果
- 定义与效果：较宽视角或较窄视角的相对描述，需依画幅。
- 边界与区分：广角不必畸变，长焦不必浅景深到无法兼顾对象。

<a id="cam07"></a>
## CAM07 镜头畸变
- 定义与效果：镜头投影相对理想模型的形变。
- 边界与区分：与近距离透视夸张、画面滚转分开。

<a id="cam08"></a>
## CAM08 变形宽银幕
- 定义与效果：横纵方向成像特性与后续解压相关的镜头方式。
- 边界与区分：不是所有宽画幅都用变形镜，不自动加横向光斑。

<a id="cam09"></a>
## CAM09 曝光与动态范围
- 定义与效果：曝光安排场景信号位置，动态范围描述可记录亮暗跨度及条件。
- 边界与区分：不能靠增加分辨率挽回已剪掉高光。

<a id="cam10"></a>
## CAM10 ISO与曝光指数EI
- 定义与效果：不同设备的增益或标定与监看选择，需按机型解释。
- 边界与区分：提高EI不必增加传感器实际进光，不承诺消除暗部噪声。

<a id="cam11"></a>
## CAM11 快门角与曝光时间
- 定义与效果：既定帧率下t＝角度÷360÷帧率，单位秒。
- 边界与区分：180°快门不等于180°空间轴线规则。

<a id="cam12"></a>
## CAM12 帧率与播放速度
- 定义与效果：拍摄和播放速率共同决定动作速度呈现。
- 边界与区分：高帧率不自动就是慢放，变速不能改原已定动作因果。

<a id="cam13"></a>
## CAM13 滚动快门与运动伪影
- 定义与效果：传感器逐行读出和快速运动可产生几何或闪光伪影。
- 边界与区分：不是所有机型相同，不为未知型号编量化结论。

<a id="cam14"></a>
## CAM14 分辨率与可读性
- 定义与效果：像素只是细节条件之一，还受取景、对焦、模糊和显示影响。
- 边界与区分：4K不能保证画内极小文字清楚。

<a id="cam15"></a>
## CAM15 设备参照与生成目标
- 定义与效果：真实相机参数是设计或制作条件，生成模型未必准确模拟。
- 边界与区分：未经生成验证不声称品牌提示必达成对应效果。
