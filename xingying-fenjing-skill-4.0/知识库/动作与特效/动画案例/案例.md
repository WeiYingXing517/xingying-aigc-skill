# 可调用分镜案例

以下为原创演练，适用性取决于场面既定空间、剧情结果及效果设定。

<a id="df01"></a>
## DF01 蓄势、释放与落点

适用：效果来源、目标和作用点已知，剧情允许先让观众辨认两者。桥侧中远景同框法印、桥身和北门圆槽；人物手稳定，最后一根淡青光丝仍在向印心收拢。合拢触发释放，切到桥侧中景。摄影机随释放短横移，前景栏柱退出，圆槽上沿完整露出后持稳。指宽青白弧带沿桥向北，内侧亮线先抵达槽沿，半透明青晕随后沿槽边展开。反光短暂扫亮相邻石砖，弧带消失后槽沿留一截附着亮纹，细屑仍落向门槛。若剧本要求先隐藏落点，内部仍确定该位置，按已定揭示顺序取景。B 首镜从实际切出阶段继续。

<a id="df02"></a>
## DF02 高速位移与地标

适用：两名角色的位置变化是下一拍的理解前提。先用桥侧同框建立桥柱、门洞与双方。角色离开桥柱时摄影机沿同侧跟移，让桥柱从画幅边缘退出，目标门洞保持可辨；接近门洞时切到守在门洞侧的固定中景，从相同位移阶段接入。角色在门洞两侧停稳后留到观众读清新站位，再接下一事件。若效果尾迹已建立方向，可让尾迹短暂保留在来路，维持主体轮廓的辨认度。已锁定一镜到底时，在同镜内完成跟移、持稳和关系重建。

<a id="df03"></a>
## DF03 近身交锋的同框与切点

适用：虚构交锋的叙事重点是读清接触及双方最后分开的位置。门洞侧中景固定，先让两人和门槛同框。两件道具在画幅中央短促交会，接触时保持双方轮廓及道具可见；若需要强调细节，接触刚成立时切局部，下一镜从接触已经成立开始。动作结束后回中景确认两人分别停在门槛内外，再接其中一人的视线变化。若接触只承担过渡，保持同框完成交会与分开即可。交接记录双方位置、道具归属及是否已分开。

<a id="df04"></a>
## DF04 遮挡解除与残留

适用：剧情已有阵面破裂和局部余效。先用中远景建立阵面挡住对岸人物，石栏仍可见。中景固定等到裂纹由原接点到达阵面边缘，接快速破裂。阵面主光熄灭后，对岸轮廓露出，石栏边缘只留附着亮纹，亮纹继续收暗。下一镜从轮廓已经露出接人物认出对方。若分段切在破裂后，承接点记录阵面停止产生新亮纹、对岸已可见、石栏亮纹尚未消退；后段全程不出现的人物省略其状态。

<a id="df05"></a>
## DF05 大范围特效与多人视点

适用：大效果确实影响场景，观众需要知道各组人物相对效果的位置。先用较宽固定镜头保留两组人物、门洞和效果边界。效果推进时，主体是一道贴地半透明弧边，细粒子延后散开；把最亮部分放在弧边，人物轮廓保持可辨。弧边经过门槛时，近侧石面短暂受光，远处背景保持原有曝光。接另一组人物反应时，用门洞或同一条弧边接住空间；需要改观察方向时，先由宽镜确认新位置。效果退去后给仍影响后续的场面状态留辨认时间。

<a id="df06"></a>
## DF06 同镜拉快与慢放交会

适用：作用点已建立，项目允许变速，需要读清效果触点及层次。沿桥侧拍青白弧带，弧带离开法印后拉快行进。逼近北门门心圆槽上沿时进入慢放，摄影机在接点前持稳，让观众依次读清亮芯触石、半透明青晕铺开、细屑离开槽沿。第一批细屑离开槽沿时恢复常速，随后可拉快弧边的扩张。场内接点始终是圆槽上沿；变速阶段以这些事件或已定成片秒点划分。

<a id="df07"></a>
## DF07 慢放后切常速大景

适用：近处交会的因果已经读清，下一镜负责呈现场面范围。以《孤剑断潮》原创示例为例，S03 在旧门槛北沿中央首次交会时慢放，第一批石屑离开石沿时恢复常速，随后拉快弧边横向展开。东端抵达断柱基座时切到 S04 常速固定大远景。S04 首帧弧边已经铺开，石屑还在下落，随后剑幕升起。若在两镜之间分段，B 记录首次交会已结束、弧边东端已抵断柱、石屑仍在下落，首镜从常速接入。
