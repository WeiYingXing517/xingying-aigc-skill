# 身体与操作基础定义

版本0.1.0，本地执行口径，来源与验证状态见[索引](../suo-yin.md)。不作为专业运动或医疗指导。

<a id="b01"></a>
## B01 启动与行动目的

定义：启动是从已有姿态进入行动的必要过程，目的决定动作要完成什么。准备动作不是每次都要补的前奏。

口径：注意对象、起始支撑、必要身体准备和开始接点。例：手已在杯旁可直接接稳提起，不必先抬头、深呼吸再伸手。与情绪标签区别：写“急切”仍需说明速度和终点。未知目的不能补偷窃、威胁等含义。应用BA01、BA02。

<a id="b02"></a>
## B02 支撑与重心

定义：支撑维持身体或物件稳定；重心变化影响起坐、俯身和制动能否完成。不是所有动作都要逐关节标角度。

口径：当前承托、必要重心移动、可用下肢或手部支撑。例：从已有坐姿起身需合理转移支撑，不能凭空站起或统一撑不存在的扶手。身体限制沿用资料，不虚构伤病。应用BA04。

<a id="b03"></a>
## B03 速度、力度与幅度

定义：速度是动作快慢及变化，力度是作用强弱，幅度是位移或姿态变化范围，彼此独立。

口径：快速启动、目标前减速、轻扶、稳定托住、短距离移动等。例：急递也可末端受控；轻拿不必全程慢动作。动作幅度大不证明情绪强。风险是用速度代替力度、所有动作匀速或无依据砸物。应用BA01、BA03。

<a id="b04"></a>
## B04 接触与释放

定义：操作物体需在相应接触和支撑条件成立时抓取、移动或释放。放下、递交与丢弃的事件结果不同。

口径：手侧、接触部位、接稳、原支撑脱离、新支撑建立、释放与归属。例：接收方接稳后递出方释放；不得双方同时松手或同物复制。简单动作可压缩描写，但不能压掉条件。应用BA01、BA02。

<a id="b05"></a>
## B05 收束与动作过渡

定义：收束是动作达到目的后的停止或接下一行动；过渡继承当前动量、姿态与任务，不是归零重启。

口径：终点、速度回收、最终姿态、手部和物件状态、下一条件。例：放稳文件后手释放，继续原对话，不自动直立微笑。过多停顿可能僵硬，但真实等待有作用，应保留。应用BA03、BA06。

<a id="b06"></a>
## B06 并行与注意分配

定义：不同动作或发声可在可执行条件下重叠；并行不是所有事情同时开始结束。注意分配需满足精细操作与交流信息需求。

口径：边说边递、说到某词时接稳、操作结束后继续发声等。例：递文件过程中说完整句，交接先结束不意味着台词同步截断。口部占用、精细判断或锁定先后可能限制并行；冲突时协调，不自改时序。应用BA05。

<a id="b07"></a>
## B07 口物接触阶段

- 定义与效果：手与物的握持、物与嘴的距离、口部当前动作是三种独立关系。物件接近唇边时仍可能留有间隙，已经抵唇也未必咬住。
- 边界与区分：区分接近、碰到唇齿、咬合或含住、分离。咬痕、缺口与液面变化需要可见结果或已知依据。手侧和握点可在物件离嘴后继续保持。
- 可见依据：当取景遮住唇齿时，可见嘴边位置、手和物的关系仍可描述，遮住的接触阶段取已有依据。并行发声条件见 [F04 发声中的表情](../mian-bu/ji-chu.md#f04)。
