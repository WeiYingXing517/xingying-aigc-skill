# 人声与台词应用场景

版本0.1.0，全部为条件化说法候选，未做实际听音实验。来源见[索引](../suo-yin.md)。原台词及标点保持，下面说明不替换原文。

<a id="va01"></a>
## VA01 同句不同交流任务

- 条件与目标：原文“你来了。”，上下文已明确本句是确认或欢迎。
- 候选与理由：确认到场可自然平稳收束；欢迎可较放松、连贯，带适度笑意。选一种符合任务的方式，不混三种意图。
- 配合：欢迎时面部候选按人物选择；确认不强加惊讶。
- 排除与替代：无依据不改质问、讽刺或挑战；语境关键歧义先确认。
- 正反例：同词不同任务分别设计；把标点改成问号就宣称完成表演为反例。关联V01、V05。

<a id="va02"></a>
## VA02 高兴但不喊叫

- 条件与目标：喜悦明确，表现自然，场合不需大音量。
- 候选与理由：在原声线内较放松轻快，重点落于结果词，词段连贯、句尾自然收住；使声音承担表达而非只有情绪名。
- 配合：面颊眼周笑意可延续，嘴部正常发音，身体可保持。
- 排除与替代：不强制升调、全句气声、每词重读或加笑声。外放风格明确时可另调幅度，不套本条音量。
- 正反例：“太好了。”突出“好”，不过分拖长；“开心、热情、有情绪地念”缺执行为反例。关联V02、V04、FA06。

<a id="va03"></a>
## VA03 低音量但坚定

- 条件与目标：明确要轻声表达立场或要求，不是无力或犹豫。
- 候选与理由：关键词相对突出，语流不散，句尾清楚收住；音量保持低，力度不被替换成大声。
- 配合：稳定注视或已有姿态即可，不必前倾威胁或攥拳。
- 排除与替代：低音量不等于耳语，坚定不等于攻击；有礼貌约束时保持。
- 正反例：低声说“请把门关上。”并清楚收尾；自动喊成命令或尾音虚弱为反例。关联V03、V05。

<a id="va04"></a>
## VA04 信息焦点明确

- 条件与目标：指定重点词，例如“明天见。”重点是“明天”，用于确认日期。
- 候选与理由：相对突出“明天”，其他词自然连接；实现方式按原语气选，不默认增加音量和停顿。
- 配合：不为强调额外点头、指人或改变台词。
- 排除与替代：用户只要求咬字清楚时不能擅设信息重音；多处强调须有依据。
- 正反例：重点词相对突出；每个字都重读或把“明天”换成其他词为反例。关联V02。

<a id="va05"></a>
## VA05 安慰而不制造哭腔

- 条件与目标：明确安慰对方，情境未要求自己悲痛或落泪。
- 候选与理由：声音稳定、语流留给对方理解的空间，关键肯定词清楚，句尾柔和但不消失；具体停顿依词句。
- 配合：面部和身体表达关注，避免机械微笑、连续点头或拥抱，除非已有授权。
- 排除与替代：不自动耳语、叹气、哽咽；需要鼓励行动时可增强力度，不必变慢。
- 正反例：清楚、稳定的支持性表达；用拖慢每字和哭腔代替安慰为反例。关联V01、V04。

<a id="va06"></a>
## VA06 原稿明确被打断

- 条件与目标：已有确定打断词段和人物关系，需保留原文及发声事实。
- 候选与理由：完整原词单独保留，实际发声范围标到被打断处，另一人按原接点进入；未发声部分不得误当已说。
- 配合：人物是否收口、转看对方依真实时序；同句后续提供剩余词段和语气关系。
- 排除与替代：不能为增强戏剧性自行截句，也不为模型方便改成顺序轮流。
- 正反例：原文“我只是想告诉你。”，原剧情说到“想”被打断，则实际词段止于“想”；直接删掉后半句原文是反例。关联V05、C03。
