# 交流与连续性基础定义

版本0.1.0，本地工作口径。来源及验证状态见[索引](../suo-yin.md)。

<a id="c01"></a>
## C01 信息到达与角色反应

定义：角色反应依据其实际可获得并已理解的信息，不依据观众掌握的一切。可听、注意、理解和回应不是同一个事实。

口径：实际事件、关键词、媒介和角色可用范围。例：在听到“录用”后反应，不在对方开口前完成惊喜。提前预期需剧情依据；内心OS不自动被其他人听见。应用CA01。

<a id="c02"></a>
## C02 状态继承与画外进度

定义：连续场景中角色、动作和物件状态持续存在，切镜或未展示不归零。画外进度可创作，但观察未知不能冒充看见。

口径：已完成、进行中、未开始、保持、回收与残留。例：听者上一段已浅笑，下一段继承，不重新演笑；持杯不因没拍到消失。时间经过不证明操作必然完成。应用CA02、CA04。

<a id="c03"></a>
## C03 制作边界与剧情边界

定义：生成单元分开不等于人物停顿；切镜不等于一句结束。转场或省略则可能有真实时间变化，须分别处理。

口径：同句续说、完整句接话、时间省略。提供前段已说与后段剩余词段，话轮和语气接点。例：句内跨段不默认换气重起。应用CA03。

<a id="c04"></a>
## C04 通道协调与合理反差

定义：身体、面部、人声属于同一行为，需物理相容、目标有依据；不要求所有通道完全相同。

口径：共享触发、并行或先后、保持项与反差依据。例：礼貌笑但声音克制有条件可行；嘴持续紧闭却正常说话是硬冲突。不能为了协调消除原文明示掩饰，也不能擅造掩饰来解释矛盾。应用CA05。

<a id="c05"></a>
## C05 时间容量与并行覆盖

定义：采用时长需容纳必要先后过程；可并行过程取覆盖而非全部累加。

口径：实测或估时、原接点、可用时长、不可删环节。例：递交与一句话并行不应把二者时长相加，但手部接稳仍不可省。锁定时长无法容纳则协调，不暗删词或延镜。应用BA05及验收T11。

<a id="c06"></a>
## C06 信息可读性与表现选择

定义：设计必须有观众可接收的承载方式；角色有状态不代表观众已看见或听懂。

口径：当前可见范围、音频可用条件、关键载体与替代。例：背面镜头不可依赖嘴角变化，可以选择有依据的身体或人声表现，或向摄影提出需求。不能自行切特写或夸张动作补曝光。应用CA06。
