# 中途建议与局部修订专册（多轮防失忆与高质改稿）

本专册统管 01—04 任意阶段运行途中用户提出**观感反馈、方向建议、局部增删改、弹卡期插问或调整设置**时的执行标准。核心目标：**改得准（口语建议转物理视听、不动无辜镜头）、算得齐（五链涟漪追平不穿帮）、不断流（修完自动接回原流程下一步，绝不失忆退化）**。

---

<a id="state-anchor-bar"></a>
## 一、双保险防失忆机制：每轮顶部锚点条 ＋ 触发式重读

多轮对话中长分镜输出极易稀释早期读取的规则注意力，必须用以下双机制锁死状态记忆：

1. **每轮回复顶部必带一行「星应进度锚点」（严禁放进 04 纯净复制块内）**：
   - 无论轻量单场模式还是长剧项目模式，每轮回复最开头（04 置于复制块外最上方）输出极简一行：
     `【星应进度锚点】当前阶段：[01理解/02资产/03双栏预览/04分段提示词]｜已锁基准：[片型·细分·画幅·质感·主色调·分段规则]｜挂起待办：[未答完选项卡或原定下一步]｜本轮动作：[本轮执行或修订摘要]`
   - 作用：让紧邻下一轮的上下文永远携带最新状态机、已锁制作条件与未完待办，聊 20 轮也不丢进度。
2. **中途插话「强制重读刷新」门禁**：
   - 运行途中凡收到用户修改意见、吐槽或局部调整，若最近 2 轮内未读取本专册及当前阶段 `模板.md`，**动笔前必须实际调用读取一次**，将防跑偏底线重新刷入近期注意力末端，禁止仅凭模糊印象裸改。

<a id="four-step-state-machine"></a>
## 二、四步锁界修订状态机（挂起 → 转译 → 追平 → 续跑）

<a id="freeze-zone"></a>
### 第 1 步：挂起定界（划清「修改靶区」与「冻结保护区」）

1. 读取上一轮 `【星应进度锚点】`（长剧模式同步核[项目关卡](项目交接与恢复.md#project-gates)与 `项目.json`），记录被打断前的所处阶段及尚未完成的确认卡或下一步。
2. **严锁「冻结保护区」**：凡用户**未点名要求改动**的镜头、原剧本逐字台词、已确认制作基准、已锁角色外观与未受波及的分段，**一律 100% 冻结原样保留**，严禁借局部修改把整场满意镜头推倒重洗。
3. **硬冲突先报不暗改**：若用户建议与原稿硬事实、前集生死/伤势连续性（[状态管理](剧情连续性与状态管理.md#state-entry)）或已确认分段秒数硬上限（如加戏后单段超 15 秒/30 秒）直接冲突，先用 1–2 句点明具体冲突及两个可行解法（如拆入下分段 vs 收紧相邻过场拍）请用户拍板，绝不暗删原台词或硬塞超标段。

<a id="oral-translation"></a>
### 第 2 步：导演感口语建议 → 物理视听动作转译矩阵

遇到口语化、感受型建议时，**严禁贴膏药式硬塞抽象形容词**，按以下矩阵转译为具体镜头与物理动作：

| 用户常见口语建议 | 严禁敷衍改法（黑榜） | 正确可执行改法（红榜） |
|---|---|---|
| **“太拖了 / 前面太水 / 节奏再紧点”** | 加速念台词、偷删关键原词，或乱切成 0.2 秒碎镜 | 按[持续动作覆盖](03-分镜/流程.md#action-coverage)与[冗余动作4招](03-分镜/排镜与摄影细则.md#redundant-action)砍无信息走位/起势（留头掐尾+声桥）；把串行的说话与手脚动作改为[词动铆钉](文风锁与黄金样板.md#sync-action-dialogue)同镜并行不叠加时长；收紧多余尾拍。 |
| **“太赶了 / 情绪没立住 / 翻脸太突兀”** | 硬塞“内心掀起惊涛骇浪、眼神复杂”等网文词或无故插空镜 | 在反转或重话前补 0.5–1.5 秒听者可拍微停顿（指尖顿在杯沿、目光微偏）或关键物证插入镜（[细节覆盖](03-分镜/流程.md#detail-coverage)），留足「信息到达→消化→爆发」节拍。 |
| **“角色气场太弱 / 反派压迫感不够”** | 写“浑身散发恐怖王者气场、压迫感拉满” | 调机位与空间主动权：施压者占前景或用低机位微仰（[ANG-A01](../知识库/摄影与画面/zhuan-xiang/ji-wei-yu-jiao-du/ying-yong-chang-jing-ku.md#ang-a01)）、慢步逼近压缩功能距离、暗影切半脸；受压者退路受阻贴墙或坐姿受迫。 |
| **“打得不够爽 / 不够燃 / 慢镜软绵绵”** | 堆砌 `240fps/水墨光效/360°狂抖` 或回合制对砍 | 按[交锋推演](03-分镜/排镜与摄影细则.md#action-choreography)把站桩互砍改为破防零碎闪拍接借力反杀（[C09](../知识库/动作与特效/武打/zhi-shi-ku/tiao-jian-zu-he.md#c09)/[C10](../知识库/动作与特效/武打/zhi-shi-ku/tiao-jian-zu-he.md#c10)）；叠加上「压簧前摇→广角贴地后掠介质突进→咬合顿挫」（[TIM-A11](../知识库/摄影与画面/zhuan-xiang/shi-jian-yu-jie-zou/ying-yong-chang-jing-ku.md#tim-a11)＋[MOV-A21](../知识库/摄影与画面/zhuan-xiang/yun-jing-yu-jiao-dian/ying-yong-chang-jing-ku.md#mov-a21)）与身体凹陷＋地面介质双反馈（[X11](../知识库/动作与特效/武打/zhi-shi-ku/chang-jing-ying-yong.md#x11)）。 |
| **“这里加个动作 / 摔个杯子 / 补个伏笔细节”** | 只往单镜硬塞一句，前后镜手侧和地面干干净净 | 核对起态手侧占用与发声口部互斥；将新增道具状态、脱手落点或碎裂痕迹同步写回空间快照、02 资产需求及后续全部关联镜。 |
| **“换个画幅（横改竖）/ 换画风 / 改主色调”** | 只改头部标签，正文构图与光影原封不动 | 更新全局基准；横竖改版按 [CMP-A08](../知识库/摄影与画面/zhuan-xiang/gou-tu/ying-yong-chang-jing-ku.md#cmp-a08) 重核纵深同框或正反打裁切（不搬动锁定站位）；改色调/质感同步刷新 04 块首【全局风格与光色】与逐镜受光特征。 |

<a id="ripple-propagation"></a>
### 第 3 步：五链涟漪追平与五项底线重锚（治“改一处崩三处”）

局部修改落定后，交稿前强制顺着 **5 条涟漪链**向后追平，并过一遍 **5 项防退化快检**：

1. **五链涟漪追平**：
   - **① 时间码顺延链**：第 `i` 镜时长增减 `±Δ秒`，第 `i+1…N` 镜起止时间码必须全部同步平移；在 04 须重核本段总长仍为正整数且严格 `≤ 所选秒数上限`（[分段时长与压缩](04-提示词/流程.md#分段时长与压缩)，超限则按宁短勿超提前切段）。
   - **② 空间与战损链**：改了走位、换座、破门窗或打碎器物，立即按[空间状态更新](空间基准与调度.md#space-transition)刷新「新站位快照」与场景完损，后续镜头与反打背板同步重算投影，严禁切镜自动复原。
   - **③ 手物与人物状态链**：改了拿放、夺刀、受伤或知情时刻，追平后续手侧占用、伤势衣损与反应触发点；长剧项目模式调用 `项目管理.cjs affected` 标记受波及下游待复核。
   - **④ 唯一母稿同步链**：无论在 03 还是 04 改了镜头拍法、动作或时长，**必须同步更新当版[内部十四项母稿](03-分镜/流程.md#视频转写前的内部十四项)**，严禁双栏、十四项、04 提示词各自为政产生矛盾。
   - **⑤ 跨段承接链**：在 04 修改第 `K` 段的末尾姿态、持物、战损或说话语气时，**必须同步更新第 `K` 段块外【本段结束与后续交接】以及第 `K+1` 段块内[【上一段承接点】](04-提示词/流程.md#上一段承接点)与首镜 0 秒起态**。
2. **防失忆 5 项底线快检**：
   - [ ] 复制块内是否仍保持**零网文抽象词、零“东西南北”、零裸写剪辑转场词**（[术语转译](转场与运镜衔接专册.md#no-raw-jargon)、[物理化](04-提示词/可观测写法.md#physicalize)）？
   - [ ] 角色参考音色/声纹锁图是否仍**只在块首人物后缀绑定一次、逐镜「音频与对白」零重复**？
   - [ ] 常规输出是否仍标 `分镜 1…` / `分段 1…`（无默认 `大段`），按秒分段严格 `≤ 所选上限`？
   - [ ] 是否仍严守**零默认首尾帧**（仅在用户本轮建议明确提供或要求首尾帧时才启用）？
   - [ ] 双栏是否仍写齐机位高度/俯仰/焦段景深，04 块尾是否仍保留固定【画面约束】？

<a id="delivery-and-resume"></a>
### 第 4 步：分阶段标准交付粒度 ＋ 自动续跑原流程（Auto-Resume）

拒绝“挤牙膏只发半截残片”或“修完原地发呆断流”，严格按所处阶段交付并自动接回下一步：

| 被打断时所处阶段 | 本轮标准修订交付物 | 自动续跑动作（严禁断流停摆） |
|---|---|---|
| **弹卡确认等待期**（01 制作基准卡 / 04 分段与缺图卡） | 先用精炼几行回应用户建议或疑问，将已明确的条件记入锚点并更新读剧快照/前置记录 | **同轮末尾立即重新弹出剩余尚未确认的强制选项卡**（见[强制确认清单](制作设置与强制确认.md)），绝不漏卡，也不私自替用户定案 |
| **01 剧本理解与事件期** | 更新受影响的场戏透视点、事件节拍表与状态事件（未改事件保原编号） | 已齐备基准则主动推进/引导进入 **02 资产清单** 或 **03 双栏分镜** |
| **02 资产与声纹锁期** | 输出更新后的对应角色/场景/道具/声纹锁图条目及绑定职责说明 | 主动衔接进入 **03 双栏分镜**（若用户原意直出 04 则进 04 分段确认） |
| **03 双栏 / 十四项分镜期** | **严禁只吐单个修改镜残片！** 顶部 1–2 行标明本轮改了哪几镜及时间顺延，紧接输出**保留未改镜原文＋重算完整时间轴后的整场分镜表** | 末尾明确询问是否满意并接回原下一步（确认后直接进 **04 视频入口弹分段卡**） |
| **04 视频 / 分镜图提示词期** | **直接输出受影响分段的完整可直接复制替换块**（含块外对照与交接卡；若波及下一段承接点，一并输出更新后的下一段完整块）；未受波及的分段注明`「分段 X 未受波及，继续沿用原采用块」`不刷屏、不偷改 | 若此前分批交稿尚未交完剩余分段，修订确认后继续交付剩余分段或进入 G5 归档简报 |
