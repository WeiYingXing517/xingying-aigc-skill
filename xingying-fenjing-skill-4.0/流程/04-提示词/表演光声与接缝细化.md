# 04 表演、光声与接缝细化（按需查阅）

本文件收录人物表演与口物接触细节、双面小道具与单实例锁、光色材质与音源基础、空间摄影细化、正文声画对齐及文字/成片接缝检查。常规转写先走[04 提示词主流程](流程.md)、[04 提示词模板](模板.md)与[转场与运镜衔接专册](../转场与运镜衔接专册.md)，仅在需要细化表演、光影声音或排查接缝时按需查阅对应章节。

<a id="part-15-人物表演与日常动作"></a>
<a id="part-15"></a>
## 人物表演与日常动作

先读人物当下已经知道什么、正在做什么、关注谁，以及本镜需要观众看懂的变化。确定触发，再选当前景别能读到的表现。允许自主润色表情、目光、重心、手部和说法，细节要符合人物、空间和已有动作进度。一次动作和一次发声在同一事件中完成。

| 要解决的问题 | 怎样决定 | 按需查询 |
|---|---|---|
| 听者何时反应 | 找到足以理解的信息，写反应从哪个词、声音或动作开始。原稿只给“听完”时按句尾。前半句已让角色获得足够信息且表演允许时，反应可以与后半句并行。只有某个词确实足以触发才绑定到该词。 | [信息到达与反应](#part-15-信息到达与反应) |
| 表情、视线怎样变 | 看清开场脸和目光的落点，选一两项能看见的变化。若当前景别看不到眼神，用身体转向、停顿或行动表现。分别确认眼睛、头、身体和手的任务。克制或掩饰可按人物目标用说法、动作或视线形成反差。 | [可见形态](#part-15-可见形态) |
| 递、拿、放、扶、起身或进食 | 定支撑、手侧、握点和接触。按接近、接触、持续或释放的真实阶段写，切在中间时交接未完成状态。进食、饮用或吹奏与发声并行时，核口部当下是否能发声，按剧情安排咬合、吞咽、咀嚼和断句。 | [接触阶段与状态传递](#part-15-接触阶段与状态传递) |
| 角色这一句怎么说 | 依据说话目的、受话者、呼吸和当下任务写可执行的说法。固定音色/声纹锁图仅在块首人物后缀绑定一次（参考音色优先，无则绑声纹锁图并明写画面严禁出现声波图形或文字，逐镜绝不重复），重音、停顿和声量变化写在该镜；原词保留。 | [发声与原词](#part-16-发声与原词) |

把起始姿态、可见神情和手部起态写入「镜头与构图」或开场站位。身体动作、视线、面部表情分别判断，成稿按事件合写到本镜「画面与动作」的同一个段落。原词和说法写入「音频与对白」，对准同一事件接点。会延续的目光、表情残留、动作进度或接触写入「切出与防穿帮」。出图时只采用选定瞬间可见的姿态和神情。

<a id="part-15-信息到达与反应"></a>
### 交流、注意力与反应

- 人物已知的事、此刻新得到的事与观众知道的事可以不同。反应从人物可听、可见或可触的足够信息开始。
- 听者不一定等说话结束才变化。前半句已足够时，可边听边抬眼、停手或继续工作。
- 眼睛、头、身体与手可以关注不同目标。说话者和画面主体可以不同，画外人物仍在场且任务可延续。

<a id="part-15-逐镜面部表演核对"></a>
### 逐镜面部表演核对

准备内部十四项时检查本镜参与者，转写时核对已采用的面部表演。把起始神情写入开场站位或「镜头与构图」，把镜内变化和动作合写进一段「画面与动作」：

1. **看得到谁的哪一部分脸**：按景别、光线、朝向与遮挡确定；脸完全遮住时从可见身体或有依据的声音表达。
2. **脸上需要看到什么**：核对每位面部可读的参与者，只输出承担本镜信息、人物表现或接续作用且有依据的神情，不逐人强配面部句子。动作或视线已足够时不重复解释情绪；原稿和采用版的必要表演完整保留。
3. **何时变、何时保持**：表情变化落到人物能感知的词、动作或声音，并与动作同段合写。无新变化不重复启动同一反应；跨镜沿用实际表情残留。

<a id="part-15-可见形态"></a>
#### 可见形态与视线姿态

- 正面或近景可选眉、眼睑、面颊、嘴角和下颌；侧面、远景或遮挡按可见范围选表现。
- 边说边笑由眼周、面颊或句间延续笑意，嘴部按词发音；吞咽、咬住物件、闭口咀嚼须与发声兼容。
- 视线描述目标与转移时机；原地站定、转头、转身、移步分别是不同状态。按问题查 [F01](../../知识库/人物与声音/zhi-shi-ku/mian-bu/ji-chu.md#f01)、[F02](../../知识库/人物与声音/zhi-shi-ku/mian-bu/ji-chu.md#f02)、[F04](../../知识库/人物与声音/zhi-shi-ku/mian-bu/ji-chu.md#f04)、[CA01](../../知识库/人物与声音/zhi-shi-ku/jiao-liu/ying-yong.md#ca01)。

<a id="part-15-接触阶段与状态传递"></a>
### 身体支撑、接触与操作

| 状态 | 可见依据 |
|---|---|
| 原支撑 | 物件仍由桌面、身体或他人托住，手的接近不等于已拿起。 |
| 稳定握持 | 手侧、握点、物件朝向及目前支撑。两手共握属于独立状态。 |
| 转移与释放 | 接受方接稳后原持有人可松手。物件离手才改为空中、落下或新支撑。 |
| 力度与收势 | 重心、速度、幅度与惯性共同决定轻放、坠落或抛出。 |

接近、首次接触、持续接触、分离和后果各自有不同首尾状态。进食/饮用/吹奏时，手物握持与物嘴接触独立变化；辨认口物阶段查 [B07](../../知识库/人物与声音/zhi-shi-ku/shen-ti/ji-chu.md#b07)，其余查[人物表演索引](../../知识库/人物与声音/zhi-shi-ku/suo-yin.md)。

- **双面小道具正反面朝向锁**：手机、照片、信件、证件、令牌等带信息面的小道具，不展示内容时必须明写“背面朝镜头，屏幕/字面朝向手心或桌面不可见”（严防模型把手机背面也画成发光屏幕或乱码）；需展示时明写“信息面朝镜头”及唯一允许可见内容。
- **同道具单实例互斥锁**：当场景图/开场画面内已有某关键道具（如桌上手机/佩剑），同时参考素材又绑定了该道具外观图时，必须点明“该参考图即场景中同一件道具、全场仅此一件；人物拿起后原位置变空，严禁原位与手中同时各出现一件”。

<a id="part-16-光色与声音细化"></a>
<a id="part-16"></a>
## 光色与声音细化

<a id="part-16-光色与材质"></a>
### 光色与材质

继承 01 采用的画面质感、成像、基础光色和风格。把相机或渲染器参考落实为可见反差、颗粒、受光与材质特征；动漫制作按画风落实线条、色块、明暗与材质；混合质感按场次、对象或画面层范围继承。根据时空、参考和锁定条件写光源来源、相对地标方向、遮挡、受光对象和变化接点；换机位重算亮面与反光，若受光负责揭示证据则明写显露时机。全段共用条件集中写进段首【全局风格与光色】，镜内只写变化。需要效果发光时查[特效索引的场景交互](../../知识库/动作与特效/特效/zhi-shi-ku/suo-yin.md#形态与场景交互)，各类介质与能量质感按[特效四维物理显形法则](可观测写法.md#physicalize)现场推演。

- **成像与色彩**：区分题材与视觉画风、景别与透视、景深与焦点；金属反射、湿面亮斑、磨砂漫散射与薄布透光由材质和受光共同决定；换画幅重核裁切。
- **光线与遮挡**：区分明暗对比、硬软光、手/门扇/人物遮挡光路、物体反射与自身发光。固定窗光反打查 [LIT-A01](../../知识库/摄影与画面/zhuan-xiang/guang-xian/ying-yong-chang-jing-ku.md#lit-a01)，走进阴影查 [LIT-A03](../../知识库/摄影与画面/zhuan-xiang/guang-xian/ying-yong-chang-jing-ku.md#lit-a03)，色彩参考查 [COL-A01](../../知识库/摄影与画面/zhuan-xiang/se-cai/ying-yong-chang-jing-ku.md#col-a01)，平涂查 [REN-A05](../../知识库/摄影与画面/zhuan-xiang/xuan-ran-yu-zhi-gan/ying-yong-chang-jing-ku.md#ren-a05)。

<a id="part-16-发声与原词"></a>
### 人声、音源与声画接点

区分画内对白、画外声、旁白与内心独白、动作拟音和持续环境声。固定音色、语言与口音只在块首人物后缀绑定一次（参考音色优先；未提供则统一绑 02 [声纹锁图](../02-资产清单/流程.md#voiceprint-lock)并加“画面中严禁出现声波图形或文字”护栏；纯文字模式挂英文/中文声纹特征词后缀），**逐镜「音频与对白」绝不重复绑定参考音色或声纹锁**，只写当镜音量、重音、断句、停顿、语速、说法、原词照录与词动铆钉。拟音对准触发动作接点；环境声说明延续、衰减或截止（考虑门窗遮挡与距离）；有意先听后见（J剪）或切走续声（L剪）写清与切画面的关系。

- **环境声退让与外语释义隔离**：暴雨、人群嘈杂或激烈交锋中说关键台词时，注明“发声期间环境底噪自然压低退让，人声咬字清晰”，话毕按场景恢复；外语对白在复制块内仅保留目标外语原句（防模型误读或印乱码字幕），中文对照释义一律放块外。
- **慢推消音聚焦（高潮/抉择瞬）**：镜头平稳推近主体面部或关键动作时，可将原有环境底噪逐拍衰减至低沉或近似静音，仅留呼吸、心跳或单一关键拟音以放大专注感；只写可听变化过程，不编无依据配乐。
- **快慢变速与重击命中的声场协同**：局部慢放窗口或极重一击咬合瞬间，可将环境杂音短暂抽空 0.3–1 秒，仅留呼吸心跳、低频余振或单一闷实撞击/金铁崩鸣，恢复常速或提速爆发瞬同步接短促破空风压与脆响卡点（防慢镜无声变卡顿）；发力闷哼、受创抽气须与完整台词口部错开，严禁边挨重击边字正腔圆念长句。
- **空镜慢摇与声音先行（转场缓冲）**：场间转场需呼吸缓冲时，可用无人环境空镜缓慢横摇，同时让下一场环境声或画外首句提前半拍切入（或让上场尾声延入下场空镜），写清声画交错接点。
- **边说边动双轨并行（词动铆钉）**：手脚、步态或视线与发声不冲突时必须同镜并行、不叠加时长；在「画面与动作」写清说话同时执行的身体动作及触发字词，在「音频与对白」用同一关键词标明同步接点（如 `[边翻找边急问]` + `说到“哪去了”同步顿手抬眼`）；进食/饮水/重击憋气等口部互斥动作错开至句前、句间换气或句尾（示范见[词动铆钉写法](../文风锁与黄金样板.md#sync-action-dialogue)）。

## 空间与摄影细化

先读[场级空间基准](../空间基准与调度.md#space-baseline)及有效状态，沿用稳定地标参照，按[画面投影](../空间基准与调度.md#space-projection)推导画面左中右、前中后景和裁切：

- **场内方位与禁东西南北**：以门、桌沿、路口等稳定地标或明确朝向的人物为参照，跨机位保持不变；视频提示词块内彻底禁写“东西南北”，全部转为当前机位视角下的前后左右与可见地标。
- **多人两级锚定与背板锁**：多人同场先用场景图强地标锁死核心锚点人，再用“已锁锚点人＋场景图地标”交叉锁定其余角色（不写孤立的“在旁边”）；为每个主要站位绑定 1 个专属背板地标，切近景/特写时虚化仍点名带出，防“一换近景换房间”。
- **180° 同侧反打投影 4 句硬口诀**：不越轴时逐镜核对——朝向锁定（左人居左朝右、右人居右朝左，不看同一边）、过肩对边互换（拍右人压左肩、反打拍左人压右肩）、背板锁死不互换、手侧不变但投影左右与受光面同步重算（详查[空间基准与调度](../空间基准与调度.md#space-projection)）。
- **轴线与遮挡**：关系轴/动作轴标明地标参照侧；移动中切出与到位停下分开；遮挡区分“仍在场”和“当前可见”。过肩查 [ORG-A02](../../知识库/摄影与画面/zhuan-xiang/jing-tou-zu-zhi/ying-yong-chang-jing-ku.md#org-a02) 或 [DEP-A04](../../知识库/摄影与画面/zhuan-xiang/jing-shen-yu-kong-jian-gan/ying-yong-chang-jing-ku.md#dep-a04)，持物空间查 [SPA08](../../知识库/摄影与画面/zhuan-xiang/kong-jian-yu-diao-du/ji-chu-ding-yi-ku.md#spa08)，转焦查 [MOV-A05](../../知识库/摄影与画面/zhuan-xiang/yun-jing-yu-jiao-dian/ying-yong-chang-jing-ku.md#mov-a05)。拍法缺口回查[03 排镜与摄影细则](../03-分镜/排镜与摄影细则.md#part-14)。

<a id="part-24-正文与声画对齐"></a>
<a id="part-24"></a>
## 正文与声画对齐

从[03 内部十四项](../03-分镜/流程.md#视频转写前的内部十四项)直接转写进统一模板的对应栏目（不再保留旧版 8 栏重复抄写）：

- **镜头与构图**：继承景别、水平方向、机位高度、俯仰、焦段/光圈（无依据不编光圈）、初始焦点与景深，并写清首帧画面位置、裁切、前后景与起始观看重点；固定机位明写，镜内摄影机变化进「画面与动作」。
- **画面与动作**：每镜合写为一个紧致连续段落。按[可观测写法](可观测写法.md)点名行动者、摄影机与特效主语，按触发→行动/反应→结果推进，把动作、视线、表演、摄影机运动、局部受光、物理接触与特效落入同一事件接点；稳态不重复抄写；仅可靠时间写精确秒点，其余用事件接点。
- **音频与对白**：复用「画面与动作」的事件接点，点名发声者、受话者、画内/画外、说法与原词；拟音对准接触点；无则省略。
- **画面文字**：仅有已确认画内文字才写内容、位置与显隐接点；无则整项省略。
- **切出与防穿帮**：写切出时变化后的地标位置、朝向、未完阶段、构图焦点、持物接触与续声；仅在有实际穿帮风险时附局部物理约束。

<a id="part-24-长对白跨镜及话尾接动作"></a>
### 长对白跨镜及话尾接动作

画面转向听者时，点名听者与可见反应，并在「音频与对白」点名原发声者画外继续（只在信息到达后反应，查 [CA01](../../知识库/人物与声音/zhi-shi-ku/jiao-liu/ying-yong.md#ca01)）。

- **同一次生成跨镜**：起声处写完整原句一次，后镜标同一次发声继续及结束接点（查 [SND-A06](../../知识库/摄影与画面/zhuan-xiang/yin-yuan-yu-yin-xiao/ying-yong-chang-jing-ku.md#snd-a06)）。
- **跨独立生成段**：按已确认词段分别写各段实际承担的原词，或按可用连续音轨标区间与剪接职责；无可用词段或音轨时在授权范围内移到合法停连，锁定冲突则报告（查 [CA03](../../知识库/人物与声音/zhi-shi-ku/jiao-liu/ying-yong.md#ca03)）。
- **内心独白与话尾动作**：内心独白不做现场口型；核清动作在发声中还是话尾结束后启动，切在途中则后镜接着未完阶段继续。

## 文字接续与分段检查

逐个检查计划切缝（已有实拍/生成成片另走下方[生成成片接缝检查](#part-22)）：

1. **取对边界与下段衔接工艺**：同段看前镜切出与后镜切入，有剪取按最终计划保留两端；段末块外标明下段衔接工艺（🟢换镜直切用常规资产图独立生成 ／ 🟡连续动作跨段默认走换视角动作相位顺接＋块首0秒动势锁独立直出，**绝不默认要求截末帧或做首尾帧**；仅用户主动提供或要求首尾帧时按[首尾帧按需分支](../转场与运镜衔接专册.md#first-last-frame-optin)核同档景别与端点路径）。
2. **交接 0 秒既成态、延续语气与人数增减账**：核场内地标、背板、朝向、走位阶段、目光、有效神情、持物手侧/握点/接触阶段与特效残留；换机位重算画面投影。续段【上一段承接点】必须写透 0 秒**人物开场状态**与**人物语气状态**，严禁写已完成过去动词（如“刚推门/刚挥刀后”），一律写“已+既成态”防 0 秒重演；**后段若新增前段未入画的具名角色，必须通过首镜方向入画、画外先声（J-cut）、时空空镜或沉默留场者原位依据交代，严禁 0 秒凭空刷出人**；复制块内禁裸写“硬切/J-cut/遮挡转场/本段结束”等剪辑流程词；非全片结束段末镜注明“动作光影自然延续至末帧截止，不提前慢停、不淡黑、人物不看镜头”。进食/饮用切缝核物件位置、唇齿接触、咬合/分离及咬痕或液面（查 [BA07](../../知识库/人物与声音/zhi-shi-ku/shen-ti/ying-yong.md#ba07)）。
3. **核声画与主语**：核发声者、续声进度与叠化重叠；点名每次行动/摄影/特效主语，核[面部表演](#part-15-逐镜面部表演核对)，直接修含糊切口，涉及锁定冲突先确认。

*糖葫芦接点示例*：若前镜保留到女孩右手握竹签、第一颗仍与唇齿接触，后镜换侧面时从同一只手、握点和接触阶段进入再继续咬合或拉开；若前镜已拉离露咬痕，后镜从拉离距离和已咬状态接。

<a id="part-19-生成分段与时间"></a>
### 生成分段与时间边界

- 每份独立生成块写齐开场站位、姿态、持物、未完动作与声源；每次独立输入局部时间从 0 秒起，同一次输入分批交稿延续局部时间。
- 分开记录生成素材总长、局部保留区间与成片区间；原词、关键动作和必要结果落在保留区间；顺接累计、叠化去重。**按秒分段时所选秒数默认即硬上限（宁短勿超，高于并入下一整镜）**；小数段按主流程局部增减有作用节拍至正整数，向上凑整严禁越过上限，不用剪除尾巴掩盖正文小数。
- 多个独立生成块按[上一段承接点](流程.md#上一段承接点)核前尾→承接→首态一致。

## 生成成片接缝检查

1. **确认范围**：需上下段可查看素材与采用剪取区间（缺音轨或仅部分可读时分别标已观察与未知）。
2. **看实际保留画面**：取上段最后保留帧和下段第一保留帧（向两侧多看短区间），比对场内位置、投影、动作阶段、手侧、接触、光色和声音，区分设计文本冲突、成片偏离与剪点选错。
3. **选最小修正**：已有可用切点先调保留区间；缺动作阶段再修提示词起态或用实际保留帧作参考；采用现有成片实际终态须先核是否改掉原事件或锁定项；重生成后以新成片复查并分别报告文字修订、剪点与实测结果。
