# 成片症状诊断

先定位源镜号、成片秒点或段间切缝。对照采用版提示词、实际素材和生成设置。下表给出优先排查的假设。有文字稿时记录可能的风险，有可查看的成片时记录实际偏差。

<a id="director-diagnosis"></a>
## 导演与画面问题的排查顺序

“画面平”先定位具体镜号和观看损失，不直接加推近、换景别或拆镜。只有文字时判断设计风险；有可查看成片时才报告实际偏差。按下列顺序检查，允许多个原因并存，先处理上游依赖：

1. 原稿、原词、揭示与锁定项是否被改；剧情或目标确需变更回[01 场戏依据](../01-剧本理解/流程.md#part-9)，已有事实不清不靠摄影猜出新真相。
2. 空间、动作、接触与素材职责是否成立；设计缺口回[空间方法](../空间基准与调度.md#space-recovery)，绑定冲突回[实际素材绑定](流程.md#part-18)。
3. 本镜必须可见的信息、反应及先后是否读得清；查[03 观看顺序](../03-分镜/流程.md#attention-design)，不因情绪判断隐藏必要结果。
4. 拍法是否支持有依据的观众体验，切镜、停留及运镜是否有观看收益；缺设计回[03 导演决策](../03-分镜/流程.md#director-decision)，获准后只改受影响镜头。
5. 已采用的安排是否在成品文字中遗漏、矛盾或过载；漏写按[04 导演继承](流程.md#director-inheritance)补回，必要摄影参数再核[镜头继承](流程.md#镜头信息继承核对)。

先区分设计缺陷、转写遗漏、素材冲突与成片偏离。文字成立但生成偏离时，依据素材与实际观察修生成输入或设置，不反向篡改原稿和导演目标；没有回跑不宣称效果已经改善。

## 具体症状

| 症状 | 优先核对 | 第一轮修改 | 回跑看什么 |
|---|---|---|---|
| 变速过多、慢动作软绵像打太极，或提速原地鬼畜无冲劲 | 是否只干写“开启慢动作/拉快2倍”或 `240fps/0.02s顿帧` 伪参数而缺物理参照、是否单镜多次快慢横跳或拿变速凑段长 | 回[03速度选择](../03-分镜/流程.md#playback-design)保常速基准（单镜≤1次转换、慢放窗0.5–1.5秒）；按 [TIM-A11](../../知识库/摄影与画面/zhuan-xiang/shi-jian-yu-jie-zou/ying-yong-chang-jing-ku.md#tim-a11) 与[物理化写法](可观测写法.md#physicalize)补同框悬浮微粒双速差、半拍压簧前摇＋广角介质后掠及声场抽空协同 | 慢镜有微粒参照不软绵，提速有跨距冲劲不鬼畜，完后平顺恢复常速 |
| 关键线索或反应有写但没被看见 | 实际范围、注意力、焦点与显露点；是否只记录入画 | 回[03细节覆盖](../03-分镜/流程.md#detail-coverage)比较原镜调整与插入／特写；保唯一证据，不仅删除不可读细节 | 细节可辨且作用清楚，不提前揭示、不重演动作 |
| 同主体相邻切口微跳 | 比较两镜实际占幅、机位、背景、动作阶段与时间；是否有意省略 | 按[03近似切口](../03-分镜/流程.md#cut-continuity)决定留镜或有效新覆盖，不能硬插无关物件 | 连续关系清楚，正常同景别反打不被误改 |
| 信息都拍到了但重点不清 | 起始重点、次要信息与干扰源是否已定，亮点、焦点及运动是否相互争抢 | 缺设计回03观看顺序，漏写补具体取景与清晰关系，不强叠所有强调手段 | 关键节点是否先读到需要的信息 |
| 镜头变化很多但剧情没推进 | 每次切镜、推拉或停留的新增收益，是否重复同一反应或动作 | 按03导演复核保留有效变化；锁定拍法之外的调整先明确授权范围 | 变化是否带来新的理解、期待或后果，而非只换角度 |
| 只有情绪标签，没有对应画面 | 目标依据与可见证据是否缺失，是否把人物情绪当观众体验 | 在03将目标落实为已有关系、取景和表演的覆盖，再由04转写，不加新剧情或陈设 | 目标是否有画面承载，必要事实是否仍可读 |
| 揭示过早或反应像预知 | 人物与观众知情差、构图和声音是否提前泄露，转移触发是否被压掉 | 事实边界回01，拍法回03，漏写或时间映射回04，保留原词与既定结果 | 信息到达、反应、揭示是否按采用顺序发生 |
| 全景被拉成近景 | 正文是否要求看清当前景别读不到的睫毛、毛孔或微表情，参考帧是否偏近 | 若正文冲突，删减无法读到的细节，保留景别与关键动作 | 构图范围和动作是否都保住 |
| 固定物件自己移动 | 「门框滑走」等句子是否把物件写成运动主体 | 明确摄影机运动，写出物件相对场景的状态和画幅变化 | 构图变化时物件是否仍在原位 |
| 手入画后变成第一人称 | 手的归属或外部摄影机位置是否缺失 | 写清人物、哪只手和摄影机观察方位 | 手的归属和外部视角是否成立 |
| 跨段起身、换手或接触断裂 | 比较前段最后保留帧、内部十四项尾态、本段首态及实际参考帧 | 根据已核实的接点修正本段开场描述或参考绑定，保留源镜号 | 姿态、持物手和接触关系是否衔接 |
| 反打后像换座或眼线接不上 | 场级基准是否明确，摄影机是否换侧，肩位与目光是否符合当前投影 | 缺设计回 03；漏写走空间继承核对；只改机位不得搬动人物 | 地标关系、双方朝向、肩身份和眼线是否同时成立 |
| 第三人再次出现时换位置 | 最近有效状态、画外期间是否有移动或跳时依据 | 恢复最后有效位置及实际变化，未知不擅补；更新受影响源镜与接入 | 留场者再现是否有可追溯位置和路线 |
| 远处直接碰到或走位穿障碍 | 功能距离、路线占用、障碍和动作阶段是否缺失或冲突 | 回 03 修未锁定站位或合法路径，再转写；锁定冲突先确认 | 到达后才接触，途中通行和身体支撑成立 |
| 换视角后门窗像换墙 | 场景布局版本、参考职责是否冲突，是否把画面左右当固定方位 | 明确固定地标关系与观察方向，核参考绑定；不为新机位重建另一房间 | 不同视点能否对应同一布局 |
| 声波图/文字跑进画面，或角色跨段串音变声 | 块首声纹锁图是否漏写“画面中严禁出现声波图形或文字”、是否误写内部编号 `V01` 或逐镜重复绑定、同场同性声纹是否拉开维度 | 保留块首单次绑定与禁声波入画护栏，清掉逐镜重复绑音色与内部编号；同场同性角色拉开源音区或音质维度 | 画面纯净无声波元素，各角色跨段音色稳定不串音 |
| 续段 0 秒重演上一幕，或一开口跳回播音腔 | 【上一段承接点】是否误写“刚推门/刚挥刀后”等已完成过去动词、是否漏写 0 秒人物开场状态与人物语气状态、连续动作跨段是否做好换视角相位顺接（用户主动给首帧图时另核同档景别咬合） | 全部改为“已+既成静态态”并补透人物开场状态、未完动势与语气余韵；用户主动提供首帧图时确保首镜同档景别承接 | 0 秒从既成态自然续接不重演，开口语气与上段无缝衔接 |
| 非末段结尾提前慢停、人物看镜头或淡黑 | 末镜「切出与防穿帮」是否漏写续帧护栏，或是否把【本段结束与后续交接】、“本段结束/硬切”等词误放进复制块内 | 将【本段结束与后续交接】与剪辑流程词清出复制块，并在末镜补明“动作光影自然延续至末帧截止，不提前慢停、不淡黑、人物不看镜头” | 末帧保持动作光影势能自然截止，无提前收势或黑场 |
| 切近景后背景换房间，或多人站位飘移 | 是否缺「角色-专属背板地标锁」、多人是否未用「两级锚定法」、或视频块内残留“东西南北” | 为主要站位锁死专属背板并在近景虚化中点名带出，多人先锁锚点人再交叉锁其余角色，彻底清掉块内“东西南北” | 切近景背板仍对应原方位，多人相对位置稳定不飘移 |
| 手机背面变发光屏、同道具变两件，或凭空多出路人/新角色 | 双面小道具是否未锁正反面、场景已有道具加绑参考图是否未锁单实例、封闭场是否漏锁人数、跨段新角色是否漏写进场 | 写清背面朝镜头且屏幕朝手心不可见；声明参考图即桌上同一件且拿起后原位变空；块首锁死场内仅指定角色无路人；跨段新人物补入画/先声过渡 | 小道具正反正确且仅一件，背景纯净无乱入人物，跨段进出场合理 |
| 打斗像回合制木偶对砍、擦身躲刀糊帧穿模，或段尾站桩摆 Pose | 防守是否只写静态格挡而缺破防过渡、闪避是否笼统写“极限躲开”、镜尾/段尾是否写收势站立 | 按 [C09](../../知识库/动作与特效/武打/zhi-shi-ku/tiao-jian-zu-he.md#c09) 补格挡震开后的侧闪/仰头/单手拍偏零碎过渡；按 [C10](../../知识库/动作与特效/武打/zhi-shi-ku/tiao-jian-zu-he.md#c10) 拆写腰背先动弧线、兵刃清晰间隙与最低点收腹蓄力；段尾停在下一击蓄力前摇 | 攻防有破防狼狈感与连贯蓄力，擦身间隙清晰不穿模，段尾不断势 |
| 长枪跳劈变垂直僵坠、贴身挥不开，或空手硬抓锋刃穿模 | 长兵是否漏写握柄转轴与近身抽杆拉开、徒手对持械是否未避锋线直接抓刀刃 | 按 [W06](../../知识库/动作与特效/武打/zhi-shi-ku/chi-xie-ji-chu.md#w06) 明写双手握柄为支点画半圆弧劈落、被欺近先抽杆换把或退步拉开；按 [W08](../../知识库/动作与特效/武打/zhi-shi-ku/chi-xie-ji-chu.md#w08) 写侧让避锋后扣握对方手腕/肘部支点卸力 | 长兵轨迹呈圆弧且距离合理，徒手拆兵锁腕肘不抓刃口 |
| 大招期间双方傻站读条、360°狂抖崩坏，或切镜后战损自动复原 | 高能蓄放期是否漏写对手反扑与施术位移、是否硬塞360°螺旋加狂抖、反打或续段是否漏继承场地裂痕与衣甲破损 | 按 [X11](../../知识库/动作与特效/武打/zhi-shi-ku/chang-jing-ying-yong.md#x11) 补蓄放期攻防互动与身体凹陷＋地面介质双反馈（默认无血合规），跨镜锁死战损痕迹；按 [MOV-A21](../../知识库/摄影与画面/zhuan-xiang/yun-jing-yu-jiao-dian/ying-yong-chang-jing-ku.md#mov-a21) 降为90°–120°半弧与命中短震即稳 | 大招全程动态博弈不站桩，运镜稳定可读，场地与衣甲战损前后一致 |

空间问题先按[空间信息继承核对](流程.md#space-inheritance)区分上游未设计、转写遗漏或矛盾、素材职责冲突和成片偏离。分别回 03、04 或实际素材绑定处理；文字成立但成片偏离时，不无依据改掉空间基准。

优先调整一个可疑变量，回跑时尽量沿用同一模型、素材和设置。记录偏差、改动和验证结果。未回跑时标为待验证。锁定内容发生冲突时沿用现有局部修改流程。
