<a id="按段转提示词"></a>
## 视频提示词

**所有视频请求先过此入口**，包括直出、中途跳步直出、同交、按段转提示词、续段、重写与润色。先读取本轮范围内有效设置：分段方式（按15秒/按30秒/按镜/整场不分段单块/自定义秒数）、贴合模式、硬上限、资产图策略（用登记图/纯文字外观锁/正常图+文字补状态）、设置来源和确认状态。已有效确认或获专项授权的设置直接复用；不能仅因文件较新视为已确认。

1. **分段方式确认（一步直达）**：分段方式或目标秒数未知时，实际调用选项卡问「星应请问您，本轮视频提示词要怎么分段？所选秒数默认为每段硬上限（宁短勿超），若允许超长请注明。」，选项为「按15秒排段」「按30秒排段」「按镜分段」「整场不分段（单块）」，其他秒数由自由输入填写。**按秒排段时，所选秒数默认即每段硬上限（严禁超过 `N秒`），仅用户明确需要大段时才选整场单块**。精确段长须为正整数秒，精确小数与整数块冲突时集中确认，不能暗改。
2. **贴合模式确认（仅按秒排段需要）**：选「按镜分段」或「整场不分段（单块）」跳过贴合卡（保留整数块检查）。目标秒数已知、贴合模式未知时，实际调用选项卡问「星应请问您，每段时长需要多接近目标？镜头保持完整且不超上限。」，选项为「精确段长」「尽量贴合」「自由分段」：**精确段长严格 `= N秒`；尽量贴合严格 `≤ N秒` 且贴近目标；自由分段按自然转折切分但仍严格 `≤ N秒`（严禁超标）**。精确模式不能牺牲必要内容，无法满足则报告冲突。
3. **无工具与等待边界**：无交互工具则文字询问并等答复，不能声称已弹卡。等待确认期间可整理前置事实和内部十四项，不得交付擅定分组的成品；“一次交齐”不覆盖设置门槛。
4. **04 内先跑内部十四栏，再分段装配**：
   - 先完成上文**内部十四栏前置补全**（已有完整采用版十四项则直接复用），再执行[G3 状态与参考双向检查](#binding-gate)（含缺图/不做图/正常图+文字补状态的明确分支处理）。
   - 按[分段时长与压缩](#分段时长与压缩)确定整镜边界与局部时间映射（常规标 `分段 1、分段 2…`，仅用户明确要大段/单块时归入整场单块）。
   - 多段或续写中段按[上一段承接点](#上一段承接点)提取有效尾态；首段与整场单块省略承接栏。
   - 按[视频提示词模板](模板.md#part-v-视频提示词模板)完整展开本段全部源镜正文（按镜分段自动套用[单镜直出简化版](模板.md#单镜直出简化版)；栏位对齐细则按需查[正文与声画对齐](表演光声与接缝细化.md#part-24)）。
5. **交付前验收**：依次完成[信息去向](#information-mapping)、[镜头继承](#镜头信息继承核对)、[空间继承](#space-inheritance)、[导演继承](#director-inheritance)、[可执行表达](可观测写法.md#executable-check)和[交付门槛](#delivery-gate)。

### 分段时长与压缩

1. **自然分段优先＋宁短勿超默认硬上限（分段切口红绿灯）。** 先按剧情转折、动作收束、对白停连和整镜边界分组，但**按秒分段时所选秒数默认即硬上限（只许短、严禁超）**：🟢**绿灯切口（首选）**为换镜切点、换场跳时或动作句尾落稳处；🟡**黄灯切口**为连续动作被迫拆段（默认不要求首尾帧，优先换视角动作相位顺接＋块首0秒动势锁独立直出）；🔴**红灯禁切口**为无因果悬空、台词半词或单侧无落点甩镜。**「宁短勿超」高于“并入下一整镜”**：再并下一镜将超 `N秒`（如 `27秒+6秒=33秒`）时强制在合法切口提前断段，下一镜归下分段；单镜本身超 `N秒` 未锁定时回 03 拆镜或走黄灯顺接，已锁定则报冲突，绝不超标输出（仅用户主动提供或要求时走[首尾帧分支](../转场与运镜衔接专册.md#first-last-frame-optin)）。
2. **算完再处理小数。** 每份独立视频提示词总长必须为正整数秒（镜长与镜内接点可小数）。已为整数且未超上限的段不再改；小数段找未锁定镜头内的可调节拍。
3. **局部增减，不机械取整。** 允许有依据地收紧停留，或增加确有作用的观察、反应、停连和动作节拍；可集中一镜或分配多镜，不平均摊派。14.6秒可因确有作用的0.4秒观察调至15秒，也可因0.6秒冗余收紧至14秒。按内容、目标及上限选择（不得因向上凑整越过上限）。不准无意义等待、重复动作、删词、播放变速或只改标题补差。锁定镜长不暗改。
4. **同步真实时间。** 调整只记本次分段生成映射，不覆盖 03 内部十四项采用版；记录源镜、源区间、本次区间、增减量和节拍依据。重算逐镜起止、镜内事件与声画接点、段末状态及成片累计区间。末镜终点=逐镜时长合计=块内总长=块外段长；不用剪除尾巴掩盖正文小数。
5. **无合法余量才报告冲突。** 不优先为整数重排自然分组；确无可调时间先比较获准的其他自然边界，仍不成立则列源镜、现有段长、差额及锁定条件待确认。按秒排段允许自然短段但**严禁越过默认硬上限**（除非用户明文允许超长）。按镜4.6秒且镜长锁定时不得假写5秒。

## 信息去向与保真

转写前直接按源镜号从[03 内部十四项](../03-分镜/流程.md#视频转写前的内部十四项)、资产表和空间状态读取信息，逐镜核对到最终视频块的落点（复用[内部镜头记录](../项目交接与恢复.md#内部镜头记录)，不另建平行台账）：

| 上游来源（02 资产 / 03 内部十四项） | 最终交付去向（纯净块内 / 块外交接） |
|---|---|
| 资产号、文件版本、清晰图片名称、职责、固定音色 | 块内【参考素材】写**图片名称+职责+音色**；块外对照表写登记图ID/版本与本地路径 |
| 固定地标、布局版本与参考来源 | 块内【场景空间与开场站位】 |
| 人物位置、朝向、距离、手物与动作阶段 | 块内开场站位、逐镜「镜头与构图」「画面与动作」（稳态不重复抄写） |
| 景别、方向、高度、俯仰、焦距、光圈、焦点 | 块内逐镜「镜头与构图」，镜内变化进「画面与动作」 |
| 观看任务、表演、动作顺序、揭示与运动触发 | 块内逐镜「镜头与构图」「画面与动作」 |
| 原词、说法、声源、续声 | 块内逐镜「音频与对白」 |
| 光影、材质、接触结果、特效 | 块内【全局风格与光色】及逐镜「画面与动作」 |
| 已确认画面文字及显隐时机 | 块内逐镜「画面文字」（无则省略） |
| 切出状态与下一段依赖 | 块内逐镜「切出与防穿帮」；块外下方【本段结束与后续交接】→后段【上一段承接点】 |

逐镜核源镜顺序与次数，清单与正文一一对应且完整展开，禁止只列摘要或“其余同上”。允许去重复措辞，不丢参数、原词、插入、反应、声光或特效。缺设计回 03 对应项，漏写由 04 直接补；只在不适用时省栏，必要缺项恢复、补设计或在块外报告。

<a id="fixed-constraints"></a>
## 固定画面约束与空栏目

每份独立视频复制块（单块、多段、单镜、续段、局部完整替换）在**块尾**【画面约束】中实际写入（不再置顶抢占开头主体权重；若目标平台有独立反向提示词栏，同时在块外给出快捷反向词）：

“画面纯净，无字幕，无水印，无平台角标，无额外叠加的标志、说明文字或界面元素。”

上述为生成约束，不要求另列“画面文字：无”，也不默认禁止必要对白、音效、配乐或已确认的场景内招牌、道具文字。用户明确要求字幕、界面或剧情标志时，仅对该项和范围改成具体允许内容，其余约束保留，块内不得同时允许和禁止同一内容。

没有实际参考素材、没有已确认画面文字，或没有相关声音、特效、物理变化等适用内容时，删去对应栏目及空子项，不输出“无、未知、不适用”或占位符；内部记录可保留“不适用”。必要站位、主语、接触和时间缺失须补，不借省栏绕过。首段或整场单块删去【上一段承接点】，续写中段不删；内部台账（`登记图ID/版本`、`包含源镜清单`、`【本段结束与后续交接】`）一律放块外，不污染视频生成块。

<a id="delivery-gate"></a>
## 视频交付门槛

所有视频成稿完成信息、空间、导演继承核对后，必读[可执行表达](可观测写法.md#executable-check)逐镜核主语、对象、因果、摄影及声画归属（剪辑/转场术语禁裸进块内，须转为物理画面，见[术语转译](../转场与运镜衔接专册.md#no-raw-jargon)），再执行[精炼](可观测写法.md#prose-polish)并回查必要信息未删。

进入 04 视频转写前：项目与采用剧本/内部十四项依赖有效，无未处理待复核；分段设置有效确认或获专项授权；源镜顺序、素材与空间基准可恢复。每块通过[G3 状态与参考双向检查](#binding-gate)，并满足交付条件：全部镜头展开；逐镜时间连续、末镜终点为正整数总长且**按秒分段每段总长严格 `≤` 所选上限**；素材名与绑定真实；固定约束存在且不矛盾；开场站位成立；续段前尾/承接/首态一致；信息映射无漏项；无空栏目和占位。项目模式按 G5 保存读回后才推进进度。

任一未通过只回责任位置修缺口：句子含糊/漏写在 04 修；空间或镜头设计回 03 修；素材职责回 02 核；锁定冲突先确认。文字检查、检索测试与实际成片核验分开记录。

## G3 状态与参考双向检查（实际素材绑定）

每块（视频块、分镜图、续段与完整替换）先读 02 真实图片登记、相关状态事件和本块全部源镜，依次执行：

1. 按故事时点核每镜/关键变化接点的有效状态，写入项目单元 `observations`（要求活着时显式核 `life`；同镜伤前/伤后分拆观察点）。
2. 从实际镜头用途提取 `referenceNeeds`（区分外观、布局、音色、风格职责；不把全场资产表照抄到每段；画外发声不自动需要该人视觉图）。
3. 只从已登记可用且对象、状态、职责匹配的图选取，建立 `需求→图片ID/版本→清晰图片名称→源镜/阶段/维度` 映射；视觉图必须核对外观/伤势/完损等视觉状态且确认 `viewed`（无读图能力须有 `unviewedAck`）。**绝不私自拿错状态图凑数**。
4. **资产图缺失或用户不想做图时的 3 路径处理（弹卡确认后放行，不死锁）**：
   - **路径 A（明确不做资产图 / 纯文生视频）**：弹卡或获范围授权后，将相关 `referenceNeeds` 记为 `mode: 'text'` + `authorization`（一次授权，后续段复用不重复问）；块内省略【参考素材】，改在【全局风格与光色】后写入统一的 **`【角色与场景固定外观（纯文字锁）】`**（读取 02 的固定文字视觉锚点，跨段保持一致防换脸换衣）。
   - **路径 B（角色受伤/换装/场景损毁但用户懒得重做新状态图）**：**先弹卡确认**「星应请问您，[对象]当前已处[状态]但缺状态图，本段怎么处理？」，选项为「沿用正常图+文字写清状态」「暂停本段先补图」「先出待补图草稿审节奏」「改用纯文字外观锁」。
     - 选**「沿用正常图+文字写清状态」**：绑定写 `overrideDims: ['injury']`（按实际填）与 `overrideAuth`；块内【参考素材】限定职责，如 `[正常图名称]：对应[角色]，仅参考脸部与基础服装（不锁[伤势部位]；当前为[具体伤势]，以正文为准）`，并在分镜「画面与动作」写清状态；块外注“已授权正常图+文字补状态，待实测”。
     - 选**「先出待补图草稿审节奏」**：块内用 `[待补图：对象-状态图]` 占位，单元保持 `workStatus: '待确认'`。
     - 选**「暂停本段先补图」**：仅暂停受影响段，其余段照常推进。
   - **路径 C（画外发声、远景背景、普通陈设）**：不建视觉图需求，不阻塞。
5. 需求↔绑定双向反查防漏防多；同段可用多张状态图（如正常图+伤后图），块内以清晰图片名称写明适用阶段与职责，由创作者按块外对照表自绑。
6. 复核正文状态、图片映射与前尾/本首一致。块内写 `[图片名称]：对应[对象]，仅参考[职责]，用于[源镜/阶段]。` 登记ID/路径放块外；块内声明一次，正文用稳定对象名。**角色音色只在块首人物后缀绑定一次，逐镜不重复**：有参考音色优先用；未提供则统一在人物后缀绑 02 [声纹锁图](../02-资产清单/流程.md#voiceprint-lock)（明写“仅锁人物音色，画面严禁出现声波图形或文字”；项目按非视觉 `voice` 放行）；纯文字模式挂同组声纹词后缀。逐镜「音频与对白」仅写说法、原词与词动铆钉。

## 镜头信息继承核对

按源镜号将[03 内部十四项](../03-分镜/流程.md#视频转写前的内部十四项)与最终视频复制块逐镜对照：核景别、水平拍摄方向、机位高度、俯仰、运镜、焦距、光圈、焦点、景深及已采用专项决定是否完整保留（单列机位高度与俯仰，区分移机与变焦、焦距与转焦，数值单位照录）。漏写由 04 补回，设计缺口回 03 内部十四项补齐；分段换算镜内时间接点时保留原拍法与参数。

<a id="part-24-核对镜内快慢"></a>
### 核对镜内快慢

常速默认；播放变速仅由[03 播放速度选择](../03-分镜/流程.md#playback-design)决定，04 不因镜长、语速、机速或分段预算另加变速。已采用例外在「画面与动作」明写进入与结束事件、恢复常速点及音轨协同，并按[物理化写法](可观测写法.md#physicalize)补齐悬浮微粒双速差或压簧广角后掠介质（单镜≤1次转换，禁干写慢放标签或 `240fps/0.02s顿帧` 伪参数；纯后期放块外）。双向核对动作/对白能否落入镜长，过密或空耗回 03，不靠变速补差。

<a id="space-inheritance"></a>
## 空间信息继承核对

对照场级空间基准、源镜切入/切出状态与最终复制块（图像只核选定瞬间），缺设计回 03，漏写由 04 补回，不用“保持空间一致”敷衍：

1. 场景地标、通路、布局版本与参考职责一致；每块自带开场空间基准（首段和单块不例外），气氛图不暗锁布局。
2. 互动参与者场内位置、朝向、视线与功能距离有依据；画外相关人物可定位，未影响本块者留在内部记录。
3. 摄影机侧、观察方向与画面左右、前后景、肩位和遮挡一致；换机位重算投影，不搬动人物，不写未定义“原轴线”。
4. 走位起终点/阶段进「画面与动作」，「切出与防穿帮」存真实变化；路线可通行、接触距离可达、已完成动作不重启。
5. 相邻切缝与隔镜/隔段再现者对照最近有效状态；换场/跳时建新范围。修后过[空间核对](../空间基准与调度.md#space-check)。

<a id="director-inheritance"></a>
## 导演决定继承核对

以源镜号将 03 已采用的镜头任务、可见证据和观看顺序对照最终块（图像只核选定帧），不重做导演选择，缺设计回[03 导演决策](../03-分镜/流程.md#director-decision)补对应项：

1. **目标有承载**：核心人、关系、动作或证据落入正确栏目，不只剩抽象情绪词，不为体验凭空加戏。
2. **观看顺序未改**：起始重点在「镜头与构图」，转移触发与显露在「画面与动作」，切出结果在「切出与防穿帮」。
3. **摄影与信息相容**：关键脸/手/文字/接触在画幅内可读，不提前泄露限制信息也不隐藏必交结果。
4. **变化服务原任务**：保留固定观察、运镜触发、停留、插入/特写细节（[03 细节覆盖](../03-分镜/流程.md#detail-coverage)）与切口连续（[03 近似切口](../03-分镜/流程.md#cut-continuity)），分段调时不破坏辨认与揭示顺序。
5. **依据与成品分开**：关键理由存内部记录，不新增理由栏；成片偏差走[导演问题诊断](成片症状诊断.md#director-diagnosis)。

## 上一段承接点

按生成序列编号，第 1 段及整场单块省略本栏；后续独立生成段（含仅续写中间一段）均在【场景空间与开场站位】后写【上一段承接点】，换场/跳时在承接起态中说明切换方式与延续项。

1. 从上一段复制块外下方的【本段结束与后续交接】及末镜「切出与防穿帮」读切出状态（文字标「计划」，已核实成片保留帧标「实测」）；有剪取时分别核局部 0 秒与第一保留帧。
2. **必须写透人物开场状态与人物语气状态**：逐一落清 0 秒当下出场人物的**开场状态**（姿态、神情残留、呼吸/体能紧松、伤势衣损、持物手侧与未完动作进度）以及**语气状态**（延续上段的发声能量、语速与情绪余韵，如仍压低声线冷硬逼问、气喘未平或克制隐忍；未完续句标气口），防止续段 0 秒立正重启或一开口跳回平淡播音腔；隔段再现回查最近有效状态，稍后入画注明镜号。
3. **禁写已完成过去动词，一律写 0 秒既成静态态**：严禁写“紧接上段推门、合盒、挥刀划伤后”（防 0 秒重演），改用“门已敞开半扇、木盒已闭合且乙右手正压盒沿、右袖已留裂口”等当下既成画面；空间用画面左右＋专属背板地标（不用东西南北），多人沿用两级锚定交接；**跨段新增前段未入画的具名角色时，须交代方向入画、画外先声或原位留场依据，禁 0 秒凭空刷人**，同时承接未歇声光与特效残留。
4. 在首镜或首次出场镜落实承接起态，核动作/对白不重启、手侧接触不跳变、道具不移位、持续声光不重置；非全片结束段的末镜须保持动作光影延续至末帧，不提前慢停、不淡黑、不看镜头。
