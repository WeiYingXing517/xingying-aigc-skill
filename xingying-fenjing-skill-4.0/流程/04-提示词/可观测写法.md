# 可观测写法

本文件是视频提示词、直出、续段及局部重写共用的表述方法源。每份视频复制块交付前必检，静镜也不跳过；已有清楚表达直接保留。图像分支采用适用的对象与空间检查，不写视频过程。方向、速度和秒点只写影响执行且有依据的部分。

<a id="executable-check"></a>
## 可执行表达检查

逐镜读最终正文，不只读内部记录：能否明确“谁、对谁或什么、在何种起态下、做什么、触发及结果是什么”？只补实际影响执行的要素，不强填所有句式槽。

1. 首次出现使用稳定角色名或身份，换行动者、声源或运动对象重新点名。同一主体连贯操作可顺写；多人有歧义时不用“他、她、对方、另一人”。原台词中的代词及原词不改，在台词外点明发声者和必要受话者。
2. 摄影机移动以“摄影机”为主语，分别描述人物走位、摄影机移动、变焦和转焦。明确谁动、谁不动、路径及画面变化。“缓慢”须能分辨指动作速度、机速还是已采用的播放慢放。运镜幅度与节奏优先写可观测的起止范围、参照地标与快慢感受，不堆砌视频模型无法精确执行的伪量化参数（如“每秒1%画幅”“抖动2-4Hz”“每圈半径缩小20%”）。
3. 互动明确行动者、对象与必要部位；持物按人物身体辨认手侧。核接近→接触→持有→释放的顺序与支撑，不以移机或切镜制造隔空接触。
4. 视线点名观看者与目标；声音点名声源、画内/画外和起止或续声；特效点名来源、作用对象、位置和阶段。区分被遮挡、出画与实际离场。
5. 核同一主体是否被要求同时完成互斥动作、同手是否同时占用、反应前是否已获得信息、关键对象是否在画内且可读、内心或未知是否冒充可见事实。发现缺设计回03相应镜，不靠润色猜剧情。
6. 独立复制块无未定义对象、未决“或A或B”、同上、空占位或只能由块外说明补齐的关键条件。必要信息缺失先补；不适用栏目直接省略。

完成条件是实际句子可执行，而非在结尾写“主语已清晰”。文字检查不等于成片已验证。

<a id="prose-polish"></a>
## 成稿精炼

顺序：必要信息完整→主语与关系明确→删套话和重复→回查执行条件。分镜便于人迅速看见画面与切点，视频提示词便于生成模型分辨对象、动作和摄影；不以修辞代替执行。

- 用具体动词替代“呈现出、展现了、营造出”。电影感、紧张、压迫等只作有依据的目标，不替代可见安排。
- 核对所有可读参与者，但只写有信息、人物表现或接续作用的神情，不逐人强配眉眼嘴角。原稿或已采用的必要表演完整保留。
- 稳定共用条件集中写，逐镜写实际变化。同一含义不在起态、过程、尾态各解释一遍；跨独立块仍写齐必要条件。
- 不以精简删除主语、动作对象、必要站位、手侧、接触、原词、摄影参数和声画接点。项目明确采用的风格化表达可留，但不得掩盖执行关系。

### 对照例（仅示范写法，不提供新增剧情依据）

- 多人递物：不写“他接过来，转过去，镜头跟上”。可写“林岚用右手接住周宁递来的钥匙。周宁松手后，林岚转身走向门口。摄影机从林岚左侧跟拍。”必要时补钥匙后续持有，不能漏释放阶段。
- 等待：不写“他焦虑地等待很久，充满张力”。采用稿若已有视线与钟声，可写“林岚望着门口。钟声结束，林岚仍未等到回应。”不能为文笔新加钟声或反复踱步。
- 对白：不写“她听后神情复杂，对方继续”。写“周宁听到‘明天离开’时抬眼看向林岚；林岚从画外继续原句。”原词及信息到达点据采用稿。
- 情绪：不机械写“眉头收紧、嘴角压低、下颌绷紧，表现警觉”。若动作已足够，可写“门响。林岚笔尖停住，抬眼望向门口。”原稿锁定的表情不得因此删掉。
- 跑动：不重复“继续跑、一直跑、快速奔跑”。镜头覆盖由[03持续动作覆盖](../03-分镜/流程.md#action-coverage)决定；转写说明具体行动者、当前阶段和终点，不自行增删镜头。

<a id="physicalize"></a>
## 抽象词物理化与特效四维显形（举一反三）

### 一、抽象强度词与快慢变速 → 物理证据推演

凡出现“强、快、重、燃、开启慢动作、拉快2倍”等抽象词或 `240fps/1:2000快门/0.02s顿帧` 等伪参数，一律禁止直写进提示词，按 **`动作载体 → 接触点/帧内速度参照 → 受方与真实场地介质后果 → 镜头微反馈`** 现场改写；单拍最多保留 **1 个接触点结果 + 1 个身体或场地介质后果**，单镜最多 **1 次速度坡道转换**（详查 [TIM-A11](../../知识库/摄影与画面/zhuan-xiang/shi-jian-yu-jie-zou/ying-yong-chang-jing-ku.md#tim-a11)）：

| 想表达 | 禁止直写 / 伪参数 | 物理证据推演示例（文武通用） |
|---|---|---|
| 强 / 重击（双反馈＋无血合规） | 毁天灭地、血肉横飞、低俗性化受击词 | 拳锋砸陷胸甲致躯干向后折成弓弧，双靴犁开积水炸起两侧水花并撞裂身后砖墙，镜头短震即稳（未明确要求血腥时默认用凹陷弓身与器物碎裂替代喷血断肢）。 |
| 真慢速 / 升格感 | 开启慢镜头、240fps升格、1:2000快门 | 刀尖贴鼻尖掠过的 1 秒进入局部慢放：角色腰背向后舒展成弧、瞳孔死锁刀柄，同框飞溅雨珠与火星在半空近乎悬停缓飘（用双速微粒差防止画成软绵太极）。 |
| 真提速 / 爆发冲刺 | 画面拉快2倍、超高速瞬移炫技 | 角色半拍沉腰屏息压低重心，蹬地瞬间跨距突进；24mm 广角贴地急跟，脚下积水尘屑向画框两侧高速后掠，衣摆滞后拖出受控方向性残影。 |
| 碰撞顿挫（Hit-stop） | 顿帧0.02秒、半帧抽帧、黑白负片闪屏 | 重刃劈中横挡长枪瞬间咬死接触点短促凝滞半拍，枪杆微弯与迸出火星清晰可辨，随即借反力猛然震开滑退。 |
| 压迫 / 危局 | 压迫感拉满、窒息恐怖 | 前景暗影逐步遮住退路门缝，脚下积水微震，角色肩背贴紧冰冷墙面。 |
| 情绪重击 | 内心剧烈震动、崩溃绝望 | 握杯的指节发白停顿半拍，茶水沿倾斜杯口滴落桌面，目光迟迟未抬。 |

### 二、一切特效与介质的「四维物理显形法则」

遇到**任何**介质或特效（火焰、冰霜、雷电、水血、黑雾、尘埃、光束、机甲废气等），严禁写十六进制色码或离线渲染器开关（如 `SSS开`、`流体解算`），统一按 4 维现场推演自然中文画面：

1. **内部层次**：写清核心态 → 中层流动或纹理 → 外层边缘消散或附着，拒绝实心纯色块。
2. **力学形态**：写清受风、重力、惯性、表面张力或湍流影响的混沌不对称变化，拒绝死板对称。
3. **环境互证**：写清它照亮了周围哪一侧、折射或热扭曲了什么背景，以及吹动、打湿、灼焦或击碎了什么既有物件。
4. **边界克制**：效果始终作为动作副产品出现，留出主体轮廓、眼神与关键接触点清晰可读。

*举一反三示范*：
- **火焰**：焰心白亮、中层橙黄涡旋上卷、边缘暗红翻出黑烟与火星，火光跳动映亮角色侧脸并令后方空气微微热扭曲。
- **能量/法术**：光核发亮、中层流纹沿刃口湍流缠绕、外缘碎光剥离消散，冷色光照亮地面裂纹而不遮盖人物轮廓。
- **粘稠液体/水血**：液面映出环境高光，飞溅呈不规则抛物线，剥离时带细微拉丝并湿亮附着在衣料或石面上。

## 运动与画幅写法

| 要表达的变化 | 写法 |
|---|---|
| 摄影机移动改变构图 | 摄影机向右横移，门框沿画幅左缘退出，露出原地站着的林岚。 |
| 人物移动进入构图 | 摄影机固定，林岚从画幅右侧走入，停在桌边。 |
| 人物原地转身 | 摄影机固定，林岚双脚位置不变，身体从面向门转为面向桌；不是摄影机环绕。 |
| 摄影机绕拍静止人物 | 林岚保持桌边原位和身体朝向，摄影机沿已定路径从门侧移至窗侧；按新观察方向更新画面位置和可见面。 |
| 出画但没有离场 | 摄影机收近何岚，林岚被裁到画外，仍停在桌靠门一端；何岚的目光仍落向该处。 |
| 实际离场 | 摄影机固定，林岚从桌边走到门口并穿门离开房间；不是只从画幅边缘退出。 |
| 遮挡而非消失 | 林岚沿既定路线走到柱后，脸和右手被挡，仍在柱后场内；未见部分保持未知，不写成穿柱可见。 |
| 焦点随事件变化 | 林岚松手时，焦点从林岚的脸移到桌上的钥匙，钥匙变清楚，林岚的脸虚下去。 |
| 局部入画容易误判视角 | 摄影机从桌侧拍摄。林岚的右手从画幅右侧伸入，握住桌沿。 |

例句只说明表达方式，实际空间依据从[空间基准与调度](../空间基准与调度.md#space-projection)读取。例句中的拍法、道具和动作按当前镜头的采用内容替换。改完核对实际运动者、场内位置和画幅结果是否一致，并保留已定拍法、动作与结果。分段转写仅按独立段的首态和时间换算调整。
