# 04 提示词交付模板

本文件存放**唯一一套视频提示词模板**（自动适配多镜段与单镜直出）及分镜图提示词模板。设计原则：**复制块内只留给视频模型直接执行的纯净视觉与声音指令，内部台账、本地图片 ID、源镜清单与段末交接单全部放块外**；素材在块内直接用**清晰的图片名称**指代，不硬绑定特定平台槽位语法，由创作者按块外对照表自行上传绑定，避免换平台或传图顺序错位导致混乱。

主流程见[04 提示词主流程](流程.md)；转场选型、运镜接力与禁裸写术语见[转场与运镜衔接专册](../转场与运镜衔接专册.md)；表演、小道具锁、光声与接缝细则见[表演光声与接缝细化](表演光声与接缝细化.md)。

<a id="part-v-视频提示词模板"></a>
## 视频提示词模板（纯净生成块 + 块外制片交接卡）

常规按秒分段输出时一律按 `分段 1、分段 2...` 交付（**每段严格不超过所选秒数上限，不再默认输出「大段」**）；**仅当用户明确要求「整场不分段（单块/大段）」时**，才输出整场单块并标 `整场单块（大段）`、省略【上一段承接点】；选择「按镜分段」时自动采用下方[单镜直出简化版](#单镜直出简化版)。

### 一、复制块外（上方：进度锚点、制片信息与素材对照表）

`【星应进度锚点】当前阶段：04分段提示词｜已锁基准：[片型·细分·画幅·质感·色调·分段规则]｜挂起待办：[无或剩余待交分段]｜本轮动作：[本轮生成或局部修订范围]`（每轮回复最顶部输出一次，**严禁混入下方视频可复制块**）

**分段[编号]｜成片[起止]｜段长[整数秒数，须≤所选上限]｜源镜[全部镜号及顺序]**

- **素材上传对照（供创作者自行绑定）**：`[图片名称] → 登记图[图片ID/版本]（[本地路径或来源]）｜仅参考[职责]｜用于[源镜/阶段]`（无参考图时省略）。
- **调时与剪取说明**：发生局部调时注明源镜、原区间、本次区间、增减量及节拍依据；有剪取时标生成总长、保留区间与成片区间（无则省略）。
- **反向提示词参考**：若目标平台提供独立反向提示词栏，可填入 `字幕、水印、平台角标、叠加界面`。
- **待核与缺口**：未确认设置、已改接点或缺失素材说明（无则省略）。

### 二、视频可复制块（直接喂给视频模型）

以下是完整自含的纯净模板：先去重再成稿，稳定环境集中放块首，**不把同一站位/持物在开场、承接、起态、过程和尾态重复抄写 4—6 遍**；块内不出现 `登记图ID/版本`、`包含源镜编号` 或 `接续方式` 等内部管理字段；画面约束置于块尾，不抢占开头主体权重。

```text
【本段时长】
总长[正整数]秒（局部时间 0—[同一整数]秒）。

【参考素材】
- [清晰的图片名称，如“林岚-常态外观图”]：对应[角色/场景/道具]，仅参考[外观/服装/布局/构图等职责]，用于[本段适用镜头或状态阶段]｜[发声角色后缀二选一（参考音色优先）：音色绑定：[参考音色名称]（仅用于锁定[角色名]人物音色）；未提供参考音色则统一用：声纹锁绑定：[角色名-声纹锁图]（仅用于锁定[角色名]人物音色，画面中严禁出现声波图形或文字）]。
  （若经弹卡授权用正常图+文字补状态，显式限定视觉职责：“仅参考脸部与基础服装款式，不锁定手臂完损；当前实际状态为左臂衣袖撕裂渗血，以正文为准”，声纹锁/音色后缀照常保留。）
  （若某发声角色本段仅画外发声不出镜，单列一行：画外发声[角色名]的音色参考[参考音色名称]／声纹锁绑定：[角色名-声纹锁图]（仅用于锁定音色，画面中严禁出现声波图形或文字）。）
  （若用户明确不做任何资产图走纯文字锁，省略【参考素材】，改在【全局风格与光色】后输出【角色与场景固定外观（纯文字锁）】，每个发声角色行后缀直接挂载对应的固定声纹特征词。）

【全局风格与光色】
- 视觉风格：[画幅、画风与可见成像质感]。
- 光线与色彩：[具体光源方向、明暗关系、主色与共用材质；必要配乐或单镜连续等约束]。

【场景空间与开场站位】
- 固定空间：[基于场景图或已定布局的强地标相对关系、通路与障碍；块内禁写“东西南北”，统一用当前视角下的前后左右与可见地标描述]。
- 开场站位：[点名出场人物相对地标的位置、专属背板地标、姿态、朝向、视线、互动距离及必要持物接触；多人时采用两级锚定——先用场景图强地标锁死核心锚点人，再用“已锁锚点人＋场景图地标”交叉锁定其余角色；影响互动的画外者注明场内位置]。

【上一段承接点】
- 人物开场状态：[0秒当下出场人物的姿态、神情残留、呼吸与体能紧松、伤势衣损、持物手侧与未完动作进度；严禁写“刚推门/刚挥刀”等已完成过去动词防0秒重演，一律写“已+既成态”]。
- 人物语气状态：[延续上段的发声能量、语速与情绪余韵，如仍压低声线冷硬逼问、气喘未平或克制隐忍；未完续句标气口，防下段一开口跳回平淡播音腔]。
- 空间与持续声光：[已变化后的门窗/道具既成态、当前背板地标衔接与未歇雨声、光影或特效残留]。

分镜[源镜号]（[局部起点—终点]秒）：[事件名]。
- 镜头与构图：[景别、机位相对地标方位、高度、俯仰、焦距/光圈/焦点与景深（真固定镜明写“固定机位，镜头完全静止，不推拉、不摇移”）；本机位画面左右位置、角色专属背板、裁切、前后景与起始观看重点；反打核对朝向与过肩对边]。
- 画面与动作：[紧致连贯一段：点名行动者、动作对象、触发、表演、视线、摄影机运动与特效（摄影机、特效各自用具体主语；转场过程直接写成可见画面与声音动作，禁裸写“硬切/J-cut/Match Cut”等剪辑术语；快慢变速写清悬浮微粒双速差或压簧广角后掠介质，禁干写慢放标签或伪帧率抽帧参数）；落实物理接触、局部受光与重点转移；切离后明写主行动进度，接回不重演；无新变化的稳态不重复抄写]。
- 音频与对白：[发声者、必要受话者、画内/画外、原词、当句说法、拟音及事件接点；无则省略]。
- 画面文字：[仅有已确认画内文字才写内容、位置与显隐接点；无则整项省略，不输出“无”]。
- 切出与防穿帮：[切出时变化后的位置、朝向、持物接触、构图焦点与续声；非全片结束段末镜注明“动作光影自然延续至末帧截止，不提前慢停、不淡黑、人物不看镜头”；有实际穿帮风险附局部约束]。

【画面约束】
画面纯净，无字幕，无水印，无平台角标，无额外叠加的标志、说明文字或界面元素。
```

### 三、复制块外（下方：本段结束与后续交接卡）

供下一段承接点及项目管理读取，**严禁放进上方视频可复制块内**（避免视频模型误判为末尾黑屏、淡出或强行转场）：

```text
【本段结束与后续交接】
- 结束时间：[整数终点]秒（对应末镜[源镜号]切出状态，标计划或实测）。
- 人物终态：[点名后续需要的角色及有效位置、朝向、神情体能、伤势/持物/动作进度]。
- 人物语气与情绪余韵：[各说话角色末帧延续的发声能量、语速与情绪状态，供下段【上一段承接点】直接读取]。
- 空间与道具变化：[具体对象及已成结果态]。
- 持续声光：[具体声源、光源或特效的延续阶段]。
- 下段衔接工艺：[🟢 换镜直切（常规资产图独立生成）／🟡 换视角动作相位顺接（常规资产图＋下段块首锁死0秒动势，默认不要求首尾帧）／🔵 声桥或创意转场衔接（点明具体声画接法；仅用户主动提供或指定首尾帧时才标首尾帧职责）]。
- 接续方式：[顺接、已定跳时、换场或本场结束]。
```

### 单镜直出简化版（选择「按镜分段」时自动采用）

当用户选择「按镜分段」（一镜一块）时，去掉多镜分段外壳，每镜直接交付紧致纯生成块（块外仍保留上方的**素材上传对照表**与下方的**【本段结束与后续交接】**）：

```text
【单镜时长】[正整数]秒。
【参考素材】[图片名称：对应对象与职责｜发声角色后缀绑参考音色（优先）或声纹锁图（明写画面严禁出现声波图形或文字）；画外发声单列音色绑定；无则省略]。
【风格与空间】[画幅、画风质感、主光色彩；场景地标与人物开场站位/专属背板/朝向/距离（块内禁写东西南北，多人用两级锚定，封闭场锁死人数无路人）；续镜写清0秒人物开场状态与人物语气状态，新增人物交代进场，禁写已完成过去动词防重演]。
【镜头与动态】[景别、机位方位/高度/俯仰/参数与初始构图（真固定镜明写固定机位完全静止、不推拉不摇移）。紧接连续一段写清行动者、对象、触发、表演、运镜/焦点、物理受光与切出状态，摄影机和特效各自点名主语，禁裸写剪辑术语；非末镜保持动作光影延续至末帧，不提前慢停、不淡黑、不看镜头]。
【音频与对白】[发声者、画内/画外、原词、说法与拟音接点；无则省略]。
【画面文字】[已确认文字与显隐时机；无则省略]。
【画面约束】画面纯净，无字幕，无水印，无平台角标，无额外叠加的标志、说明文字或界面元素。
```

### 模板填写铁律

- 逐镜部分按本段实际镜数完整展开；例如块外源镜清单写 05、06、07、08，块内必须有四份完整分镜正文，不能残留“同上”或只展开一镜。核源镜清单、块内正文与时间映射一一对应、顺序不变、各出现一次。
- 首段和整场单块删去【上一段承接点】，保留【场景空间与开场站位】；续写中段保留【上一段承接点】。
- 无适用内容的栏目和子项直接删去，不输出空栏、“无”或模板说明；必要信息缺失按[交付门槛](流程.md#delivery-gate)回责任步补齐。
- 角色音色只在块首人物后缀绑定一次（参考音色优先，未提供统一绑声纹锁图并加“画面严禁出现声波图形或文字”护栏，块内不出现 `V01` 内部编号）；**逐镜「音频与对白」绝不重复绑定参考音色或声纹锁**，只写当镜发声者、画内/画外、说法、原词与词动铆钉，不用“它”跨对象指代。
- 成稿文风、句式节奏与去重尺度严格对齐[文风锁与黄金样板](../文风锁与黄金样板.md)，动作与对白可并行时按[词动铆钉写法](../文风锁与黄金样板.md#sync-action-dialogue)同步锚定，严禁退回机器人台账复读腔或空洞网文腔。
- 严禁默认产出首尾帧提示词或默认要求用户截末帧垫图（仅用户主动提供首尾帧素材或明确要求首尾帧模式时启用）；块内严禁裸写“硬切、J-cut、L-cut、Match Cut、Whip Pan、遮挡转场、本段结束”等剪辑或流程词，一律写成具体可见的物理动作与声画变化。
- 【画面约束】默认置于块尾；用户明确要求局部字幕或界面时，按[固定约束](流程.md#fixed-constraints)仅对所需范围改写允许项，不同时允许和禁止同一内容。

## 分镜图提示词模板

每张图独立交一块。块外写源镜号、采用版、选定瞬间及素材图片名称→登记ID/路径对照；块内直接用清晰的图片名称声明参考职责，替换所有占位并省去不适用部分。

```text
【参考素材】
[图片名称：对应对象及具体参考用途；无参考图时省略。]

【选定画面】
[画幅和采用画风。继承源镜选定时刻的地标关系、人物场内位置、身体朝向和必要距离；明确摄影机所在区域与观察方向，再写该帧景别、裁切、画面位置和前后景，落实该瞬间已采用的观看重点与可见证据，不提前后续揭示。
点名当帧人物及其姿态、可见神情、视线、手和道具的接触状态。写可见场景、受光、影调和材质。已采用且在该帧可见的效果按当帧形态写。
只在画面有相应内容时写已确认的画内文字。]
```
