# 03 排镜与摄影细则（按需查阅）

本文件收录长对白切镜、分段编号时间轴、全场节奏复核以及双人戏拍法、景别机位与运镜基础定义。新排镜主流程和核心铁律见[03 分镜流程](流程.md)，交付版式见[03 分镜模板](模板.md)。

<a id="part-12-事件排镜与镜长估算"></a>
<a id="part-12"></a>
## 事件排镜与节奏复核

<a id="part-12-先登记已确认的镜头"></a>
### 先登记已确认的镜头

重排前先从本轮要求和有效的修改记录提取已确认的同镜动作、镜号对应、切点与其他锁定拍法。用户把两镜合成一镜后，下一版沿用合并结果。动作进入下一阶段、对白开始、运镜启动或构图连续变化，都可以留在该镜内分阶段表达。确有需要改动锁定镜头时，先指出具体冲突并确认。已有合并或重编号时，保留源镜号对应。

<a id="part-12-从事件决定拍什么"></a>
### 从事件决定拍什么

沿 01 的事件顺序标出观众必须获得的信息、看见的关键动作及其结果。先决定本镜观察谁或什么，再决定是否切。一个画面能交代完整的行动、接触或对白反应时，可留在同一镜；需要改变观察对象、揭示顺序、可读尺度或时间关系时再切。说话者与镜头主体可以不同，原发声者和受话者照录。

以动作结果作为分镜边界时，先确认前镜到底停在动作前、进行中还是完成后。位于画外的人、声音或道具仍按场内状态继续。交付文字只展开本镜执行和接续需要的状态；内部按[空间状态更新](../空间基准与调度.md#space-transition)保留后续仍有效的位置、朝向、持物、接触、视线和对白进度，包括暂时画外的留场者。已完成动作不再起势，无位移依据时不凭切镜换位。

<a id="part-12-长对白先选观察对象"></a>
### 长对白先选观察对象

同一人物连说几句、句内发生明显转折，或刻意重复一句话时，先按可拍的变化判断画面，再估镜长。

1. 找出说话目的、语义、说法或动作的变化，以及听者从哪里开始理解、反应或行动。以原词、表演要求和场戏因果为依据。某句反应尚未确定时，区分原稿事实与可采用的表演设计。
2. 逐拍选观众此刻该看的对象。可以是说话者、听者、两人的关系、关键动作或证据。同一画面能持续读出变化时就留镜。换观察对象或收近能让关键信息、表演或接触变得可读时，选在对应事件处切换。
3. 分开核对白与画面的时间。说话未结束时可以切给听者，原说话者在画外继续。同一次发声和重复表演各按原定次数发生。定位到半句或词语时，要有可见变化或信息接点支撑。已有自然先后关系继续保留，再按完整发声、必要反应和接触过程估时。

<a id="part-12-分段编号与时间轴"></a>
### 分段、编号与时间轴

1. 先定镜头及必要占用，默认按源镜号连续顺排，**不强行包裹「成片大段」**（仅在用户明确要求按“大段”划分展示时才按戏的转折标注大段）。视频生成分段及严格秒数上限一律交由 [04 视频提示词](../04-提示词/流程.md#按段转提示词) 按所选秒数切分。本步的镜长按内容估出，连同源镜号、切点和锁定状态交给 04。
2. 镜号全场稳定。按[估时方法](流程.md#part-12-怎样给计划时间)记录每镜成片区间；若用户明确要大段结构时再写大段号、成片起止与所含镜号。普通顺接时，前镜终点和后镜起点对应同一个时间点或事件边界。
3. 同镜内的动作、运镜和对白可按必要阶段注明进度。分段优先落在镜头边界。若已确认的连续一镜遇到独立输入时长限制，指出冲突并确认可行方案。检查每镜落在对应段内、相邻区间按实际剪辑衔接、最终终点对应成片总长。叠化或跳时有明确设计时另注。

<a id="part-12-全场节奏复核"></a>
### 全场节奏复核

新排镜或重新安排节奏时，先逐镜对照必要占用、可读切出点与额外停留，再按成片顺序看观众在哪里接收信息、感到压力、看到揭示或读到后果。无总时长目标也做这项检查。局部修改只复核受影响的连续几镜。

1. **检查哪里可以收紧。** 去掉已经交代过的动作起势、重复建立信息的镜头和没有作用的等待。连续短镜逐个问「这次换镜让观众多看到什么？」同一构图能让动作或反应连续读清时，可以留在原镜。短促冲击或证据插入仍要留出可辨认的时间。
2. **检查哪里值得留。** 自然说完原词、完成关键接触、读清证据、理解反应，以及有作用的悬念和余韵，都需要实际时间。拿不准一镜该留四秒还是六秒时，问「第 5 秒让观众多看懂或多感受到什么？」有具体作用就保留，没有就收紧。秒数仅用于比较候选估时。
3. **检查全场的长短关系。** 对照铺垫、变化和后果各自所需的时间。可以用同镜内的动作或发声变化形成快慢，也可以在观察任务改变时切换。连贯长镜或连续短镜有叙事作用时可以保留。时长由内容占用决定。
4. **专查开场和长对白。** 开场已交代站位与关系后，问当前景别还能让观众读到什么。后续转折、听者反应或关键动作读不清时，调整观察对象或尺度。若长段一直拍说话者，查听者的重要变化有没有画面位置。若已拆成多镜，逐个确认切点的观看收益，删去仅按字词或句号切分的冗余镜头。
5. **修完重核。** 检查原词、必要动作、信息可读性、前后接缝和总时长。优先调整无作用占用和确能并行的部分。已有采用版镜头按锁定条件执行，确需改切点或时长时指出具体冲突。

按当前疑问直接查条目：

- 长对白留镜查 [ORG-A01](../../知识库/摄影与画面/zhuan-xiang/jing-tou-zu-zhi/ying-yong-chang-jing-ku.md#org-a01)，信息触发听者反应查 [ORG-A09](../../知识库/摄影与画面/zhuan-xiang/jing-tou-zu-zhi/ying-yong-chang-jing-ku.md#org-a09)。
- 对白有原词但无实录查 [TIM-A01](../../知识库/摄影与画面/zhuan-xiang/shi-jian-yu-jie-zou/ying-yong-chang-jing-ku.md#tim-a01)。摄影必须先到位才读得清目标时查 [TIM-A03](../../知识库/摄影与画面/zhuan-xiang/shi-jian-yu-jie-zou/ying-yong-chang-jing-ku.md#tim-a03)。
- 对白与动作并行查 [TIM-A02](../../知识库/摄影与画面/zhuan-xiang/shi-jian-yu-jie-zou/ying-yong-chang-jing-ku.md#tim-a02)，跨镜续声查 [TIM-A06](../../知识库/摄影与画面/zhuan-xiang/shi-jian-yu-jie-zou/ying-yong-chang-jing-ku.md#tim-a06)。
- 需要渐紧或收束查 [TIM-A04](../../知识库/摄影与画面/zhuan-xiang/shi-jian-yu-jie-zou/ying-yong-chang-jing-ku.md#tim-a04) 或 [TIM-A05](../../知识库/摄影与画面/zhuan-xiang/shi-jian-yu-jie-zou/ying-yong-chang-jing-ku.md#tim-a05)，动作快慢、三式速度坡道与物理快慢显形查 [TIM-A07](../../知识库/摄影与画面/zhuan-xiang/shi-jian-yu-jie-zou/ying-yong-chang-jing-ku.md#tim-a07)、[TIM-A11](../../知识库/摄影与画面/zhuan-xiang/shi-jian-yu-jie-zou/ying-yong-chang-jing-ku.md#tim-a11)，超时查 [TIM-A08](../../知识库/摄影与画面/zhuan-xiang/shi-jian-yu-jie-zou/ying-yong-chang-jing-ku.md#tim-a08)。

采用前核对已确认的同镜要求。把镜长或事件边界写回「镜头基础信息」，观察对象变化、续声及切出状态写入「分镜内容」。其他问题按 [摄影专项索引](../../知识库/摄影与画面/zhi-shi-ku/zong-suo-yin.md) 定位。

<a id="redundant-action"></a>
### 冗余动作过渡与运镜强化（4 招决策树）

遇到走路、上下楼、长时间翻找、等待、整理收拾等容易水节奏或令视频模型画崩的冗余过程时，按以下顺序从省镜到强化逐级决策：

1. **留头掐尾 + 声音桥（优先砍过程）**：只拍起势（起身/迈步/推门）直切落点（抵达/拿到手），省略无信息中段；用下场门响、环境音或首句画外对白提前半拍切入（J/L 剪）焊掉路程。
2. **切离借壳藏时间 / 动作匹配切**：把枯燥移动藏到画外，镜内切向等待者反应、逼近威胁或关键物件，切回时主体已到位；或借同方向、同手势动作做匹配切（如拧开旧门直接切推开新厅门）一刀跨过路程。
3. **极简细节切片（专治繁琐操作）**：搜屋、整装、沏茶等操作不拿中景呆拍七八秒，拆成 2–3 个 1–1.5 秒高信息局部特写（拉屉→拨信→捏出钥匙），利落交代过程。
4. **必须留镜时的 4 种运镜与层次强化**（当走路本身承载情绪煎熬、环境揭示或对白时）：
   - **前景遮挡侧跟**：侧移跟拍让既有廊柱、门框、树干掠过前景，拉满纵深与速度感（查 [MOV-A14](../../知识库/摄影与画面/zhuan-xiang/yun-jing-yu-jiao-dian/ying-yong-chang-jing-ku.md#mov-a14)）；
   - **景别渐变推信息**：边走边平稳推近面部压紧心事，或从手中物件慢拉远露出压抑空间（查 [MOV-A16](../../知识库/摄影与画面/zhuan-xiang/yun-jing-yu-jiao-dian/ying-yong-chang-jing-ku.md#mov-a16)）；
   - **牵引 / 尾随立方向期待**：前置倒退拍正脸给气场，背后尾随带出走廊尽头与未知危险（查 [MOV-A13](../../知识库/摄影与画面/zhuan-xiang/yun-jing-yu-jiao-dian/ying-yong-chang-jing-ku.md#mov-a13)）；
   - **动作退居节拍底**：把倒茶、理袖等降级为伴随动作，让对白交锋、眼神微变或掠过脸庞的光影成为观看重点，并按[词动铆钉写法](../文风锁与黄金样板.md#sync-action-dialogue)同步推进。

## 景别、机位与运镜选择

先按[导演决策](流程.md#director-decision)明确观看目标，再问本镜必须读清的是环境、人物关系、表情、手物接触还是证据；本节将决定落实为摄影，不另套情绪处方。以实际入画范围选景别，能清楚读出任务的范围即可。需要同时知道位置与动作时，保留足够的空间参照。需要看清细部时，再收近或另设细节镜。手、脸或道具承担关键信息时，写明实际入画范围。画幅改变时重新核对裁切、前后景和留白，场内站位与道具状态沿用实际镜头。

机位跟随观察任务，但必须从已建立的场内关系推导，按[场内关系与画面投影](../空间基准与调度.md#space-projection)明确摄影机所在区域、朝向及适用轴线的地标参照侧。写清从谁的哪一侧或哪个地标方向看过去，以及影响观感的平视、俯视或仰视。相邻镜头有反打、走位或遮挡时，先核场内朝向、相对位置与轴线，再判断画面左右及谁可见。换角度可以改变画面投影，人物在场内的位置和动作阶段按事件延续。需要越轴时，用已有连续移机、主体走位造成的轴线变化或能重新建立方位的沿轴、交代镜头，让观众看懂观察侧怎么变。

<a id="part-14-按画面任务选双人戏拍法"></a>
### 按画面任务选双人戏拍法

| 画面任务 | 可采用的拍法 | 写到能排镜的程度 |
|---|---|---|
| 看清人物关系、距离或高低差 | 双人同框、双人侧拍 | 写两人各在画幅哪侧、站坐和朝向，注明应同框的动作。 |
| 看两人对峙、对话或互相观察 | 过肩正反打 | 写从谁肩后拍谁、谁的肩在前景、主体朝哪看，以及平视、俯或仰的关系。正反打机位按已采用的轴线一侧核对，保持视线能对上。 |
| 看听者反应、犹豫或准备行动 | 侧脸近景、单人反打 | 写观察哪一侧或从哪个场内方向拍，注明画外说话者与视线目标。 |
| 看清一句重话、眼神变化或正脸反应 | 正面特写 | 写从人物正前方或近正面观察、脸部实际裁切和眼睛的落点。人物看对手时保持视线落在画外对手位置。需要换侧时核对轴线与过渡。直视镜头按已定表演意图采用。 |
| 同时读清伸手、接触、道具和结果 | 动作同框或保留必要空间的中近景 | 写哪几只手、哪个物件或接触点要入画，依据任务决定留镜或切换。 |

每镜按「景别与主体｜机位方位、高度与俯仰｜焦段与景深｜构图关系｜固定或主要运镜」写基础信息。按观察任务选择上表拍法。双人关系交代清楚后，再决定是否需要以过肩、侧脸、正面特写或动作同框看到新的变化。已确认连续一镜时，可按原拍法在镜内收近到所需构图。

固定镜适用于观察任务稳定的画面。主要运镜服务于跟随、揭示、关系变化或改变信息尺度；在简版中写主要运动、触发和起止构图。例如「第二次接触离手后小幅推近，从双人中景到双人中近景」，需要时说明哪些手物须留在画内。项目已锁定拍法时沿用。

<a id="part-14-景别机位构图与运镜"></a>
### 景别、机位、构图与运镜基础定义

<a id="part-14-景别与可读信息"></a>
#### 景别与可读信息

| 景别 | 常见可读内容 | 边界 |
|---|---|---|
| 远景、全景 | 环境关系、全身路径、站位与距离 | 面部微变化或手中细节未必可辨。 |
| 中景、中近景 | 人物交流、上身动作、表情与部分操作 | 局部手物可能被画框裁去。 |
| 近景、特写 | 表情、握点、接触、道具的关键变化 | 场地和主体之间的距离可能难以从局部构图看出。 |

<a id="part-14-机位与构图"></a>
#### 机位与构图

- 机位说明从哪侧、哪种高度、朝什么方向看。俯仰、侧面与过肩分别描述上下和水平关系。过肩画面由近处人物的肩部前景和远处被观察主体构成。
- 前中后景说明层次。画幅裁切与景深分别影响脸、手与结果的可见性和清晰程度。留白可以为目光或移动留出空间。
- 转焦是清晰范围随对焦变化而移向另一主体。浅景深下背景仍可能保留可辨认的形状。

<a id="part-14-运动与裁切"></a>
#### 运动与裁切

| 术语 | 可见差异 |
|---|---|
| 固定 | 摄影机保持位置与朝向，主体可以在画面内行动。 |
| 摇、俯仰 | 机位位置大致固定，观察方向改变。 |
| 推拉、横移、跟拍 | 机位实际移动。靠近或远离可改变前后景相对大小，横移和跟拍可产生视差。 |
| 变焦 | 视场收窄或放宽，未必改变机位和透视关系。 |
| 环绕 | 摄影机绕主体改变观察侧，人物和物件的场内位置照旧。 |

<a id="part-14-按需查专业条目"></a>
### 按需查专业条目

<a id="action-choreography"></a>
#### 动作与交锋场排拍推演（按需）

遇到打斗、追逃或高张力肢体博弈时，先顺着[5 问推演](流程.md#director-thinking)落到具体拍法：

- **先排方向身位链与爬坡节奏**：先定清连续节拍的位移与攻守流向（切入侧→折返位→压进/退让→换线或借物→终段落位），多轮交锋按「先提速试探→后提力道与要害威胁」爬坡；段尾或镜尾动作停在**下一击蓄力前摇**，严禁收势站桩摆姿势。
- **破防三态流转与擦身闪避分段让位**：拒绝回合制木偶对砍。守方受重压按「完整防线→格挡震开中门暴露→侧闪/仰头/单手拍偏零碎过渡→找回支点反击或受创」推进（查 [C09](../../知识库/动作与特效/武打/zhi-shi-ku/tiao-jian-zu-he.md#c09)）；高危贴身躲闪拆写腰背先动逐段成弧、兵刃留清晰间隙、视线死锁持械手与最低点收腹蓄力（查 [C10](../../知识库/动作与特效/武打/zhi-shi-ku/tiao-jian-zu-he.md#c10)，常速成立，关键险失可配 [TIM-A11](../../知识库/摄影与画面/zhuan-xiang/shi-jian-yu-jie-zou/ying-yong-chang-jing-ku.md#tim-a11) 急→微慢→急爆坡道）。
- **兵种力学与距离克制**：长枪长棍写清前后把杠杆传导、杆身微弯震颤、被贴身抽杆拉开及握柄为轴的半圆弧跳劈（防画成垂直僵坠，查 [W06](../../知识库/动作与特效/武打/zhi-shi-ku/chi-xie-ji-chu.md#w06)）；远程弓弩写清推弓引满→撒放弦震→追视与被近身退射拉扯（查 [W07](../../知识库/动作与特效/武打/zhi-shi-ku/chi-xie-ji-chu.md#w07)）；空手对持械先避锋线再扣腕/托肘锁支点卸力，严禁赤手硬抓刃口（查 [W08](../../知识库/动作与特效/武打/zhi-shi-ku/chi-xie-ji-chu.md#w08)）。
- **镜头附着、贴地冲刺与防崩降级**：动作镜头点名贴附矢量（贴刃、贴拳、贴退路），擦镜接招保住唯一命中证据（查 [MOV-A19](../../知识库/摄影与画面/zhuan-xiang/yun-jing-yu-jiao-dian/ying-yong-chang-jing-ku.md#mov-a19)），一镜到底查 [MOV-A20](../../知识库/摄影与画面/zhuan-xiang/yun-jing-yu-jiao-dian/ying-yong-chang-jing-ku.md#mov-a20)；破场突进可用离地 10–30cm 广角斜后对角线贴地跟拍并绑定接敌结果（禁空跑），将 360° 环绕降为 90°–120° 半弧、全程狂抖降为呼吸手持配命中短震（查 [MOV-A21](../../知识库/摄影与画面/zhuan-xiang/yun-jing-yu-jiao-dian/ying-yong-chang-jing-ku.md#mov-a21)）。
- **围攻合并、破障换场与战损反站桩**：4人以上群战不逐个报流水账，用宽镜建合围、代表性击倒连带撞翻同伴与残敌退半圈组织（查 [X09](../../知识库/动作与特效/武打/zhi-shi-ku/chang-jing-ying-yong.md#x09)）；确有跨区依据时把破门窗/坠落写成位移＋攻防＋破坏合一并刷新空间快照（查 [X10](../../知识库/动作与特效/武打/zhi-shi-ku/chang-jing-ying-yong.md#x10)）；重击落实身体凹陷弓身＋场地介质双反馈与默认无血合规替代，高魔大招保留敌方反扑与施术位移（禁站桩读条），前序场地与衣甲战损跨镜累积不复原（查 [X11](../../知识库/动作与特效/武打/zhi-shi-ku/chang-jing-ying-yong.md#x11)）。
