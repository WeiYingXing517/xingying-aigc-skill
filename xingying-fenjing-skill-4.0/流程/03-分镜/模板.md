# 03 分镜模板与选帧规范

本文件存放双栏简版模板、十四项详细分镜模板、十四项填写要点及分镜图选帧步骤。排镜规则与导演/动作/时长铁律见[03 分镜主流程](流程.md)；双人戏拍法、冗余动作过渡及摄影细则见[排镜与摄影细则](排镜与摄影细则.md)；成稿句式节奏、防台账/网文腔与边说边动铆钉严格对齐[文风锁与黄金样板](../文风锁与黄金样板.md)。

<a id="part-13-十四项设计与选帧"></a>
<a id="part-13"></a>
## 十四项填写要点与选帧

采用已有镜头时保留镜号、拍法、主要事件和原词，只细化本轮所需范围。内部十四项是 04 视频提示词的**唯一转写母稿**；用户明确要求完整分镜时，按下方[十四项详细分镜](#part-4)交付同一份稿，每镜一行。出图任务按本页[选帧步骤](#part-13-选帧并交给图像分支)补对应画面。

<a id="part-13-十四项怎么填"></a>
### 十四项怎么填

| 列 | 填写要点 |
|---|---|
| 镜号 | 沿用稳定编号。确需拆并时保留源镜对应。 |
| 时间／时长依据 | 写统一时间原点、区间与指定、预估、实测或未定。关键瞬间也可按事件定位。已定局部变速或速度坡道记录进入与结束事件、物理参照（悬浮微粒双速差或压簧介质后掠）及恢复常速点（单镜≤1次转换，禁填伪帧率或半帧抽帧参数）。 |
| 镜头任务 | 写本镜要让观众获取的变化、证据或反应，以及有依据的理解或体验目标；区分人物情绪与观众已知信息，不只填情绪标签。 |
| 画面、动作与表演 | 写主体、发生顺序、关键接触及同一时刻发生的行动或反应。 |
| 景别与机位 | 写景别和主体裁切、水平观察方向、机位高度、俯仰及适用的起始焦距与光圈。区分机位高度与俯仰，保留已定数值和单位。 |
| 起始构图 | 从场级基准和最近有效状态读取主体相对地标的位置、身体朝向、必要距离及接触，再按本镜机位写画面左右、前后景、裁切、起始焦点和可见景深；明确起始观看重点及其可见证据，限制信息按采用范围遮留。 |
| 运镜与焦点 | 固定机位则明写。区分摄影机移动、摇摄、变焦和转焦，记录已定触发、方向、路径、速度、起止构图或清晰对象，以及运动或转焦带来的观看收益；无转移需求时保持明确重点。 |
| 结束构图与状态 | 写切出时相对地标的位置、身体朝向及动作阶段，再写画幅位置、手侧、持物及接触；保存实际变化，未变项继承，运动中注明已到位置。 |
| 切换与前后衔接 | 写接入、切点的观看收益及后镜需要的状态，保铺垫、揭示与反应的实际顺序。镜头终止或时空跳接据实写，不为变景别强加切镜。 |
| 光源与受光 | 按采用的场景光色写光源、方向、阴影和主体受光。 |
| 台词与说法 | 保留发声者、原词、必要说法与续声位置。 |
| 声音／音效 | 写来源、触发、消失或跨镜持续关系。 |
| 视觉特效 | 写当时可见的形态、阶段、空间影响及残留。无需求时留空或写 `-`，**不填字面“无”**（避免转入提示词时误带空值）。 |
| 画面文字 | 写已确认的文字、位置和出现状态。无确认文字时留空或写 `-`，**不填字面“无”**。 |

<a id="part-13-选帧并交给图像分支"></a>
### 选帧并交给图像分支

1. 优先采用用户指定瞬间。未指定时，选择最能表现本镜任务的一帧，用可靠时间或明确事件定位，例如「握住门把手、尚未拧动」。
2. 按[空间恢复](../空间基准与调度.md#space-recovery)取得源镜选定时刻的场内位置与摄影机状态，再对照景别、画幅裁切、朝向、视线、姿态、手侧、接触和道具状态。移动镜头按当时画面确定，避免把不同阶段叠进一张图；只改构图不得重排人物站位。
3. 按[观看顺序](流程.md#attention-design)恢复该瞬间的主要信息、允许的揭示范围和焦点，核所选静帧确实承载本镜任务；不能将尚未发生的注意力转移或动作结果提前叠入。确定该帧可见的光影、影调、特效阶段和文字。固定光源换视点时查 [LIT-A01](../../知识库/摄影与画面/zhuan-xiang/guang-xian/ying-yong-chang-jing-ku.md#lit-a01)。
4. 为出图记录镜号、选定帧及其可见状态。已经交付十四项完整分镜时，可以用表后的「必要备注」记录。只做分镜图方案时交所记录的源镜号、选定瞬间及可见画面设计。要求提示词时把相同信息交给 [04 图像分支](../04-提示词/流程.md#分镜图提示词)。运动和声音帮助定位瞬间，图像正文落实该帧可见的结果。

## 双栏简版分镜模板

每镜按下面的双栏版式写成两段。开头用一行标明已确认的场戏方向和画风，再简短说明全片镜数、计划总长与依据。有待准备的实际素材时在逐镜前列一次。双栏阶段即明确机位方位、高度、俯仰与焦段/景深；后续转视频时，由 04 流程内先跑齐内部十四栏，再补全手侧持物、局部受光、声画与特效细节。**常规双栏直接按「分镜 1、分镜 2…」连续顺排，不强包「大段」外壳**（仅在用户明确要求按“大段”分组展示时才临时加大段标题），既有镜号沿用。单镜正文只使用「镜头基础信息」和「分镜内容」。

```text
【简易预览版分镜（审阅用）】
【场戏方向与画风】[已确认的表达方向、画风和适用的制作基准]
【时长评估】[发声语言与估时依据、相关约束、总镜数与预计总长]
【空间基准】[本场必要地标关系、人物初始位置与身体朝向、功能距离及适用观察侧；简写，逐镜记录变化。]
【素材准备清单】
[有需要时逐项列对象、用途和实际状态]

分镜N｜简短事件名
镜头基础信息：X秒到Y秒｜景别与主体｜机位方位、高度与俯仰｜焦段与景深（有数值写数值，无数值写焦感与清晰范围）｜构图关系｜固定或主要运镜。
分镜内容：人物的关键位置、动作、完整对白和必要声音按发生关系合写，落到本镜需要保留的切出状态。
```

导演决定直接落实在现有双栏：观看重点和可见证据写入构图，转移触发、揭示与反应按事件进入「分镜内容」，不新增理由栏或强填体验口号。关键采用理由留内部记录，用户要求审方案或解释时再展示。

成稿使用普通 Markdown 段落并填入实际内容，无关的头部项省略。「镜头基础信息」使用成片时间，普通顺接的相邻镜头首尾区间相接；从双栏阶段即明确主体、机位方位、机位高度、俯仰角度、焦段（定性焦感或参考毫米数）与景深清晰范围，方便审阅定调并直接被内部十四项与 04 继承。填写焦段与景深须遵守三条护栏：
1. **按画风适配**：实拍/3D 渲染可写定性焦感或参考焦段（无锁定数值标明为参考）；二维手绘/平涂动漫等无物理镜头画风只写透视感与前中后景清晰层次，不强编相机毫米数。
2. **与景别和可读证据相容**：远景/全景需看清环境关系时不配极浅虚化；普通近景/特写人脸非压迫变形意图不误用超广角（详见 [CAM-A04](../../知识库/摄影与画面/zhuan-xiang/xiang-ji-yu-cheng-xiang/ying-yong-chang-jing-ku.md#cam-a04)、[DEP-A01](../../知识库/摄影与画面/zhuan-xiang/jing-shen-yu-kong-jian-gan/ying-yong-chang-jing-ku.md#dep-a01)）。
3. **不凭空编光圈**：双栏用“景深清晰范围”表达虚实即可，光圈（如 f/2.8）仅在有真实项目依据时记录，04 补十四栏时不因双栏没写光圈而硬编数值。

过肩写从谁肩后拍谁，移动镜头写主要触发及起止构图。普通切换由相邻镜号表示。「分镜内容」写谁在哪里、做或说什么、怎样回应以及必要结果。声音贴近发生事件，台词原词只写一次。不同视点下要接续的朝向、手物或动作状态随事件说明。长对白可以在同一栏分行。新排镜按对白、动作和观察时间估算起止并标计划。仅能定位事件时，写起止事件并标秒点待定。已有区间沿用原含义。

涉及互动时，「分镜内容」明确参与者相对地标的位置、身体朝向及能否接触；固定关系可由头部空间基准简写引用，变化必须落到实际镜号，不能只写“在旁边”。单人静镜和空镜只写任务所需参照，不强加关系轴。

示意（以下布局及实拍焦段均为本例设计参考，文风对齐[文风锁与黄金样板](../文风锁与黄金样板.md#gold-samples)）：

**空间基准**　俯视布局：房间后方为亮窗，左侧靠墙为深色书架，右侧为木门，长桌横置房间中央。甲坐长桌左端、背靠深色书架面向右侧的乙；乙坐长桌右端、背靠木门一侧面向左侧的甲；木盒放在乙面前桌面、右手可及。本组机位均在长桌前侧（轴线同侧）拍摄，甲专属背板为深色书架、乙专属背板为木门与右侧亮窗边缘。

**分镜 1｜试探与合盒**

**镜头基础信息**　0 秒到 3 秒｜双人侧面中景｜摄影机在长桌前侧正对桌面、视平线高度平视｜标准中焦（实拍参考约50mm）、中等景深（甲、乙与桌盒均清晰）｜甲居左朝右（背衬深色书架），乙居右朝左（背衬木门侧墙），后景居中透出亮窗，木盒位于桌面中轴｜固定。

**分镜内容**　甲身体微微前倾，盯着右侧的乙发问：“准备好了吗？”话音落到“好了吗”，乙垂眼顺势压下木盒盖；清脆“咔哒”声落定，乙指尖仍按在盒沿尚未松开时切镜。

**分镜 2｜切离藏步与答复**

**镜头基础信息**　3 秒到 6 秒｜越甲右肩拍乙的中近景｜摄影机在甲左后侧（仍在桌前同侧）略高于肩平视朝向乙｜中长焦（实拍参考约85mm）、浅景深（前景甲右肩微虚，焦点落在乙面部与按盒右手，背景木门与半扇亮窗微虚）｜甲右肩压住画左缘，乙居画右偏中朝画左看，右手与木盒完整可见｜固定。

**分镜内容**　甲话尾刚落便起身向左画外移步，前景右肩滑出留出单人框；乙不回头，右手缓慢把合拢的木盒向身前推回半掌，同时压低声音回答：“好了。”盒停手稳、乙抬眼望向左侧画外时切出。

<a id="part-4"></a>
## 十四项详细分镜模板

用户明确要求完整分镜或十四项详细表时使用。按[十四项怎么填](#part-13-十四项怎么填)填实下列内容。保留十四项列名与顺序，每镜一行，画面选定帧放在必要备注。

<a id="part-4-稿件信息"></a>
### 稿件信息

- 片名／场次
- 版本
- 时长与采用依据
- 画幅及分辨率，按采用的项目规格
- 语言

<a id="part-4-总设定"></a>
### 总设定

- 相机或统一成像
- 主要参考色调
- 风格／渲染质感
- 场景地点、时间与必要环境
- 空间基准：采用布局版本、地标关系、人物初态与功能距离、适用的轴线和观察侧；逐镜在现有十四项记录变化
- 基础光线及场内位置
- 声音原则与贯穿约束
- 已采用的全片锁定项

<a id="part-4-人物设定"></a>
### 人物设定

按实际角色写姓名或身份、关系、外形与服装、采用参考及职责、已给固定音色或 02 声纹锁图/声纹特征词、有关起态。场次稳定设定写一次，逐镜填实际变化。

<a id="part-4-道具与素材使用"></a>
### 道具与素材使用

按实际对象写名称、采用参考与范围、出现时段和关键状态。区分无素材、需准备和已有素材。绑定时采用清晰图片名称。

### 分镜表

|---|---|---|---|---|---|---|---|---|---|---|---|---|---|

<a id="part-4-必要备注"></a>
### 必要备注

- 选定帧与依据，写镜号、时间或事件点及该帧可见状态。
- 关键拍法依据仅在用户要求解释或审方案时展示，注明源镜和实际取舍，不增第十五列；常规交付保存在内部记录。
- 未定或冲突，定位到有关人物、素材或镜头。
- 验证范围，区分计划估时、文字核对与实际成片观察。
- 本版修改，说明实际改变及影响范围。
