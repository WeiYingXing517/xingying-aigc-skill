# 文风锁与黄金样板（防跑偏锚点）

本文件用于把双栏分镜、十四项分镜与视频提示词锁死在统一、克制、可直拍的电影画面文风里，确保轻量或弱势模型在少读深层细则时也能稳定产出高质量成稿。

<a id="weak-model-guard"></a>
## 弱模型防降智 4 条硬底线

任何模型在交稿前，必须死守以下 4 条底线（优先级仅次于原稿事实与已锁定项）：

1. **动作与对白先判并行**：手脚、视线与发声不冲突时必须同镜并行，用「词动铆钉」把动作变化钉死在具体字词上，**绝不把并行动作与台词时长叠加**。
2. **冗余过程先压缩再强化**：走路、寻找、等待等流水账先走「留头掐尾+声桥 / 切离借壳 / 细节切片」，必须留镜时必用前景遮挡、景别渐变、牵引尾随或动作退居节拍底来强化。
3. **封杀两类烂腔调**：严禁机器人台账复读腔（“保持原位未位移、切出状态未变”），严禁空洞网文修辞腔（“空气仿佛凝固、压迫感拉满、复杂目光”）。
4. **句式节奏对齐黄金样板**：成稿的句子长短、动词密度、去重尺度与同步标注方式，严格仿照下方[双题材黄金样板](#gold-samples)。

<a id="sync-action-dialogue"></a>
## 锁三：动作与对白并行「词动铆钉」写法

1. **生理分轨判断**：
   - **可全并行（手脚/身体/视线 + 发声）**：边走边回头说、边倒茶边试探、边格挡边放狠话——同镜同步推进，镜长按两者较长项估算，绝不相加。
   - **口部互斥（吞咽/饮水/咬物/重击憋气 + 发声）**：发声与口部占用错开半拍，把动作卡在句前、句间换气或句尾。
2. **三态铆钉格式**：
   - **双栏**：用自然连词焊合（`边……边……` / `话音落到“某词”时同步……`）。
   - **十四项**：动作列写 `[说到“某词”时+具体动作]`，台词列写 `[边+并行动作+说法]：“原词”[“某词”同步+变化]`。
   - **视频提示词**：「画面与动作」写清主体开口说话的同时执行哪项身体动作，并在关键词处触发微变；「音频与对白」标明 `[边……边……]` 与同一关键词同步接点。
