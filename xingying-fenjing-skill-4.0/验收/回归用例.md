# Skill 回归用例

## 4.0 项目/连续性/绑定回归

运行 `node --test 验收/检索.test.cjs 验收/链路.test.cjs 验收/项目一致性.test.cjs`。主动修改 `知识库/` 内容后，运行 `node 工具/刷新基线.cjs` 同步更新 `验收/基线清单.json`。自动化脚本覆盖跨平台知识库基线、分级指纹（G0–G2/G3/G4–G5）、多集交付采用演进、防空图状态与未看图拦截、弹卡授权正常图+文字补状态（`overrideDims+overrideAuth`）、CRLF/BOM 引文、层级作用域、`until` 无缝衔接及全链路写入 CLI，不代表自动理解剧本或真实生成验收通过。

实际宿主另跑：

| 输入/条件 | 必须观察到的结果 |
|---|---|
| 单场短剧情、未指定项目目录 | 走轻量单场模式，不强建8目录与 `项目.json`；按「片型（保留感谢语与 `Weiyx517517`）＋画幅＋质感 → 片型细分方向（对齐通道）→ 结合前序信息的首项定制推荐主色调」紧凑确认；双栏即含机位高度/俯仰/焦段/景深 |
| 网文小说片段含大量心理/回忆/无主语对话 | 01 先切时空场并走读透剧本 5 层透视与四路可拍化转译（心理外化建议、画外OS不配口型、往事不混入当前空间、沉默留场者挂名、标隐含动作缺口），给 3–5 行一针见血读剧快照 |
| 角色无参考音色走声纹锁图 | 02 推导 4–6 英文词生成纯白底声波+英文词一键生图提示词；04 只在块首人物后缀绑定一次并明写“画面严禁出现声波图形或文字”，块内不写 `V01`，逐镜「音频与对白」不重复绑定 |
| 选按 30 秒排段（尽量贴合或自由分段），累加 `27秒+6秒=33秒` | 「宁短勿超」高于并入下一整镜：强制在 27 秒合法切口提前断段，下一整镜归入分段 2，严禁输出 33 秒超标段；单镜本身超 30 秒回 03 拆镜/黄灯顺接或报冲突 |
| 多段连续动作拆段，用户未提首尾帧 / 用户主动上传首尾帧 | 未提首尾帧时 100% 走常规资产图＋换视角动作相位顺接＋块首0秒动势锁独立直出，**绝不默认要求截末帧或出首尾帧提示词**；用户主动提供或要求首尾帧时启用同档景别咬合与双端力学路径核对 |
| 分镜含转场设计、跨段新增人物、手机/桌上同道具及封闭场 | 分镜/块外可标转场名，进 04 复制块全部转为可见物理动作（零裸写“硬切/J-cut/遮挡转场/本段结束”）；跨段新人物写明入画/先声过渡；手机背面锁朝向不发光、同道具锁单实例互斥、封闭场锁人数无额外路人 |
| 长枪近战/擦身躲刀/大招对轰及快慢速度反差 | 打斗识别为是后命中 `W06–W08`/`C09–C10`/`X10–X11`/`MOV-A21`（写实不混玄幻光污染、破防零碎过渡、半圆弧跳劈、避锋锁腕、无血合规双反馈、战损跨镜保留、大招禁站桩、段尾蓄力前摇）；快慢节点按 `TIM-A11` 写双速悬浮微粒或压簧广角后掠介质＋声场抽空协同，单镜≤1次速度转换，禁 `240fps/0.02s顿帧` 伪参数 |
| 运行中途提口语建议（“太拖/不爽/气场弱/加个摔杯”）或在弹卡期插问 | 每轮顶部（复制块外）输出 `【星应进度锚点】`；冻结未点名镜头与原词不推倒重洗，把口语建议转译为可拍机位/速度坡道/物理动作（不塞网文形容词），同步顺延后续时间码、空间战损快照、内部十四项与下段【上一段承接点】；03交完整重算预览表、04交受影响分段完整可复制块，弹卡期插话同轮重弹未完卡并自动续跑原下一步 |
| 双栏分镜转分段提示词 / 一键直出 | 04 流程内先跑齐完整内部十四栏底稿（长剧模式落盘登记）再转写；块内用清晰图片名称、无登记图ID/本段结束交接、块尾写【画面约束】 |
| 角色受伤但用户懒得做伤后图 / 明确不做资产图 | 弹卡确认后按授权走「正常图+文字写清状态」（`overrideDims+overrideAuth`）或「纯文字外观锁（`mode:'text'`）」防换脸换衣，不私自凑错图 |
| 新项目只发剧本，无画幅画风色调 | 实际弹适用卡，可推荐待确认；原稿保存，通过写入 CLI 记入权威设置与 `项目.json` |
| 第1集交付采纳后继续导入第2集与未来死亡 | 第1集 G0–G5 保持有效不误红；回头改第1集原稿或早期事件则精准拦截 |
| 视觉图漏填伤势状态或未看图 | 触发 `IMAGE_STATE_MISSING` / `UNVIEWED_IMAGE` 暂停受影响段，不凑图放行 |
| 仅说分段提示词 | 实际问未知分段/秒数/贴合；不擅定 |
| 明确用户指认生成图/回传图要登记 | 对象/状态/来源/实际文件正确；无导出能力标仅会话，不伪造路径 |
| 第2集死亡，第70集无依据正常行动 | 先读源稿定位，转写错自行修；源文真冲突才问，不补假死 |
| 第70集明确复活，另有早期倒叙 | 生效点前不复活，倒叙用更早状态，不误报 |
| 暂离不死，伤势变化，场景损毁 | 维度分开；同段变化按阶段绑定；反打不修复场景 |
| 多绑/漏绑/缺状态图 | 逐镜需求与绑定双向核；未授权缺图阻塞相关段不凑图，获弹卡授权可走纯文字锁或正常图+文字补状态 |
| 换对话只说继续 | 从项目文件恢复并简报集场段/阶段/素材/待办，不重问有效设置 |
| 修改前集死亡或受伤事实 | affected列候选范围，语义核后标相关后续待复核，不静默覆盖 |
| 保存中断、文件被替换或输入版本改变 | 不宣称完整，旧检查失效，查证后恢复 |
| 清理弃用图 | 先查全项目引用，垃圾箱分类可恢复，默认不参与选图 |
| 100分钟项目分多批做到后部 | 开头/中期/后期均查源文、状态、登记和正文；至少一次新会话恢复 |

每次行为试跑保存输入、实际读取证据、真实工具调用、文件落点、下游采用和通过/失败。实际成片试跑另记；没有发生的弹卡/恢复/生成测试保持未验证。

## 4.0 调用与成稿回归

运行 `node --test 验收/检索.test.cjs 验收/链路.test.cjs`。后者验证包内本地链接、关键调用边及冲突条款，不等于模型已真实执行。以下行为用例须在实际宿主试跑，逐项记录输入、实际读取方法、产物落点、下游采用结果和通过/失败，不能只记录“有该规则”。

| 用例输入/条件 | 预期调用与可见产物 |
|---|---|
| 只说“转视频提示词”，无有效设置 | 04视频统一入口直接弹分段方式卡（按15秒/按30秒/按镜/整场单块）；选按秒再补未知贴合 |
| 明确分段，未知段长；随后只选15秒 | 依次补段长和未知贴合设置；未答前不交擅定稿 |
| 选“整场不分段（单块）” | 仅用户明确要大段时选用，跳过贴合卡，套用同一视频模板标整场单块（大段）并省承接栏；常规按秒排段一律标分段1/分段2且严格 ≤ 所选上限 |
| 已确认分组或明确授权自主选择 | 复用设置，不重复弹卡；保留来源与范围 |
| 跑到巷口，无其他角色与事件 | 03覆盖先于估时，可合法省略普通路程，不造等待者 |
| 跑向已有等待者 | 切离期间跑者可继续，接回已推进状态，不重起跑 |
| 持续长镜的难度/体验确有作用 | 不机械切碎或设置跑步时长上限 |
| 多人递钥匙后转身；代词指向不清 | 明确递者、接者、手侧、释放及摄影机主体，不能只声明主语清楚 |
| 摄影机横移露人/人物走入/转焦 | 三种运动分别明确主语、起止和可见结果 |
| 长对白切听者 | 点名听者、原发声者画外续声和信息到达点，原词不改 |
| 无需微表情的等待或静镜 | 核参与者但不强配眉眼嘴角，必要原表演仍保留 |
| 自然段14.6秒，可增加有作用0.4秒 | 内容分组不变，内部调至15秒，所有接点同步 |
| 自然段14.6秒，有0.6秒可收紧 | 可调至14秒，不机械向上取整或均摊 |
| 已整数且节奏成立 | 不再为了调时而更改 |
| 按镜4.6秒且锁定、不得改 | 报真实冲突，不标题写5秒或偷偷变速 |
| 四镜05/06/07/08，总15秒 | 清单与四份完整正文一一对应，内部可小数，末镜到15秒 |
| 无图首段或独立新段 | 有基本地标、站位、朝向、距离，无上段承接栏 |
| 只续写中间一段 | 恢复前段/最近有效状态，承接栏不能因本轮单段而删 |
| 有布局图/只有气氛图/人物图 | 职责分开；站位在已采用布局内，不用气氛图暗锁布局 |
| 换机位、隔段人物再现、持物跨段 | 地标关系及最近状态有来源，画面投影重算，不无因换位 |
| 内部十四项含插入、声音、参数、特效及文字 | 04 统一视频块逐项保留必要信息，不能摘要丢失 |
| 无画面文字、无特效、无实际素材 | 对应栏和子项不输出，不写“无/不适用”，不编造填空 |
| 所有独立视频块 | 块尾【画面约束】实际写无字幕、无水印等固定约束（块外附独立反向词参考），不把“无字幕”理解成静音 |
| 剧情有招牌，另明确要求局部字幕 | 保留确认的场内文字；仅对所需范围解除字幕禁令，不同时允许禁止 |
| 未确认的必要站位/主体/接触 | 回责任步骤补齐或报告阻塞，不以删空栏掩盖 |

验收分层：静态结构与检索可自动化；主语、空间和文风需语义审阅；实际生成遵循度需视频试跑。当前未试跑项保持未验证。
